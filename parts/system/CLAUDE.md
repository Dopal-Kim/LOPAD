# 게임 시스템 파트

## 역할
전투, 로그라이크 루프(런·스테이지·시련·보스), 무기 개성 변화, 스탯·감각 수치, 맵 생성(방+복도), 세이브, 메타 진행(무기 도감·영혼 토큰)의 설계와 코드 구현.

## 소유 경로
- `parts/system/**` — 설계 문서, 수치 설계 메모
- `src/**` — 단, `src/ui/**`는 UI 파트 소유이므로 **열지 않는다**
- `data/**` — 적·아이템·무기·스테이지 데이터
- 빌드·설정 파일 (`package.json`, `vite.config.*`, `tsconfig*.json`, `index.html`)

## 사용 가능 스킬
- `.claude/skills/phaser/` (필수 준수)

## 개시 시 인터뷰로 확정할 항목 (기획서 10장 기준, 아직 미정)
- 기본 해상도와 스케일 방식
- 데이터를 JSON 파일로 분리할지, 폴더 구조(`src/`, `data/`, `assets/`)
- 프로토타입 1단계 범위 (사각형 캐릭터 이동·공격, 적 1종)
- 스탯 표의 미정 수치(치명타 데미지 기본값 등)
- 세션 시작 훅(의존성 자동 설치) 설정 여부

## 금지
- `src/ui/**`, `assets/**`, `parts/{ui,art,sound,story}/**` 읽기·쓰기
- UI와 공유해야 하는 이벤트·상태 인터페이스는 승인 후 `parts/producer/contracts/`에 계약으로만 둔다
