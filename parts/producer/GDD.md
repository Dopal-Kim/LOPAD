## 1. 게임 개요

| 항목 | 내용 |
|---|---|
| 제목 (가제) | LOPAD |
| 한 줄 소개 | 로파드식 메가봉크 순수 도파민 사기치기 |
| 장르 | 로그라이크 + 액션 + LOPAD(자체 장르) |
| 시점 | 탑다운 |
| 플랫폼 | PC 웹 |
| 1회 플레이 시간 | 순수 플레이 최대 50분. 숙련도·컨트롤이 부족하면 10~20분에 머물 정도로 난이도가 중요 |

**참고 게임**
- 메가봉크: 아이템 조합으로 엄청나게 강해지는 것
- 테라리아 인페르노 모드의 무기: 다양하고 강력한 도트 구현 이미지. 무기 자체 이미지와 개성이 뚜렷한 게임으로 나아가고자 함
- 타이탄 소울: 아이템 조합으로 강해지되, 상대적으로 약한 아이템으로도 컨트롤로 보스를 공략 가능하게, 보스를 무너뜨릴 한 방이 존재. 같은 무기로 계속 보스만 잡는 매력
- 할로우 나이트: 보스 전투 양상을 많이 참고

**차별점**
아이템 조합으로 뛰어나고 멋진 아이템을 만들어내는 재미와, 그 무기로 보스를 헤쳐나가는 재미를 함께 누린다. 보스를 잡는 과정에서 무기가 강력해도 주의를 기울여야 하고, 무기가 부족해도 보스를 노려볼 수 있는 **캠페인 모드**를 구성한다. 캠페인 클리어 후에는 무한히 강해지며 패턴이 달라지는 보스와 최고의 아이템을 겨루는 **경쟁 모드**도 구현한다. 초반 **캐릭터 개성 설정** 테마: 자신이 생각하는 가장 강력한 것의 이미지를 3번의 획으로 그리거나, 키보드·마우스로 개성을 보여주는 움직임을 나타내는 등의 개성 선택을 통해 해당 루프에서 사용할 무기가 결정되는 "운명" 같은 느낌.

**세계관·스토리**
세계관과 스토리는 비워둔다. 메인 분위기만 정함: 판타지 중에서도 현실과 맞닿아 있는 판타지. 강력하고 현실에서 느끼지 못하는 미지의 무언가를 조우하는 느낌을 가져오되, 반드시 현실적인 면모를 강조해 너무 큰 괴리감을 만들지 않는다. 죠죠의 기묘한 모험: 스틸 볼 런의 해학적인 감정과, 무기·능력에서 느껴지는 강하되 신비한 분위기를 강조 (무기·능력을 본받아 제작하라는 뜻이 아니라 분위기만 이해). 나머지는 모두 **BLANK**.

## 2. 핵심 게임 루프

**긴 루프 (런 하나)**: 캐릭터 설정 → 스테이지 탐험 (총 7개 예상) → 스테이지마다 보스 조우 → 최종 보스 클리어 시 끝

**짧은 루프 (스테이지 내)**: 필드에서 여러 방식의 전투 양상을 클리어하고 총 3~4번의 시련을 통과하면 해당 스테이지 보스와 조우.

**시련 보상**: 캐릭터 기본 스탯(무기의 추후 변경 양상과 직결), 체력 혹은 기력 회복, 재화 등.

**플레이어가 느낄 재미**: 각 시련에서 현재 무기의 매력을 강조해 어떤 전투를 할지 임의 계획을 세울 수 있게 하고, 보스 전투에서는 일정한 패턴을 모두 받아내고 높은 난이도의 보스를 잡아 성취감을 준다. 보스를 잡은 뒤에는 무기 자체의 변화를 촉진해 다음 스테이지에서는 달라지는 무기의 전투 양상을 준비하는, 변화하는 전투 체계. (테라리아처럼 보스를 잡을수록 얻는 재화로 무기를 진화시키고 새 보스 무기를 받으며 한 무기를 계속 성장시키는 매력. 무기 시스템의 이펙트·기본 셋업은 테라리아 인페르노 모드 위키에서 주로 참고.)

## 3. 로그라이크 시스템

| 항목 | 정한 내용 |
|---|---|
| 사망 처리 | 영구 사망. 죽으면 무기도 모두 초기화 |
| 무작위 요소 | 맵은 7가지 스테이지 일정. 적은 스테이지 컨셉에 따라 변화. 무기는 처음 개성 선택 과정에서 결정 |
| 런 간 성장 (메타) | 무기 도감: 개성 선택으로 나아간 무기 진화 과정 기록. 죽으면 기본 스탯·대쉬 등 기본 능력치를 올릴 수 있는 "영혼" 토큰을 성장 정도에 따라 부여 |
| 난이도 상승 | 높은 스테이지일수록 몬스터 체급 상승, 공격 양상은 스테이지마다 다름. 최종·후반 스테이지는 난이도 있게. 보스는 패턴 파훼 필수 (구현: 층별 HP·공격 배율 + 웨이브 표, 보스 변형 6종 + 최종 보스 3페이즈 — 12라운드) |
| 시드 | 같은 맵 재도전은 특수 모드가 아니면 불가 |
| 저장 | 런 중간 저장은 스테이지를 넘어가는 순간에만, 총 2번까지. 그 외 중간 세이브 불가 (구현: 전환 시 자동 저장, 재진입 시 자동 이어하기 — 12라운드) |

## 4. 플레이어·전투

**전투 방식**: 실시간. 무기별로 개성 있는 전투 양상.

| 스탯 | 시작값 | 설명 |
|---|---|---|
| 체력 (HP) | 100 | 0이 되면 사망 |
| 공격력 | 5 | 예리함 → 치명타 기반 / 둔중함 → 데미지 기반 |
| 이동 속도 | 2 (**재검토**: 프로토타입은 임시 6칸/초, 6라운드) | 칸/초 |
| 치명타 | 0 | 치명타 확률 |
| 방어력 | 3 | 데미지 감소 계수 |
| 개성 | 0 | 무기 개성 변화를 위한 수치. 개성 변화마다 초기화, 100 달성 시 개성 변화 진행 (구현: 적 처치로 획득 — 11라운드 보충) |
| 치명타 데미지 | 0 | 치명타 데미지 |
| 감각 | 0 | 패링·무기·회피 후 급습·대쉬 공격 등 적을 잡는 방식을 매 스테이지마다 새롭게 할 때마다 1씩. 스테이지 클리어 시 감각 수치에 기반해 기본 능력치 보상 (구현: attack/dashAttack/parry 3분류 — 11라운드 임시. 보상: 보스 처치 후 감각 1점당 능력치 포인트 1 선택 — 13라운드) |

**행동 목록**: 이동, 공격, 패링, 회피, 스킬, 상점, 대화

**캐릭터(직업)**: 기존 캐릭터는 일정. 삶의 무한 루프를 반복하며 매번 기억이 초기화되는 메인 캐릭터가, 자신이 아는 수많은 무기 개성 변화를 새롭게 싸우며 떠올려내는 형식.
