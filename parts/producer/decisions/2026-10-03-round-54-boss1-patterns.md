# 2026-10-03 · 54라운드 · 1층 보스 '만취' 패턴 디벨롭

도영 님 지시: "보스의 다채로운 패턴을 연구해야해. 일단 1스테이지 보스의 패턴만 더 디벨롭하자. 술을 주로 마시는 이미지이니, 화면을 뒤집거나 어지럽게 하는 그런 패턴과 그 패턴 도중에 3연 대쉬 공격을 한다던가 등의 새롭고 술에 관련된 패턴을 디벨롭하자. 패턴 참조는 테라리아, 타이탄 소울이야. 여러가지 참조해보고 기존의 탄막, 단순 공격보다 새로운 양상을 그려내는 패턴을 디벨롭하자."

- 참조 추가: 보스 패턴 한정 **테라리아·타이탄 소울**(GDD 1장 기존 참조와 같음). 시각 참조 원칙(CLAUDE.md 4-1)과는 별개 — 패턴 설계 참조.
- 사전 조사: 시스템 현황 보고(2페이즈, 돌진·내리찍기·부채꼴 탄·소환, HP 200, 그로기 없음, `dash.repeat` 있음, 화면 연출 가능성 — 회전·180° 뒤집기·조작 반전·어둠 쉬움 / 거울·이중상·색수차는 셰이더 필요, UI 씬은 영향 없음).
- 콘셉트: 52라운드 Q2 '술에 잔뜩 취한 지배자' 그대로(보스 자신의 취기가 화면에 번짐).

### Q1. 페이즈
- 선택지: 3페이즈 얼큰·만취·인사불성 (추천) / 2페이즈 유지 / 4페이즈
- 결정: **3페이즈 (추천)** — 100~60% 얼큰, 60~25% 만취, 25%~ 인사불성. 전환마다 술 들이켜는 연출.

### Q2. 취기·화면 패턴 (복수 선택)
- 선택지: 세상이 돈다 + 3연 취권 돌진 / 거꾸로 선 세상(180°) / 취중 환각 분신 / 등불 끄기(어둠)
- 결정: **세상이 돈다 + 3연 취권 돌진, 등불 끄기(어둠)**. 거꾸로 선 세상·환각 분신은 채택 안 함.

### Q3. 술 소품 패턴 (복수 선택)
- 선택지: 술독 굴리기 / 불붙은 술(웅덩이 점화) / 건배 충격파 / 한 잔 더(약점 잔)
- 결정: **술독 굴리기, 불붙은 술, 한 잔 더**. 건배 충격파 채택 안 함.

### Q4. 코드 구조
- 결정: **패턴 모듈 분리 + 1층만 새 패턴 (추천)** — 패턴 모듈·레지스트리, 수치는 `bosses.json` `patterns.<이름>` 로 통일. 2~7층은 새 틀로 옮기기만 하고 패턴은 그대로.

### Q5. 페이즈 배치
- 결정: **추천 배치 (추천)** — 얼큰: 돌진·내리찍기·술독 굴리기·한 잔 더 / 만취: + 세상이 돈다·3연 취권·불붙은 술 / 인사불성: + 등불 끄기, 어둠 속 3연 취권·불 웅덩이 연계, 패턴 간격 짧아짐. **부채꼴 탄·징집병 소환 제거**(1층만).

### Q6. 한 잔 더
- 결정: **마시기가 화면 패턴의 방아쇠 (추천)** — '세상이 돈다'·'등불 끄기'는 보스가 큰 잔을 다 비워야 발동. 마시는 2초 동안 잔(약점)을 한 번이라도 맞히면 잔이 깨져 술을 뒤집어쓰고 3초 경직, 화면 패턴 취소. 얼큰에서는 마시면 다음 패턴 강화(추천안 배치 기준).

### Q7. 세상이 돈다 세기
- 결정: **기울기 ±8° 천천히(주기 약 2초) + 약한 가장자리 흐림, 6초 (추천)** — HUD 영향 없음, 설정에서 끄기 가능(흔들림 끄기와 같은 방식).

### Q8. 어둠 해제
- 결정: **촛대를 다시 켜면 밝아짐 (추천)** — 쓰러진 촛대(2~4개)를 치거나 E로 다시 켜면 주변이 밝아짐, 불붙은 웅덩이도 광원, 12초 후 저절로 복구.

### Q9. 3연 취권 돌진
- 결정: **휘는 궤적, 예고 600→350→350ms (추천)** — 예고선도 휘어 보임. 인사불성 500→300→300. 세 번째 뒤 넘어져 2초 경직(반격 창).

### Q10. 보스 HP
- 결정: **300 (추천)** — 데모로 조정.

### Q11. 보스방 장애물
