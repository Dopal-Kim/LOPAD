# 2026-10-03 · 55라운드 · 무기 이펙트 전면 디벨롭

도영 님 지시: "무기 이펙트 전면 디벨롭 관련해서 계속 진행하자."

### Q1. 범위 (복수 선택)
- 선택지: 휘두름·궤적 그림 / 타격감(맞는 순간) / 갈래 진화 이펙트 / 움직임·잔상(대쉬·패링 등)
- 결정: **네 가지 모두** + 자유 답변 "아까 전에 디벨롭했던 내용들도 데모에 반영 안되있어서 해당 내용들 기반해서 디벨롭하자" — 53라운드 무기 이펙트 v3(Q5·Q55·Q61~Q68)를 기반으로.

### Q2. 제작 방식
- 결정: **도트 그림 + 실시간 연출 혼합 (추천)** — 궤적 주 모양은 도트 시트(아트), 칼끝 잔상 리본·불똥 입자·빛 번짐·히트스톱은 시스템 실시간.

### Q3. 순서
- 선택지: 칼 먼저 (추천) / 4종 동시 / 타격감 공통 규칙 먼저 → 결정: **4종 동시**.

### Q4. 참조
- 결정: **데드셀 중심 + 테라리아 인페르노 (추천)** — 데드셀: 궤적·히트스톱·타격 밀도 / 테라리아 인페르노: 진화할수록 화려해지는 무기 이펙트(GDD 기준).

### Q5. 데모 미반영 확인
- 결정(도영 님 보고): **기본 연격 궤적이 예전 그대로, 갈래 진화 이펙트가 안 보임**.
- 비고: 배포본에는 fx v3 103종 중 101종이 들어 있음(flash·heavyarrow 제외) — 게임 내 사용 경로 진단을 시스템에 지시.

### Q6. 히트스톱
- 결정: **무기별 차등 (추천)** — 단검 30ms·칼 45ms·대검 80ms·활 25ms, 막타·치명타 ×1.8, 동시 다수 적중은 한 번만.

### Q7. 칼끝 잔상 리본
- 결정: **가느다란 호박 선 + 빠르게 사라짐 (추천)** — 칼끝 2~3도트 폭, 100ms 안에 재색으로 식으며 소멸, 도트 궤적을 가리지 않음.

### Q8. 적중 반응 (복수 선택)
- 결정: **적중 스파크 + 흰 점멸, 재 파편 입자, 화면 흔들림(막타·대검·치명타만 짧게)**. 방향성 넉백 강화는 채택 안 함.

### Q9. 갈래 진화 단계 표현
- 결정: **단계마다 눈에 띄게 쌓임 (추천)** — 기본 = 재·호박 궤적 / 1단 갈래 = 궤적 모양이 갈래별로 확 달라짐 / 2단 = 모양 + 입자·빛·잔연이 더해지고 크기 증가. (53라운드 Q61 '재·호박색만'·Q65 '판정 순간 백열' 유지)

### Q10~Q13. 작업 B 산출(art 4092e33) 검수
- 막타용 큰 적중(`hit_<무기>_heavy`) 기준: **연격 마지막 타 + 치명타 (추천)**(대쉬 공격 마무리 포함).
- 적중 스파크 크기(일반 104~128도트, 막타 192): **이대로 (추천)**.
- 움직임 이펙트 길이 증가(예: 패링 섬광 330→360ms): **늘어난 길이 그대로 (추천)**.
- 대쉬 잔상 색: **따뜻한 재 유지 (추천)**.
- 비고: `shakeHint`·입자 recipes·ironwall `depthByDirection` 은 아트 임시값·제안 — 시스템 연결 후 데모로 조정.

### Q14~Q17. 기준선 진단(system 조사)·작업 A(art a70506d) 검수
- 진단: 코드 연결은 정상(fx v3 재생 중). '예전 그대로'의 원인 = 기본 흰 리본이 덮음, 히트스톱이 예비 프레임에 멈춤, 대검 궤적이 적중보다 ~128ms 먼저, 리본이 히트스톱 뒤 직선으로 끊김, 갈래 판정 확대가 그림에 미반영, 1단·2단 차이가 작았음. 데모 보스전은 진화 없이 시작.
- 타이밍 교정: **네 가지 모두 (추천)** — ① 히트스톱은 판정(백열) 프레임에서 정지 ② 히트스톱 중 리본·지연 판정도 정지 ③ 대검 궤적을 타격 순간에 맞춤 ④ 기본 흰 리본 제거 → Q7 호박 칼끝 리본.
- 갈래 크기: **판정 배율만큼 그림도 키움 (추천)**.
- 2단 갈래 표현: **전용 시트 확정 (추천)** — 계약 §10 문구 갱신.
- 아트 세부: **모두 추천대로 (추천)** — 발도 반달 면은 판정 순간 40~50ms 만 꽉 참(데모 확인), 단검 바늘 3.6 유지, 관통 2단은 꼬리 시트가 구 pierce 겹침 대체.
- 계약 §16 신설(적중 스파크·입자·리본·움직임 fx 키).

### 도영 님 피드백 (공격 형태 재설계 지시)
- 원문: "테라리아의 이펙트를 참조하라고는 했는데 이펙트 구현 측면에서는 좋은데 검은 뭔가 원으로 벤다는 이미지는 좋은데 대검은 뭔가 정면에 검을 내려치고 휘두르고의 반복이 더 좋을 것 같아. 그리고 뭔가 원 보다는 호로 구성된다면 더 재밌을 것 같아. 로그라이크 게임 상위권에 위치한 게임들을 참조해서 대검의 움직임과 검의 움직임을 다시금 찾아보고 더 새롭게 단조롭지 않은 공격 형태를 구현하자."
- 해석: 대검 = 정면 내려치기 ↔ 휘두르기 반복, 베기는 원보다 방향이 있는 호(대각·수직·수평), 칼·대검 연격을 단조롭지 않게 재설계.
- 참조 추가(공격 동작·연격 구조 한정, 시각 참조 원칙 4-1 과 별개): 상위권 액션 로그라이크(2015년 이후) — 조사 후 인터뷰.
