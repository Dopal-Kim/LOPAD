# 결정 로그

도영 님과의 인터뷰 결과를 라운드 단위로 기록한다. 파일 이름: `YYYY-MM-DD-round-NN-<주제>.md`.

## 항목 형식
```
### Q<n>. <질문>
- 선택지: A / B / C   (추천안에 (추천) 표시)
- 결정: <선택한 답. 자유 답변이면 그대로 인용>
- 비고: <조건, 보류 사항, 후속 인터뷰 필요 여부>
```

## 다른 파일
- `cross-references.md` — 파트 간 참조 승인 대장. 승인 없는 참조는 금지.
- `research-*.md` — 인터뷰에 앞서 Claude가 조사한 내용 (스킬 후보 등). 결정이 아니다.
