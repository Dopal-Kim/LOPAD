# LOPAD 무기 성장 체계: 현행 정밀 조사 (읽기 전용, 2026-10-05 기준)

결론부터 말하면, 지금 1층 런에서 실제로 겪는 성장은 **"개성 100 → 1단 갈래 1개 → 이후 200마다 강화(최대 3회) → 게이지 정지"**뿐입니다. 2단 갈래와 각성은 무기 시험장에서만 나옵니다. 무기 외형이 영구적으로 바뀌는 지점은 **각성 1회뿐**이고, 이 각성은 실제 런에서 도달할 수 없습니다.

## 1. 개성(트레이트 점수) 획득과 임계
**획득처** (`gainPersonality` 호출: `Progression.ts:94-133`)
- **일반 처치**: `round(personalityValue × 0.5)`입니다(`build.json:337` normalKillMult).
  - 징집병 4, 사수 5, 결사병 6, 독주 행상 6, 술통 짐꾼 7 (`enemies.json:11,47,69,115,155`).
  - 처치 배율: 패시브 `personalityMult`('개성 각성' +100%, floor 2라 1층엔 없음), 판돈 종(2층), 엘리트 rewardMult, 연쇄 6 '살기' ×2(floor 2).
- **보스**: 1층 만취 50(절반 처리 없음) (`bosses.json:21`). 2~7층 55~80, 황제 100.
- **보스 결정타**: +30 (`bundle2.json:431`, `BossBreaks.ts:95`).
- **노드 성과 '완(完)'**: +20, 위험 노드면 ×2 (`bundle2.json:345`).
- **노드 보상 '획 자국'**: +40, 층당 1회 (`bundle2.json:6,11`, `NodeFlow.ts:276`).
- **이벤트 E4 '떠올린다'**: +30 (`bundle2.json:127`).
- **무명 전사의 묘 '받아들인다'**: +25 (`structures.json:98`).
- **저주 '깨진 잔'**: 즉시 +60 (`curses.json:43`, `BuildRuntime.ts:340`).
- 결과적으로 1층 한 판에서 100은 확실히 넘고, 200(강화 1회)도 닿을 수 있는 수준입니다.

**임계 규칙** (`weapons.ts`)
- 임계표는 무기 4종 모두 `thresholds:[100,200]`입니다(`weapons.json:107,561,836,1049`).
- `threshold`는 현재 단계(=갈래 경로 길이)의 임계이고, 표가 끝나면 마지막 값 200을 계속 씁니다(`weapons.ts:67`).
- **임계는 누적이 아닙니다.** 고르면 개성이 0으로 돌아갑니다(`choose` :189, `reinforceNow` :205, `consumeChoice` :199).
  - 따라서 1단까지 100, 2단까지는 다시 200을 모아야 합니다(누적 300). 그 뒤로는 200마다 메뉴가 열립니다.
- 임계에 닿으면 수치가 임계값에 고정되고 `choicePending`가 켜집니다(:177-186). 메뉴는 다른 메뉴·보스 연출이 끝난 뒤 게임을 멈추고 엽니다(`Progression.ts:137-141`).
- 열린 칸이 하나도 없으면 개성 획득이 **조용히 무시**되어 게이지가 멈춥니다(`BuildMenus.canEvolve` :92, `anySlotOpen` `evolveSlots.ts:64`).

**메뉴 칸 구성** (`evolveSlots.ts:35-61`, `BuildMenus.openEvolveMenu` :96-171)

| 시점 | 칸 1 | 칸 2 | 칸 3 |
|---|---|---|---|
| 1단 임계 100 | 1단 갈래 A | 1단 갈래 B | 강화 |
| 2단 임계 200 | 2단 α | 2단 β | 강화 |
| 그 뒤 200마다 | 강화 | 피의 계약 | 각성(조건 미충족이면 잠김) |

- **강화**: 피해·범위 +15%, 상한 3회(각성 후 5). 현재 갈래 노드의 첫 태그 점수 +1(최대 3). 갈래 없이 고른 강화는 태그 점수를 주지 않습니다.
  - 근거: `weapons.json` rules, `tagScore.ts:39-43`.
  - 100에서 강화를 고르면 단계가 그대로라 다음 임계도 다시 100이고, 갈래 선택지가 그대로 남습니다.
- **층 제한**: `evolve.maxTierByFloor {"1":1}` (`build.json:327`). `runOptions`가 1층 런에서는 단계 1 이상이면 갈래 선택지를 비웁니다(`BuildMenus.ts:67-71`). 시험장은 예외입니다.
  - 그래서 1층 런의 200 메뉴는 **[강화 / 피의 계약(닫힘: '이 층에서는 열리지 않는다') / 각성(잠김)]**입니다.
  - 강화 3회가 끝나면 게이지가 멈춥니다.

## 2. 무기별 상세
**공통 구조**
- 4동사: 좌 = 연격, 우 = 시그니처, Space = 대쉬(+대쉬 직후 좌 = 대쉬 공격), 좌 홀드 = 고유 자원 기술 (`README.md` §7, `CHANGELOG.md:1072-`).
- 1단 갈래는 동작을 더하지 않고 **같은 칸의 기본 동작을 대신**합니다(`moves.ts:163-165` availableMoves).
- 2단: α = 동작 심화, β = 자원 규칙 전환.
- 갈래 노드의 태그 1개당 태그 점수 1점입니다.

**칼** (자원: 기력은 배경 자원, 보이는 자원은 검기 3단 `gauge.kenki`)
- **4동사**: 3연격(올려·내려·찌르기) / 가드·패링(→ 좌 간파 반격) / 대쉬·일섬(4칸 돌진) / 발도(검기 전부 소모, 단마다 +25%, 3단이면 확정 치명).
- **1단 A 선풍(iai, 연쇄·원격)**: 좌 홀드가 회전 베기로 바뀝니다. 2타 호 180°·판정 ×1.2.
  - 2단: 회오리(지속 회전·탄 반사) / 잔월(처치 시 검기·달 궤적).
- **1단 B 투구가르기(batto, 중량·급소)**: 좌 홀드가 가드 불가 내려베기로 바뀝니다. 1타 경직 0.2초.
  - 2단: 일도양단(균열 4칸·HP 30% 처형) / 명경(검기 상한 5·패링 2단·5단 발도 분신).

**대검** (보이는 자원: 울분)
- **4동사**: 4타 순환 / 가드·퍼펙트 가드(울분)·떼면 밀쳐내기 / 대쉬·어깨 태클 / 차지 3단 내려찍기 + 균열(울분 전부 소모).
- **1단 A 파쇄(crush, 원격·중량)**: 대쉬 공격이 공중제비 도약 찍기로 바뀝니다. 균열이 탄을 지우고, 4타 끝에 짧은 균열이 생깁니다.
  - 2단: 지진(균열 3갈래) / 반향(퍼펙트 가드 균열 반격).
- **1단 B 중압(weight, 중량·버팀)**: 막은 직후 우를 떼면 버티기 올려베기(슈퍼아머)가 나갑니다. 차지 자리에 원형 진동이 생깁니다.
  - 2단: 거인(차지 4단·피해 −50%) / 울혈(그로기 울분·자동 폭발).

**단검** (가속 `heat`은 숨김, 보이는 자원은 낙인 최대 5)
- **4동사**: 3찌르기(가속) / 그림자 걸음(낙인 기폭 → 등 뒤 치명) / 대쉬 찌르기 / 고속 난타.
- **1단 A 쌍격(twin, 표식·급소)**: 시그니처 칸이 분신 교차 베기로 바뀝니다. 3타가 2연 찌르기가 됩니다.
  - 2단: 난무(분신 3초 동행) / 출혈(기폭 60% + 출혈).
- **1단 B 질풍(gale, 원격·돌파)**: 대쉬 공격이 부채꼴 투척 3개로 바뀝니다. 이동 +15%.
  - 2단: 비도(투척 5개·박힌 단검으로 걸음) / 열풍(가속 반전·100% 폭발).

**활** (보이는 자원: 화살 8발. 숨은 저격 갈래에서만)
- **4동사**: 짧게 쏘기 / 당겨 쏘기·완벽 놓기(화살 미소모) / 대쉬 사격 / 화살비(좌 홀드).
- **1단 A 속사(rapid, 연쇄·원격)**: 좌 홀드가 초당 5발 연사로 바뀝니다. 탄창 +4, 간격 −30%.
  - 2단: 연궁(분열) / 무한통(처치가 곧 장전).
- **1단 B 저격(snipe, 급소·간파)**: 시그니처 칸이 관통 3명 화살로 바뀝니다. 숨 3개면 감속 정밀 조준.
  - 2단: 필중(정밀 조준 치명 확정) / 천공(연결 스택·벽 관통).

**각성** (`awakenings.json`, `evolveSlots.ts:81-87`, `BuildMenus.applyAwaken` :185-202)
- **조건**: 2단 보유 + 그 2단 태그 중 하나 6점 + 5층 보스 처치 이후. 시험장은 층 조건을 무시합니다.
  - 데이터는 `build.json:329`이고, 메뉴 잠김 문구가 이 조건을 그대로 보여 줍니다.
- **획득 방식**: 200 메뉴의 '각성' 칸에서 얻습니다. 무기당 **이름·외형은 정말 1종**이고, 공통 효과 + 현재 2단에 따른 규칙 1개가 더해집니다(2단 4종이므로 규칙 4종).
- **각성 효과**: 강화 상한 5. 배너·자막('이름 — 설명')·각성 순간 fx·외형 오버레이가 나오고, fx는 각성 궤적으로 교체됩니다(`AwakenFlow.ts:31-57`).
- **무기별 내용** (`live:false`는 데이터만 있고 효과 미연결, `buildMods.ts:141-147`):
  - **칼 만월**: 검기 5·연속 일섬·분신. **공통 효과 자체가 live:false**이고, 규칙 중 명경만 live입니다. 즉 칼 각성은 사실상 명경 규칙 외에 효과가 없습니다.
  - **대검 산붕**: 4타 충격파, 울분 가득이면 차지 3단 즉시. 울혈 규칙만 live:false.
  - **단검 백귀**: 그림자 걸음 쿨 0.5초, 기폭마다 분신 3체. 비도·열풍 규칙 live:false.
  - **활 유성**: 3초마다 자동 화살비, 완벽 놓기마다 하늘에서 1발 추가. 필중 규칙 live:false.

**'원한' 정정 (중요)**
- 코드상 'grudge1~3'은 **대검 울분(鬱憤) 자원 단계 오버레이**입니다. '원한'이 아닙니다.
  - 울분 비율 1~33% / 34~66% / 67~100%가 1·2·3단계입니다(`PlayerGauges.ts:182-184`). 칼의 대응물은 검기 `_ki1~3`입니다(:167-172).
- 코드에서 '원한'은 서사 쪽 이름입니다. **'원한의 한마디'**(무기 목소리 STORY `voice`, 런당 장면 1회: 첫 처치·위기·보스 앞·보스 처치)로 쓰이며, 성장 단계와 무관합니다(`StoryHud.ts:54`, `narrative.json:4`).

**이중 개성** (`dualTraits.json`, `evolveSlots.ts:92-133`)
- **원래 규칙**: 갈래 + 짝 태그 2점(1단) 또는 4점(2단)이면 다음 보상 3지선다 1칸이 확정 등장합니다. 태그 점수는 주지 않습니다.
- **1층 규칙(흡수)**: `absorbOnFloors:[1]`. 1단을 고르는 순간 일반 짝이 자동으로 붙고, 취기 짝은 취기 2점에 도달하는 순간 자동으로 붙습니다(`BuildRuntime.ts:414-427`).
  - 이때 보이는 것: notice '{갈래} 강화 — {이름}: {설명}' + `dual_trait_get` fx.
- **수량**: 1단 짝 12개(일반 8, 취기 4), 2단 짝 5개는 live. 2단 제안 짝 11개는 `live:false`.

## 3. 플레이어가 보는 것 (단계별)
1. **HUD**: 전투 묶음 맨 아래 2px 진행선만 있고 숫자는 없습니다. 가득 차면 강조색이 됩니다(`CombatHud.ts:248-266`).
   - 수치는 Tab 빌드 보기('개성 n/max', `BuildPeek.ts:61`)나 일시정지 일기장(`PauseScene.ts:150`)에서만 보입니다.
2. **임계 도달**: 게임이 멈추고 카드 3장이 뜹니다.
   - 제목: '손이 먼저 알았다 — {무기} · 개성 {임계}'. 머리표: 〔갈래 A〕〔갈래 B〕〔강화〕〔피의 계약〕〔각성〕.
   - 카드에는 갈래 설명·태그가 나오고, 하단 문구는 '한 번 고르면 되돌리지 않는다. 강화는 세 번까지.'입니다(`story.json:152-157`, `textBuild.ts:116-125`).
3. **갈래 선택 후**:
   - 화면 연출(`screenFx.evolve`)과 가운데 배너('사무라이 칼 · 선풍 (旋風)')가 나옵니다.
   - 자막은 `evolutionLine`입니다. byName 표에 없는 이름(선풍·투구가르기·명경 등)은 '손이 먼저 알았다. {이름}.'으로 나옵니다.
   - 효과음 evolve가 나고, 4동사 키캡 칸 이름이 갈래 이름으로 바뀝니다(`verbs.ts:14-28`).
   - 이어서 이중 개성 notice가 뜨고, 세트 단계가 오르면 notice + `set_flash`가 나옵니다.
4. **강화**: 배너 '…+n'과 자막 `STORY.reinforce[n]`이 나옵니다.
5. **각성**: 배너, 자막 '만월 — …', 각성 순간 fx 이후 외형 오버레이가 켜집니다.
   - 주의: `BuildMenus.ts:196`의 EventBus 경로(`UiRelay.ts:157`)와 :197의 직접 `__system.emit` 때문에 UI `WEAPON_EVOLVED`가 두 번 나갈 수 있습니다. 배너 중복 가능성이 있어 확인이 필요합니다.

## 4. 무기·fx 외형 변화 지점 (`assets/sprites/weapons/v3`, `fx/v3`)
**무기 위에 겹치는 순서**: 무기 → `_awaken` → `_ki`/`_grudge` (`WeaponOverlay.ts:63,324-383`).

| 무기 | 영구 외형 | 자원 오버레이(일시) | 갈래 = 새 동작 시트 | 갈래 fx 교체 | 각성 |
|---|---|---|---|---|---|
| 칼 | 기본 / 각성 | 검기 ki1~3 (60장. 명경 4~5단은 시트 없음 → 칼날 틴트 대체) | katana_spin(선풍)·guardbreak(투구) | fall → fall_wide | 오버레이 20장, 궤적 9종, `katana_awaken_in` |
| 대검 | 기본 / 각성 | 울분 grudge1~3 (66장) | leap_slam(파쇄)·brace_upswing(중압) | 균열 → shatter | 오버레이 20장, 궤적 4종 |
| 단검 | 기본 / 각성 | 없음 | fan_throw(질풍) | combo3 → combo3_double | 오버레이 11장, 궤적 4종(+갈래·각성 합본) |
| 활 | 기본 / 각성 | 없음 | rapid_loop(속사) | aim_charge → quick | 오버레이 9장, 궤적 3종 |

- 갈래는 **무기 모양을 바꾸지 않습니다**. 새 동작 그림과 fx만 바뀝니다.
- 따라서 무기의 영구 외형 변화는 무기마다 **1회(각성)**이고, 이것은 런에서 도달할 수 없습니다.
- 2단 갈래 fx 16세트와 각성 시그니처 4종(`katana_fullmoon` 등)도 시험장에서만 보입니다.

## 5. 처음 하는 사람이 겪을 문제 (코드·UI 문구 기준)
1. **'개성'이라는 말이 여러 뜻으로 겹칩니다.**
   - 시작 의식의 '개성 선택'(3획으로 무기 결정, `ResultScene` '영혼 → 개성 선택')과 무기 성장 수치가 같은 단어입니다.
   - 패시브 '개성 각성'(개성 2배)과 '최종 각성'도 겹칩니다(`passives.json` `_rename` 메모).
   - '개성 발현'이라는 말은 UI에 전혀 없고, 메뉴 제목은 '손이 먼저 알았다'입니다.
2. **임계가 거의 보이지 않습니다.** 2px 진행선뿐이고 숫자가 없습니다. 임계가 100→200으로 바뀌고, 고르면 0이 된다는 안내도 없습니다. 노드 보상 이름 '획 자국'만 보고는 개성 보상인지 알기 어렵습니다.
