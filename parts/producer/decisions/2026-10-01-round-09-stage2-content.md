### Q1. 1층 보스 설계 (플레이스홀더)
- 선택지: 2페이즈 돌진 → 투사체 추가 (추천) / 1페이즈 돌진만 / 다른 설계
- 결정: **2페이즈**. 1페이즈: 예고 후 돌진, 벽 충돌 시 경직(파훼 창). 2페이즈(HP 50%): 돌진 후 부채꼴 투사체 + 주기 발사. HP 200, 접촉 20, 돌진 25, 투사체 10. 수치는 `data/bosses.json`.

### Q2. 전투 시련 적 구성
- 선택지: 일반 적 3종 지금 추가 (추천) / dummy 1종 웨이브만 / 2종
- 결정: **3종**. dummy(직진 근접), archer(거리 유지 + 투사체), charger(예고 후 돌진). 시련마다 웨이브 2회: [dummy×3], [dummy×2, archer, charger]. `data/stages.json`.

### Q3. 방 그래프 형태

- 결정: **열린 구조**. 시련 4개는 어떤 순서로든 가능, 4개 클리어 시 보스 문 해금. 인접한 방끼리 추가 연결(확률 0.3)로 루프 생성.

### Q4. 코드 품질 도구

- 결정: **vitest + ESLint + Prettier**. `npm run test | lint | format`. 세션 훅의 npm install 로 함께 설치.
