# 2026-10-02 · 51라운드 · 데모 v19 플레이 피드백

### 1. 획 연출 (원문)
"획을 기반으로 진행하는 거는 얼추 괜찮은데 뭔가 획이 너무 두껍고 부드럽지가 않아. 픽셀이 더 세분화되고 나눠져서 곡선에도 엄청 매끄러운 연출이 가능했으면 좋겠어."
- 반영: 획을 더 가늘게, 고해상도 렌더(픽셀 세분화)·곡선 보간(스플라인)으로 매끄럽게.

### 2. 회피 시험 (Q1)
- 원문: "13초부터 너무 괴랄해서 … 좀 더 회피 능력을 테스트하는 방향으로 15초라는 시간에 제한 받지 않고 재디자인"
- 결정: **짧은 과제 5개를 차례로 (추천)** — 예고선 피하기 → 조여오는 고리 틈 빠지기 → 유도탄 따돌리기 → 대쉬 무적으로 탄막 통과 → 종합. 각 4~6초, 읽으면 피할 수 있게, 과제별 피격으로 등급(시작 감각 보상 유지).

### 3. 튜토리얼
- 원문: "튜토리얼에서는 너무 맵이 좁고 설명이 잘 드러나지가 않아. 플레이어에게 플레이 방식 설명을 좀 더 전달력 있게 해주고, 그리고 몬스터가 나올거면 주의하세요 이런 문구라도 띄워줘."
- 반영: 튜토리얼 전장 확대, 안내를 화면 중앙 큰 패널(키 아이콘 + 짧은 문장)로, 적 등장 전 "주의" 경고.

### 4. 무기 (Q2·Q3·Q4)
- 원문: "무기들의 공격 속도가 너무 차이가 없고 빠르기만해서 특징을 잘 살리는 방향 … 활은 이제 산탄 빌드는 그냥 없애고 나중에 화기류가 나오면 그때 적용하고 지금은 속사 혹은 원거리 저격(거리 멀수록 데미지 증가) … 개성 발현이 됨으로써 기본 공격에서부터 뭔가 이펙트가 개성이 두드러지도록"
- Q2 활 갈래: **속사 갈래 + 저격 갈래 둘 다 (추천)** — 산탄(확산·비) 갈래 삭제(화기류 도입 시 재사용), 속사 = 연사 속도↑·탄창↑, 저격 = 조준 사격 거리 비례 피해↑·관통.
- Q3 템포: **대검 느림 · 칼 보통 · 단검 빠름 · 활 충전 (추천)** — 대검 3연격 약 2초(예비 동작 길게, 한 방 큼), 칼 약 1.1초, 단검 약 0.5초(가열 시 더 빠름), 활은 시위 당기는 시간이 보이게. 느릴수록 한 방 피해 큼.
- Q4 휴대 재미: 결정(원문) "**뽑는 첫 타 보너스와 넣은 채 회복되는 기능은 좋고 그렇다면 넣기 뽑기 키를 따로 만들자 f 키로**" — F = 넣기/뽑기. 넣은 상태 첫 타 보너스(칼 발도 = 치명 확정, 대검 끌어내기 = 크게 밀쳐냄), 넣은 동안 기력 빠른 회복. (넣은 상태 이동 속도·뽑은 상태 방어 보너스는 추천 2안 내용이라 미채택.)
- 개성 발현 시 기본 공격 이펙트도 갈래별로 달라지게.
