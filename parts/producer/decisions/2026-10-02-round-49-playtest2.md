# 2026-10-02 · 49라운드 · 2스테이지 플레이 피드백 + Gemini 도입

도영 님 원문 요지: "2스테이지까지 플레이했는데, 지금까지의 내용으로 스테이지별 테마를 이미지로 구축하고 싶어 … 1스테이지 내에서 이동하는 과정을 '잔'의 심층부로 가는 듯한 지도를 펼친 느낌으로 … 작은 스테이지에서도 해당 지역에 존재한다는 느낌을 주는 타일과 구조물 … 제미나이 open api키를 만들고 자유롭게 사용하도록 하고 싶어" + 플레이 피드백 1~7 (아래).

## Gemini 도입 (아트 이미지 생성 보류 해제)
### Q1. 사용 범위
- 결정: **테마 키아트·지도 일러스트·배경까지, 게임 도트는 직접 (추천)** — 스테이지별 테마 이미지, '잔' 심층부로 가는 펼친 지도 일러스트, 노드 전투장 원경 배경은 Gemini 생성 후 LOPAD 팔레트로 보정. 캐릭터·적·무기·타일·구조물 도트는 직접 찍고 Gemini 이미지는 참고 자료.
- 키: 도영 님이 Google AI Studio 에서 발급 → 클라우드 환경 편집의 **API 자격 증명**으로 등록(허용 웹사이트 `generativelanguage.googleapis.com`, 헤더 `x-goog-api-key`, 접두사 없음). 프록시가 붙이므로 세션은 키를 보지 않는다. 채팅에 노출된 키는 폐기 권고. `generativelanguage.googleapis.com` 접속은 확인됨. 키가 들어오기 전까지 Gemini 작업은 대기.

## 피드백 반영
### 1. 획 연출
- 원문: "획을 긋고 발광하는 연출은 좋으나, 뭔가 부스러기가 떨어지는 연출도 좋을 것 같음. 그리고, 획을 다 그은 이후에는 다음 15초 회피 시험으로 가기 전에 화면이 살짝 흔들린 이후 해당 획에서 빛이 터져나오는 연출"
### 2. 회피 시험 → 체급 보상 (Q2)
- 원문: "멀리서 피하거나 … 개성을 정하는 것은 좋지 않은 것 같음. 차라리 초반에 감각 수치를 어느 정도 부여하는 등의 기본 체급과 관련된 보상 … 지금보다 더 난이도가 있으면 … 서있는 공간도 매번 새롭고 공간 자체가 점점 갉아먹혀서 좁아지는 것"
- 결정: **버틴 시간·피격 수로 등급 → 시작 감각 +0~3 (추천)**. 무기는 **3획만으로** 결정. 난이도 상향, 경기장 모양 매번 무작위 + 시간에 따라 가장자리부터 갉아먹혀 좁아짐.
### 3. 탄생 · 튜토리얼 (Q7)
- 원문: "너무 생뚱맞은 공간에서 태어나는 느낌 … 튜토리얼 지역(황폐화된 전장)에서 영혼이 뭉쳐져 태어나는 느낌"
- 결정: **탄생 후 조작 안내 + 허수아비·약한 적 (추천)** — 부러진 무기·깃발·쓰러진 병사의 흔적이 남은 전장에서 혼불(영혼)이 모여 태어남, 땅의 표식으로 이동·공격·대쉬·보조 동작 안내, 허수아비·약한 적, 끝나면 출구.
### 4. 무기 휴대 (Q3·Q5)
- 원문: "무기 자체를 가지고 있다는 느낌이 너무 적음 … 늘 손에 쥐고 다니는 무기와 등 허리에 차고 다니는 무기를 구별할 것"
- 결정: **칼 = 허리 칼집(뽑아 베고 일정 시간 뒤 납도) · 대검 = 등(두 손으로 끌어내 휘두름) · 단검 = 손(역수) · 활 = 손 (추천)**
### 4-2. 바닥·지역 (Q8)
- 원문: "바닥 … 컨셉이 잘 드러나지 않음. 지금은 뭔가 한 건물 안에서 움직이는 듯한 느낌. (내가 원하는 느낌은 황무지에서 술의 제국 안으로 입성하고 술 제국의 외곽 거리부터 천천히 파헤쳐 나가다가 '잔'의 지배자에게 찾아가 술에 잔뜩 취한 보스를 잡아내는 것.)"
- 결정: **여정(황무지·전장) → 성문 → 외곽 거리 → 양조 구역 → 지배자의 연회장 (추천)** — 노드 단계마다 바닥·가장자리·소품·배경이 바뀜. 실내가 아니라 하늘이 트인 거리, 외벽 대신 담·잔해·건물 앞면으로 두름.
### 5. 무기 동작·자원 (Q4·Q6)
- 원문: "무기의 움직임이 너무 단순함 … 대검이라면 두손으로 잡고 크게 휘두르고 그만큼 더 뭔가 기력을 소비해서 잠시 이동이 제약 … 개성이 발현된 이후 충격파를 가하는 경우에는 대검을 내리쳐야하는 이미지 … 마우스 위치 방향으로 살짝 도약하며 내려찍는 느낌 … 대쉬 공격은 … 뛰면서 대검으로 밴다면 훙 휘두르고 잠시 공격을 하기 위해 대기 … 무기 테스트용 탭을 만들고 무기들의 개성 발현을 마음대로 브랜치를 띄우고 고를 수 있도록 해줘. 중앙에는 허수아비와 투사체를 일정한 방향으로 쏘는 허수아비 2개체"
- 결정(원문): "**대검과 칼은 기력 기능, 활은 화살 탄창 기능, 단검은 과열 기능**을 만들어보자. (단검은 연격 초반보다 후반 갈수록 연격이 가열되고 공격속도가 빨라지는 느낌)"
- 무기 시험장: 타이틀에서 진입, 무기·진화 갈래 자유 선택, 중앙 허수아비 1 + 일정 방향으로 투사체를 쏘는 허수아비 2.
### 6. 노드 지도
- 원문: "계단이 놓여져 있는데 이것 보다는 앞으로 나아간다는 느낌 … 입체적으로 맵을 표현하고, 넘어가시겠습니까? 이런 문구 … 음소거 키를 esc에서 설정하는 것으로 넘기고 m을 눌러서 현재 위치와 위치에 대한 정보 그리고 지도를 펼칠 수 있도록 … 특성이 있는 노드들로 들어가는 경우에는 맵 중앙에 그 기능이 위치"
- 결정: 여정 아이콘 교체(앞으로 나아가는 길), 지도 입체 표현(펼친 지도 일러스트는 Gemini 키 후), 노드 확정 전 "넘어가시겠습니까?" 확인, **M = 지도 + 현재 위치·위치 정보**, 음소거는 Esc 메뉴 설정으로 이동, Tab 은 M 과 같은 지도(보조). 특수 노드(상점·휴식·이벤트) 기능은 전투장 중앙.
### 7. 구조물
- 원문: "노드 중간에 위치하도록 하고, 너무 생뚱맞게 있기보다 맵과 조화롭게 … 구조물 팀과 맵 디자인 팀의 상호 작용이 필요"
- 결정: 노드 전투장을 **세트 배치(set-piece)** 로 설계 — 노드 종류·지역별 중앙 광장 배치(예: 휴식 = 모닥불 광장, 상점 = 노점 거리 한가운데), 주변 소품·바닥 무늬가 구조물을 감싸도록. 시스템(배치)·아트(지역 타일·소품) 공동 계약 art §7.3.
