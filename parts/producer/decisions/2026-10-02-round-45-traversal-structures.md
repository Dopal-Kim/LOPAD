# 2026-10-02 · 45라운드 · 비전투 이동(달리기·워프)과 테마 구조물 초안

배경: 도영 님 — "지금 맵이 너무 넓고, 비전투 기간에 움직이기 너무 힘들어 워프 수단이나 달리기 기능 구현해. 그리고 맵 내부에 넣을 테마별 상호작용 가능한 구조물 여러 초안들 작성해줘. 기획서에 언급한 게임들 참조해서 아이디어 구현해."
참고 게임(GDD 1장): 메가봉크, 테라리아 인페르노, 타이탄 소울, 할로우 나이트.

### Q1. 비전투 이동 수단
- 선택지: 달리기 + 워프 둘 다 (추천) / 달리기만 / 워프만
- 결정: **달리기 + 워프 둘 다**
- 비고: 시스템 파트 구현. 방 크기 80×48(32라운드)은 유지.

### Q2. 달리기 방식
- 선택지: 비전투 중 Shift 홀드 1.8배 (추천) / 비전투 1초 이동 시 자동 1.6배 / 전투 중에도 Shift 1.4배
- 결정: **비전투 중 Shift 누르는 동안 1.8배**
- 비고: 전투 중(시련·보스 진행 중)에는 무효. 발밑 먼지 잔상. 세부(가속 시간, 대쉬와의 관계)는 시스템 임시값.

### Q3. 워프 방식
- 선택지: 클리어한 방마다 봉인석 + 그 앞에서 미니맵 선택 (추천) / **비전투 중 어디서든 미니맵 열고 클리어한 방 선택** / 층당 정류장 2~3곳
- 결정: **비전투 중 어디서든 미니맵을 열고 클리어한 방을 선택**
- 비고: 추천안이 아닌 선택. 미니맵 선택 화면은 UI 파트, 워프 실행·가능 방 목록은 시스템 파트 → 계약 `ui-system-interface.md` 에 추가(아래 계약 변경).

### Q4. 테마별 상호작용 구조물 초안 범위
- 선택지: world-bible 열람 승인 + 공통·8층 테마 초안 문서 (추천) / 열람 + 문서 + 대표 2~3종 시제품 / 열람 없이 공통만
- 결정: "일단 1~2층 우선적으로 제작하자. world-bible 열람 승인하고, 1~2층 위주로 테마 초안 문서 제작해"
- 비고: **1~2층 위주 초안 문서**(구현은 검수 후). 시스템 파트가 작성(`parts/system/structures-draft.md`), 승인 #11 로 `parts/story/world-bible.md` 읽기.

## 계약 변경 (Q3 에 따름)
- `UiSnapshot` 에 비전투 여부와 워프 가능 방 목록, UI→시스템 워프 요청 명령을 추가한다. 정확한 필드명은 시스템이 `contracts/ui-system-interface.md` 에 먼저 적고 UI 가 그 문서만 보고 구현한다.
