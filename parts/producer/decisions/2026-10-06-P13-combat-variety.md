# P13 전투 다채롭게 — 개성 전투 양상·칼/단검 재디자인·보스 기둥 숨기·드랍 그림 (61라운드 단계 5, 프로듀서 결정)

## 도영 님 피드백 (데모 버전 7, 원문)
> 사무라이칼이랑 단검이 특히 디자인이 너무 아쉬운 것들이 좀 있어서. 좀 더 새롭게 바꿔보고, 보스 진행은 괜찮은데 벽 기둥 뒤에 있으니까 너무 쉽게 잡는다. 개성 발현을 더 가독성 좋게 한 건 좋아. 근데 전투를 좀 더 다채롭게 만들고 싶어. 개성에 따라서 전투 양상도 더 특색 있게 달라지는 방향으로 기존의 개성을 디벨롭하고 해당 개성과 어울리는 이미지를 구현하자. 항상 무기와 무기 이펙트는 같이 디벨롭하고. 지금 전표랑 물약이 드랍되면 아직 초록생이랑 노란색 사각형인데 이거 수정해. 제미나이 API 써도 문제 없으니 계속 진행해. 다른 목표들도 진행하자.

- 확인(유지): 보스 진행 흐름, 개성 발현의 가독성(P12 UI).
- 상시 원칙(새): **무기 그림과 무기 이펙트는 항상 함께 작업한다** — 한쪽만 바꾸는 작업 지시를 내지 않는다.
- Gemini 범위 확대: 개성 카드 그림·드랍 아이템 그림·무기 콘셉트 참고(루트 CLAUDE.md §4 갱신). 게임 도트는 팔레트 보정.

## 1. 개성 → 전투 양상 (시스템·아트·음향·UI)
개성 56장(무기당 8 + 갈래 2×3)을 다시 다듬는다. 기준:
1. **보이는 새 행동**: 개성 하나가 화면에서 구별되는 새 행동을 만든다 — 새 공격 모양(파동·사슬·회오리·낙하), 새 이동(되돌아오기·끌어당기기·뛰어넘기), 적 상태 변화(띄움·묶음·서로 부딪힘·끌려옴), 분신·소환물, 환경 상호작용(술 웅덩이 점화·술통 터뜨리기·촛불·벽에 박기).
2. **환경과 엮기**: 1층의 술 웅덩이·불·술통·기둥과 연결되는 개성을 무기마다 2장 이상.
3. **고유 그림**: 개성마다 ① 카드 그림(아이콘, Gemini 콘셉트 → 도트 보정) ② 발동할 때 보이는 전투 이펙트(전용 fx 또는 기존 fx 의 뚜렷한 변주) ③ 짧은 발동음. 숫자만 다른 개성 금지.
4. **조합의 맛**: 같은 태그 개성 2장 → 두 개성이 엮이는 '공명' 효과 하나(무기마다 태그 2~3개 조합만, 과하지 않게).
5. 카드 문구는 '조건 → 행동' 한 문장 그대로, 수치 금지.

## 2. 칼·단검 재디자인 (아트 — 무기+이펙트 함께)
- 대상: 기본 무기 그림(손에 든 모든 동작 시트), 연격·시그니처·대쉬 공격·고유 기술의 휘두름 이펙트, 맞음 이펙트, v4 각성 외형(갈래 3 × a1/a2)까지 한 디자인 언어로.
- 방향: 칼 = 얇고 긴 날의 날카로운 실루엣, 날끝에서 끌리는 가는 빛줄기와 종이 베이는 듯한 직선 궤적(굵은 반달 덩어리 지양). 단검 = 손에 감기는 짧은 곡선 날, 빠른 X·찌르기 섬광, 잔상은 짧고 많게(뭉툭한 원뿔 지양). 데드셀 수준 밀도·프레임.
- 틀·프레임 수·ms·판정 앵커는 가능하면 유지(시스템 수정 최소). 바꾸면 메타에 명시.

## 3. 보스 기둥 숨기 방지 (시스템·아트)
- 기둥은 금 3단 다음 충돌에서 **무너진다**(잔해 — 낮은 장애물·통과 가능, 무너짐 그림·소리). 3단에서 멈추던 판단(단계 3)을 바꾼다.
- 플레이어가 기둥 뒤에 1.5초 넘게 가려 있으면 만취가 **포물선 술병 던지기**(벽 넘어 낙하, 착탄 원 예고)로 몰아낸다. 길 찾기는 기둥을 돌아오게.
- 목표: 기둥은 잠깐의 피난처이지 이기는 방법이 아니다.

## 4. 드랍 그림 (아트·시스템)
- 전표·물약(+화염 술병 등 바닥에 떨어지는 줍기 물건 전부)의 사각형 자리표시를 도트 그림으로: 바닥 그림자, 반짝임 루프, 자석 흡수 때 늘어남, 획득 팝.

## 5. 다른 목표 (계속)
- 1층 실제 길이 보정(런 로그), '원격' 태그 1층 표시 버그, 성장 처음 안내 메타 기록, stageIndex 배선 정리, 기둥 무너짐 소리(기존 break_pillar 의 와르르를 무너짐 쪽으로).
