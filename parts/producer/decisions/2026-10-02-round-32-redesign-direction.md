# 2026-10-02 · 32라운드 · 디자인 전폭 수정 방향 (해상도·맵·UI)

### Q1. 내부 해상도
- 선택지: 960×540 (추천) / 640×360 유지 + 방만 크게 / 1280×720
- 결정: **960×540**. 창 크기에 맞춘 정수 배율 유지(1920×1080 = 2배, 1280×720 = 1배).

### Q2. 방·맵 크기와 카메라
- 선택지: 방 확대 + 카메라 추종 (추천) / 방 수 증가 / 둘 다
- 결정: **방 확대 + 카메라 추종**. 방 한 칸을 화면보다 크게, 카메라는 플레이어를 부드럽게 따라감. 복도도 길고 굽게.

### Q3. UI 재설계 범위
- 선택지: 전폭(아트 팔레트·일기장 컨셉) (추천) / 레이아웃만 / 전폭 + 픽셀 폰트
- 결정: **전폭 재설계** — 무채색 팔레트 + 층 강조색, 종이·잉크·일기장 질감. 아트 파트가 UI 타일(패널 틀·아이콘·게이지)을 그리고 UI 파트가 적용. HUD 는 가장자리로 밀어 시야 확보. (픽셀 폰트는 이번 범위 밖)

### Q4. 주인공 스프라이트 크기
- 선택지: 16×24 유지 (추천) / 24×36 재제작
- 결정: **16×24 유지** (28라운드 변경 금지 유지). 기존 시트 전부 유지.

### 작업 순서(프로듀서 제안)
1. 시스템: 해상도 960×540, 방 확대(셀 크기 상향)·카메라 추종, 리듬 단계 하얀 점, 조준 사격 차지 유지→떼면 발사, 소품·스폰 규칙 재조정.
2. 아트: UI 키트(패널 9-slice·게이지·아이콘·일기장 텍스처) → 계약 `contracts/ui-art-kit.md`.
3. UI: 새 해상도 레이아웃 + UI 키트 적용 + 31라운드 문구 채택.
4. 아트: 층별 전용 보스·타일셋(31라운드 3항) — 이후 묶음.

### Q5. 방 한 칸 크기
- 선택지: 80×48 타일 (추천) / 60×34 / 120×68
- 결정: **80×48 타일** (1280×768px, 화면 960×540 의 약 1.3×1.4배). 시련 적 수·소품 수는 면적 비례 재조정(시스템 임시값 → 기록).
