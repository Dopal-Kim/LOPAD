# P17 — 62 루프 3: P0 3건·새 지도 이동 지원·결 정리 (프로듀서 결정, 전권 위임)

근거: `review-2026-10-12-stage1-loop3-audit.md`(평균 4.5 → 6.2), 도영 님 추가 지시(지도에서 고르기 + 키아트 미리보기 — §25 로 반영됨).

## 묶음 A — P0·회귀 (반나절)
- P0-1 타이틀 로고가 메뉴가 열리면 멈춤(`introT` 가 intro·prompt 에서만 진행) → 로고 쓰기·부제·무기 불씨는 phase 와 무관하게 끝까지, 돌아온 타이틀은 완성 상태로.
- P0-2 장터 1번 노점 E 가 옛 '외상 장부' 구조물을 엶 → 장부 구조물 제거(외상은 상인 대사만), E 대상 우선순위 = 화면 프롬프트와 같은 규칙(가장 가까운·프롬프트에 보이는 것).
- P0-3 보스 국면 카드와 파훼 카드 같은 자리 겹침 → 파훼는 보스 HP 막대 위 칩, 국면 카드 레인 독점.
- 개성 획득 배너·토스트 같은 문장 두 번 → 하나로. 세트 배너 '+20%' 등 수치 제거(용어집 카드 문장 규칙).
- favicon 404(유일한 콘솔 오류) 제거. 사연 방 NPC 자리 궤짝 프롬프트 겹침 정리. 지도가 열린 채 이동되는 경우(디버그) 대비 fade begin·ROUTE_NODE_ENTERED 때 지도 닫기.

## 묶음 B — 새 지도 이동 지원
- 노드 지도 가독성: 주인공 표식 = `ui/map_marker_ghost`(먹 붓 망령), 갈 수 있는 곳 강조(굵은 테·맥박), 한 글자 표식이 마름모와 겹치지 않게, 지나온 길 흐리게.
- 미리보기 그림: 지역 키아트 5장 + 노드 종류(사연·장터·쉼터·정예·군주의 방) 그림이 지역마다 다르게 보이도록 — 기존 입구 그림 paint/door_<지역>_<종류> 가 없는 조합을 채운다(아트), 작은 카드용 밝기 보정판.
- 로딩 카드 액자 빈칸 폴백(키아트 없을 때 지역 색 종이)·선로드. 'fade' 소리 `sfx/transition_fade`(음향).

## 묶음 C — 결 정리
- 돌바닥 방의 칸 모양 빛 판 제거(조명), 전투장 엄폐 벽 섬 → `pillar_stone` 3면 구조물로 교체(QuarterView), 회피 시험 무대 조명·가운데 정렬, 기억 장 장터·몸 칸 아이콘(먹물·풀무·체력·공격·대쉬 5장)과 '빈손' 그림.

## 묶음 D — 아트 병행(길게)
- 보스 시트 재도트(월드 밀도), 단검·활 궤적 스미어, 칼 갈래 시트용 스미어. 새 개성 8장('떠올릴 개성')은 그림·효과가 같이 필요 — 루프 4.
- 패드는 '완벽' 컨펌 직전 마지막.

## 진행
- 병행: UI H(A·B UI 몫) / 시스템 I(A·C 시스템 몫) / 아트(B 그림·C 아이콘 → 이어서 D 보스) / 음향(fade 소리).
