## 1. 아트 (28라운드 1~5단계, 결정 A·D·G·J)
1. 팔레트: 1·4·6층 난색 분리(호박/겨자/맑은 노랑), 무채색 청색 기운 b*=-3 — 유지?
2. 주인공 디자인(케틀햇·붕대·검은 외투·호박 눈빛 한쪽·허리 일기장), 사망 시 일기장만 호박색으로 남는 연출.
3. 1층 바닥 톤(석판 G04 + 줄눈 G02), 출구 계단에 호박 4px 예외, 상점 2×2 '술 좌판'.
4. 적 3종 실루엣(징집병 술통 갑옷 / 사수 삼각모 화승총 / 결사병 통 투구·파비스·망치 24×24).
5. 무기 오버레이 48×48 실체화 연출(호박 윤곽→쇠→불티), 활은 고정 전방 위치(활 전용 주인공 프레임은 미제작).
6. 보스: 양조장주(통나무 망치 공성추, 양눈 호박) / 황제(무채 외투, 눈·훈장만 강조). **2~7층 보스는 1층 보스 시트 + 층 램프 스왑으로 대체 중** — 전용 시트 제작 여부.
7. 2차 진화 16종 이펙트는 1차 재사용 중 — 전용 제작 여부. 2층 이후 타일셋 미제작(플레이스홀더 격자).

## 2. 스토리 (결정 B)
1. 2차 진화 정식 이름 3건: 만월(滿月)·허보(虛步)·급소(急所).
2. 적 이름: 징집병·사수·결사병 (게임 표시 이름으로 이미 적용).
3. 진화 자막 20종·메뉴 한 줄 24종·강화 자막 3줄 — 검수.
4. **보류 중 UI 문구**: '런 클리어'→'한 생을 다 썼다', '타이틀로'→'일기장을 덮는다', 일시정지 제목 '일기장'. 채택 여부.
5. 엔딩 메뉴 제목 "황제가 쓰러졌다. 평(平)을 —" (시스템 임시 문장) — 스토리 파트 정식 문장 필요.

## 3. 시스템 (결정 27라운드 임시값·C·H·K)
1. 우클릭 수치: 가드 이동 0.35·밀쳐내기 2.5칸 / 그림자 걸음 사거리 6칸·쿨 2초·확정 치명 1초 / **조준 사격은 차지 0.6초 완료 시 자동 발사**(떼면 발사 아님) — 해석 확인.
2. 2차 효과 임시값(잔월 1초 틱, 중압 경직 400ms, 거인 슈퍼아머=공격 중 피해 50% 감소 근사, 추적 240°/s 등).
3. 애니: 공격 애니 길이 = 무기 쿨다운, 사망 후 +400ms 결과 화면, 그림자 알파 0.35, 소품 배치 규칙(방당 2~5, 문·시작점 회피), 개체-소품 가림 미구현.
4. 오디오: 버스 SFX 0 / BGM -8 / 보스전 -3 dB, 일시정지 -6 dB, 결과 화면 무음, 엔딩 선택음 = fate_decided 재사용, 마지막 시련은 boss_unlock 만.
5. 새 devDependency `@types/node`(vite 플러그인 타입). 승인 여부.
6. `data/palette.json` 은 `parts/art/palette/lopad.json` 사본(동기화 책임: 프로듀서).
