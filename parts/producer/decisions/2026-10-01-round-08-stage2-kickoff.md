# 2026-10-01 · 8라운드 · 2단계(핵심 루프) 개시

도영 님: "프로토타입에는 문제가 없고 지금부터 정식 게임 출시를 위한 수준으로 디벨롭."

### Q1. 2단계 범위
- 선택지: 무작위 맵 1층 + 시련 + 보스 + 사망/재시작 (추천) / +대쉬 / +대쉬+패링 / 맵 생성만
- 결정: **기획서 2단계 그대로**. 대쉬·패링은 3단계.

### Q2. 방+복도형 맵 생성 방식
- 선택지: 방 템플릿을 그래프로 연결 (추천) / BSP / 손으로 만든 고정 맵
- 결정: **방 템플릿 + 그래프 연결**. 셀 격자(셀 = 화면 하나) 위에 방을 트리로 배치하고 복도로 연결.

### Q3. 1층 구성
- 선택지: 시작1+시련3+휴식1+보스1 (추천) / 시작1+시련4+보스1 / 시작1+시련2+보스1
- 결정 (Other 성격): **시작 1 + 전투 시련 4 + 휴식 1 + 보스 1**. 시련 수는 `data/stages.json` `trialCount`.

### Q4. 맵 크기와 카메라
- 선택지: 방 단위 고정 카메라 (추천) / 큰 연속 맵 + 추적 / 방은 고정, 보스 방만 더 크게 + 추적
- 결정: **방은 고정 카메라, 보스 방만 2×2 셀 크기 + 추적 카메라**.
