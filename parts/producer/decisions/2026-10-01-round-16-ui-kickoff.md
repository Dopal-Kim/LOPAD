# 2026-10-01 · 16라운드 · UI 파트 개시

### Q1. UI ↔ 시스템 교차 참조 범위
- 결정: **계약 문서만**. `contracts/ui-system-interface.md` 에 UI 가 구독할 이벤트·페이로드, 읽기 전용 상태 스냅샷, UI → 시스템 명령을 정의. 시스템 파트는 `src/contract/ui.ts` 어댑터로 계약을 구현하고, UI 파트는 그 파일만 import 한다 (ESLint 로 강제).

### Q2. 화면 목록
- 결정: **타이틀 → 메타(강화·도감) → 개성 선택 → 게임(HUD) → 일시정지 / 보상·상점 오버레이 → 결과**. 타이틀에 이어하기/새 런. 임시 텍스트 메뉴는 전부 정식 화면으로 교체.

### Q3. HUD
- 결정: **체력바 · 골드 · 물약 · 층/시련 진행 · 무기명+개성 게이지 · 보스 체력바(보스전) · 미니맵(방 그래프)**. 패시브·감각은 일시정지 화면. 병렬 UI 씬.

### Q4. 조작키
- 결정 (Other): **현재값 확정** — WASD 이동, 좌클릭 공격(커서 방향), 우클릭 보조 동작(현재 패링), 스페이스 대쉬, Q 물약, Esc 일시정지, 메뉴 숫자/방향키+Enter·마우스.
- **도영 님 추가 지시: 우클릭 기능은 무기마다 다양하게 바꿀 예정.** 계약에서는 우클릭을 '보조 동작(secondary)'으로 일반화하고, 현재 무기의 보조 동작 이름을 스냅샷에 포함한다. 무기별 보조 동작 설계는 시스템 파트 후속 인터뷰.
