# 2026-10-02 · 34라운드 · UI 글꼴

### Q1. 글꼴
- 선택지: Galmuri 본문 11px + 제목 14px (추천) / Galmuri 본문 14px / monospace 유지 후 직접 업로드
- 결정(원문): **"Galmuri 채택하되, 지금 한자 표기들은 깨지는 점에 유의해서 한자를 지우던가 표현하던가 정해"**
- 조사 결과(fontTools 로 글리프 확인): 게임 텍스트의 한자 63자 중 **Galmuri11 은 徵 1자만 없음**(게임 화면에 표시되지 않는 글자). Galmuri14·9 는 擊·步·虛(쌍격·허보)가 없고, Bold·Condensed 는 한자 전부 없음.
- 프로듀서 결정(지시에 따라 정함): **한자 표기 유지**. 규칙 — 한자가 들어갈 수 있는 모든 텍스트(무기·진화명, 층 제목, 자막, 메뉴 항목, 결과 줄)는 **Galmuri11**(필요하면 정수 배율 2배로 키워 배너용). Galmuri14 는 한자 없는 고정 제목(일기장·타이틀 메뉴 등)에만, Galmuri9 는 설명 줄(한자 없음 확인된 문구)에만. Bold 는 쓰지 않는다.
