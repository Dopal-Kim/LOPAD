### Q1. 보스 처치 후 전환 방식
- 선택지: 보스 방에 출구가 열림, 걸어서 진입 (추천) / 처치 즉시 자동 전환 / 결과 화면 경유
- 결정: **출구 열림, 걸어서 진입**. 보스 방 중앙 2×2 출구 타일. HP·무기·개성·감각·처치 수 유지.

### Q2. 스테이지 2~7 난이도·구성
- 선택지: 데이터 스케일 + 스테이지별 웨이브 표 (추천) / 배율만 / 스테이지별 새 적
- 결정: **데이터 스케일 + 웨이브 표** (`data/stages.json`). 스테이지 컨셉은 스토리·아트 파트 개시 후.

### Q3. 스테이지 전환 세이브
- 선택지: 지금 구현 (추천) / 다음 단계
- 결정: **지금 구현**. 전환 시 자동 저장, 런당 최대 2회(`run.maxSaves`), localStorage. 페이지 재진입 시 자동 이어하기(저장 시점 = 해당 층 시작). 사망·클리어 시 삭제.

### Q4. 스테이지 2~7 보스
- 선택지: 1층 보스 변형 + 최종 보스 3페이즈 (추천) / 전부 복사 / 보스별 새 패턴
- 결정: **변형 + 최종 3페이즈**. 2~6층은 수치·투사체 수·속도만 변경, 7층 최종 보스는 돌진 → 부채꼴 → 연속 돌진 3회 + 전방위 탄막 12발.
