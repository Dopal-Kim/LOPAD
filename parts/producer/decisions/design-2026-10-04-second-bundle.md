## 0. 전제

### 0.1 1층 노드 지도 (현행 + 가정)
- 48 Q9: 여정 3(황폐한 탄생지 → 버려진 길[쉬운 전투] → 국경 초소[휴식]) + 잔 제국 두 갈래 길 6(전투 3·상점 1·휴식 1·이벤트 1) + 보스. 한 판 7~8노드.
- 계약 §10.1: 노드는 `col`(진행 단계)·`row`(같은 단계 안 위치)·`links`. → **가정: 잔 구간 = 3단 × 2갈래, 단마다 1개를 고름 → 잔 3노드 + 보스 = 한 판 7노드** (숨은 노드를 찾으면 8).
```
 [탄생지]─[버려진 길 ⚔]─[국경 초소 ⛺]─┬─[잔 단1-a]─┬─[잔 단2-a]─┬─[잔 단3-a]─┬─[보스]
                                      └─[잔 단1-b]─┴─[잔 단2-b]─┴─[잔 단3-b]─┘
```
- 이 설계안이 쓰는 기호: ⚔ 전투 · ☠ 위험(엘리트 길·저주 길) · 🛒 상점 · ⛺ 휴식 · ? 이벤트 · 숨은 노드 = 점선. (문서 표기용, 실제 아이콘은 UI 파트)

### 0.2 채택·미채택 경계 (57 Q8~Q15)
- 채택: 노드 보상 미리보기 · 상점 진열 확장 · 도전 성소 + 노드 성과 등급 · 위험 노드 · 이벤트 노드 내용 풀 · 숨은 노드·지도 정보 구매 · 약점 파훼 처치 보너스 · 엘리트 접두어 · 층 테마 소모품.
- **미채택(이 설계안에서 쓰지 않음)**: 리롤·건너뛰기·추방 **토큰**, 보스 유품 2택, 보스 저주, 결투 노드, 시간제 보상 문, 숙취·취중 내기 저주.
- 빌드 축에서 이미 정한 것: 패시브 획득 = 보스 + **궤짝 2택** + 상점 진열 + 노드 보상 + 저주 / 1층 저주 7종 / 저주 획득 = 위험 노드 + 1층 구조물(카운터·장부대·화로·묘) + 이벤트 + '피의 계약' 칸.

### 0.3 설계 원칙 (제안)
1. **두 갈래 길은 '계획'이 되어야 한다**(GDD 2장 "현재 무기로 어떤 전투를 할지 임의 계획"). 갈림길마다 보이는 정보가 다르고 서로 다른 보상을 준다.
2. **위험은 고르는 것**이다. 안전한 길로도 1층 보스를 잡을 수 있어야 한다(타이탄 소울 원칙, GDD 1장).
3. **1층 한 판(약 6분·7노드)에서 선택 화면이 과하지 않게** — 보상 메뉴는 노드당 최대 1개(+ 성과 등급은 메뉴 없이 자동 지급).
4. 새 구조물·NPC는 **기존 그림 재사용**을 먼저 찾는다(47 구조물 16종, 신규 적 독주 행상, 보스 '불붙은 술').
