# 2026-10-02 · 38라운드 · UI 키트 3차 검수

### 도영 님 답변 (원문)
> 잉크로 적으니까 손글씨 같은 폰트가 좋고 페이지가 더 더럽고 어둡되, 글씨가 빛나는 느낌으로 적혀지는 방향

### 정리
1. **페이지는 더 더럽고 어둡게** (3차본 L*43 → L*25~30 대, 얼룩·때·그을림 더 많이).
2. **글씨는 빛나는 느낌** — 잉크로 적은 글자가 어두운 페이지 위에서 발광하듯: 밝은 글자색(세피아 S5 또는 G13~G15) + 바깥쪽 1px 은은한 광륜(halo, 세피아 S4 또는 층 강조색 저밝기) 처리. UI 파트가 Phaser Text 의 shadow/stroke 또는 2중 텍스트로 구현.
3. **손글씨 같은 폰트**: 네트워크 제약으로 받을 수 있는 픽셀 폰트는 Galmuri 뿐(손글씨체 아님). 다음 인터뷰에서 손글씨 폰트 확보 방법을 정한다(도영 님이 파일 업로드 / 아트 파트가 손글씨풍 비트맵 글리프 제작(한글 2,350자 — 큰 작업) / Galmuri 유지 + 발광 처리로 손글씨 느낌 대체).
4. 아트: 키트 4차본(페이지·얼룩·글자 발광 목업). UI 파트는 4차본 승인 후 적용.
