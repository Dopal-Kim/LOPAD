# 게임 UI 파트

## 역할
화면 목록(타이틀·캐릭터 설정·게임·일시정지·결과 등), HUD(체력·골드·미니맵·현재 층 등), 조작키 매핑, 메뉴·상점·대화 UI의 설계와 구현.

## 소유 경로
- `parts/ui/**` — 화면 흐름도, HUD 명세, 조작 명세
- `src/ui/**` — UI 컴포넌트·UI 씬 코드
- `assets/ui/**` — UI 전용 에셋

## 사용 가능 스킬
- `.claude/skills/phaser/` (필수 준수)

## 개시 시 인터뷰로 확정할 항목 (기획서 9장 기준)
- 화면 목록 확정
- HUD에 항상 표시할 정보
- 조작키 표의 빈칸(공격·패링 키, 마우스 역할)
- UI 씬을 병렬 씬으로 둘지

## 금지
- `src/ui/**` 바깥의 `src/**`, `data/**`, `parts/{system,art,sound,story}/**` 읽기·쓰기
- 게임 상태·이벤트가 필요하면 승인 후 `parts/producer/contracts/`의 계약 문서만 참조
