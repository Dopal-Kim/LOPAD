### 2.1 무채색 16단 (인덱스 G00~G15)
- 순흑 `#000000` ~ 순백 `#ffffff`, L* 등간격. 중간 톤에 b*=-3 의 약한 청색 기운.
- 역할 권장: G00 셀아웃·순흑 / G01 외투 그림자·모자 / G03 외투 본색 / G05 외투 주름 / G06 각반·천 본색 / G08 천 하이라이트 / G10 붕대 그림자 / G12 붕대 본색 / G14 붕대 하이라이트 / G15 글린트.
- 타일(바닥) 중간 톤은 캐릭터 중간 톤(G03·G06·G12)과 **명도로** 분리해야 한다. 29라운드 자율 결정 A 로 1층은 **어두운 바닥**: 석판 본색 G04 + 줄눈 G02 + 하이라이트 G05, 벽 G00/G01. 주인공 외투 G03 은 셀아웃 G00 과 시스템이 그리는 발밑 그림자로 분리한다 (`parts/art/work/tiles_stage1/preview_room.png` 로 검증).
- 적 몸통 본색은 바닥 본색 G04 를 피한다 (징집병 술통·결사병 방패 G05, 사수 튜닉 G06, 결사병 갑옷 G03).

### 2.2 강조 램프 12칸 (인덱스 16~27)
- '틀'이다. 층 진입 시 그 층의 ramp 로 인덱스 16~27 을 통째로 교체한다. 무채색은 바뀌지 않는다.
- 칸 역할: 16 ink · 17 deep · 18 shadow2 · 19 shadow1 · 20 base_dark · **21 base(본색)** · 22 base_light · 23 light1 · 24 light2 · 25 glow · 26 flash · 27 white.
- 어두운 쪽은 hue 가 청색으로, 밝은 쪽은 황색으로 돈다 (직선 어둡게 금지). 채도는 본색에서 최고.
- 피·불꽃·발광·마법 등 모든 유채색은 **현재 층 램프만** 쓴다. 고정 포인트색 없음.
- 층별 hue (임시 제안, 검수 대상): 1 잔 호박 h32 / 2 패 도박장 녹색 h150 / 3 붕 병원 청록 h172 / 4 계 황토 h44 저채도 / 5 귀 보라 h272 / 6 연 황금 h50 고채도 / 7 적 진홍 h352 / 8 평상 은빛 흰색 h222 s0.12.
  - 1·4·6 은 모두 난색이라 hue 와 채도로 벌려 두었다 (호박=주황 기운, 황토=탁한 겨자, 황금=맑은 노랑).

## 3. 윤곽선·빛·셰이딩
- **윤곽선: 검정(G00) 셀아웃(inside), 1px, 전 캐릭터 공통.** 바깥 윤곽(outside)은 쓰지 않는다 (16폭 캔버스에 여백이 없다).
  - 한 재질 안의 부위 구분은 윤곽이 아니라 **한 단계 어두운 열(G01)** 로 한다 (팔/몸통, 앞다리/뒷다리).
- **빛: 화면 좌상단 고정.** 좌/우 뷰도 빛은 좌상단. 그래서 좌우는 거울이 아니라, 형태만 뒤집고 하이라이트/그림자 역할을 다시 배치한다 (`build.py` 의 `LIGHT_SWAP`).
- 셀 셰이딩: 본색 + 그림자 1단 + 하이라이트 1단. 디더링은 16~24px 스프라이트에 쓰지 않는다 (타일·큰 보스의 넓은 면에서만 허용).
- 안티에일리어싱 없음 (≤24px). 반투명 픽셀 0.
- 고립 픽셀 금지. 예외는 눈빛·글린트 뿐.

## 3.1 셀아웃 예외 (소지품 keep 마스크)
- `outline(inside)` 는 투명 이웃이 있는 모든 픽셀을 검게 칠하므로 1~2px 폭 소지품(총신·곤봉·술병·망치 자루)과 강조색이 통째로 검어진다.
- 적 리그는 소지품·강조 픽셀을 `keep` 마스크에 기록하고 셀아웃에서 제외한다 (`parts/art/work/enemies/build.py` `Rig.px(keep=True)` / `finish`). 결과: 몸은 검정 셀아웃, 소지품은 윤곽 없는 쇠(G07)·나무(G06)·술(21) 색 그대로.
- 1px 사선 선(총신)은 4방향으로는 고립이지만 8방향 연결이면 허용한다 (의도된 선).

## 4. 주인공 (전장의 망령)
- 실루엣: 검은 케틀햇(챙 10폭) → 붕대 얼굴(8폭) → 어깨 12폭 검은 외투 → 각반 → 검은 장화. 세로 비율 머리 8 : 몸통 8 : 다리 7.
- 강조색은 1층 호박 램프 2칸만: **왼눈 눈빛 = 23 light1 (1px)**, **일기장 = 21 base (2~3px, 오른쪽 허리)**. 오른눈은 꺼진 눈(검정).
- 방향 구분: down = 얼굴·눈빛·일기장 / up = 얼굴 없음·등의 사선 끈·등솔기 / left = 눈빛 보임, 일기장은 끈만 / right = 눈빛 안 보임(꺼진 눈), 일기장 보임.
- 무기는 들지 않는다. 공격은 팔 휘두름만 (무기·이펙트는 별도 스프라이트를 시스템이 얹는다).
- 피벗 (8, 23) = 발바닥 중앙. 모든 동작·프레임 공통. 대쉬·공격의 몸 이동은 프레임 안에서 ±1~2px 오프셋으로만.

## 4.4 UI 키트 (32·33라운드, 임시) — 상세 `parts/art/ui-kit.md`
- 내부 해상도 960×540, 정수 배율. UI 그림도 1배 기준으로 그리고 창 배율만 정수로 키운다.
- 재질 두 가지뿐: **낡은 종이**(G09 바탕 — 33라운드 검수 "A4 가 아니라 낡은 용지, 칙칙한 색". G10 덜 바랜 자리, G08 얼룩·섬유·가장자리 그을림, G07 접힌 자국·해진 가장자리, 누런 얼룩 점 19/18 은 G08 로 감싼 2~3px 군집만. 메뉴·일시정지·결과·타이틀) 와 **잉크**(G00~G02, HUD 틀. 림 G01/G00, 꺾쇠 G02). 유채는 현재 층 램프만 — 게이지 채움(상한 22), 커서 잉크 방울 21, 아이콘 포인트 1~3px(하이라이트 22), 공지·보스 이름 글자 22.
- 종이 패널은 팔각 모따기 이중 잉크선(바깥 G01 2px 무게 = G01 + G03 번짐, 안쪽 G06) 을 유지하고, 코너에만 낡음을 둔다: 좌상단 접힌 자국(사선, 잉크선이 그 자리에서 닳음), 우상단·좌하단 찢긴 결손(알파 0 1~3px), 우하단 접힌 귀 16px, 코너 잉크선 12% 닳음. 9-slice 가운데 띠에는 결손·얼룩을 두지 않는다(늘리면 줄무늬). 가운데는 민 G09 로 두고 질감은 `paper_tile`(64, 주기 노이즈 스티플) 을 inner 안에 타일링. 32 타일은 1배에서 격자 반복이 보여 64 로 키웠다.
- 종이 위 글자(UI 권장): 제목·선택 G00, 본문 G01, 비선택 G03, 흐린 글 G04. 바랜 종이라 G03 보다 밝은 글자는 묻힌다. 잉크 위는 G13/G11 + 강조 22.
- 잉크 패널은 가운데만 반투명(G01 0.85) — 스프라이트 "반투명 0" 규칙의 유일한 예외. 림·선은 불투명.
- 아이콘 16×16: 1px 여백 안에 그리고 **바깥 K 윤곽**(outside) — 종이·잉크 두 바탕에서 모두 읽히기 위한 규칙 (캐릭터의 inside 셀아웃과 다름). 채움은 G10(흰 G13 아님), 옅은 선 G06. 무채 ≤5 + 강조 ≤3. 미니맵 8×8 글리프는 윤곽 없는 G12 단색(어두운 지도 전용).
- 게이지 채움은 1×8 세로 띠(22/21/20×3/19×2/18)를 가로로 늘린다. 틀은 9-slice, 채움 원점은 JSON `fillInset`.
- 도장은 바랜 잉크 G02(닳음 G03/G04). 커서·도장·일기장은 회전하지 않는다 (픽셀 밀도 혼합 금지). 깜빡임은 프레임 교체.
- HUD 배치(33라운드 Q3): 상단 좌 층 제목, 상단 우 미니맵·음소거, **하단 중앙 잉크 패널 480×64 한 묶음**(체력·전표·독주 / 무기·개성·우클릭), 그 위 보스 게이지, 그 위 자막.

## 6. 시트·JSON 규칙
- PNG: 가로 = 프레임, 세로 = 방향 `down / up / left / right` 순. 패딩 없음. 프레임 인덱스 = `row * frames + column`.
- JSON 필드: `image, action, frameWidth, frameHeight, frames, directions, layout, frameIndex, fps, frameDurationsMs, loop, pivot, palette`.
- 엔진 연동(로드 방식·애니 키 이름)은 계약 승인 후 `parts/producer/contracts/` 에 두고 그것만 따른다.

## 7. 제작 절차
1. 브리프(크기·색 예산·실루엣 한 줄) → 2. `parts/art/work/<slug>/build.py` 작성 (문자 지도 + 파라미터 자세) → 3. 실행 → 4. preview 를 **눈으로** 보고 `.claude/skills/pixel-art-studio/references/validations.md` 체크리스트 대조 → 5. 수정 → 최소 3회 반복 → 6. `assets/` 로 내보내기. PNG 를 손으로 고치지 않는다.
