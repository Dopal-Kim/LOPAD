## 0. 한 줄 요약
인페르노의 "굵고 선명한 예고 → 백열 섬광 → 겹쳐 쏟아지는 광선 → 긴 잔상" 을, 16×24 고대비 흑백 세계에서는 **"어두운 가장자리 1px 로 테두리 친 은빛 몸체 위에 1px 백열 선"** 으로 번역한다. 색은 늘리지 않고 **층(레이어)** 을 늘린다. 밝기는 코어 1px 에만 몰고, 몸체는 중간 톤으로 눌러 캐릭터(흑백)와 바닥(어두운 흙)이 묻히지 않게 한다.

## 2. 3층 색 구조 (팔레트 `fx` 블록, `parts/art/palette/lopad.json`)
```
1 코어   X0 #ffffff (= G15) 1px 선 / X1 #fff4dc 백열(따뜻한 흰) 1~2px, 섬광 프레임의 몸체
2 강조   현재 층 램프 27 / 26·25 / 24·22 — 머리 글린트(2px), 불티, 닫히는 원의 섬광. 무기 이펙트 하나당 ≤3칸
3 몸체   무기 보조 램프 W3(밝음, 코어 옆) → W2 → W1(꼬리·잔상)
  가장자리 W0 1px (어두운 림). 1~2층처럼 아주 어두운 바닥에선 G00 대신 W0 그대로 (W0 가 바닥 G01 보다 밝아 윤곽이 잡힌다)
```
| 무기 | 라벨 | W0 가장자리 | W1 몸 어두움 | W2 몸 | W3 몸 밝음 |
|---|---|---|---|---|---|
| katana | 차가운 은빛 | `#3a4556` | `#6f7e97` | `#a9b8cc` | `#dde6f2` |
| greatsword | 재·용암 | `#4a3c38` | `#a8321c` | `#e35c1c` | `#f9b23c` |
| dagger | 보라 그림자 | `#1c1327` | `#3e2a62` | `#7a4fb2` | `#c89cf0` |
| bow | 번개 청백 | `#1e3350` | `#2e71c9` | `#6cb9f5` | `#cdefff` |
- 색 예산(이펙트 하나): **무채 ≤2 + 코어 2 + 층 강조 ≤3 + 보조 4 = ≤11.** 적·보스 예고와 공통 피격(`hit_burst`)은 보조색 없이 층 램프 ≤8 + 코어.
- 금지: 캐릭터·적·보스·타일·UI 에 `fx` 블록 사용. 보조색 두 무기 혼용 금지(한 시트에 한 무기). 보조색을 넓은 면(디스크)으로 채우지 않는다 — 띠·선·점만 (단검 웅덩이 W0 만 예외, 그림자이므로).
- 층 스왑과의 관계: 보조색은 고정. 층이 바뀌면 글린트·불티·예고만 바뀐다 → "어느 층에서도 내 칼은 은빛, 이 층의 불꽃은 그 층 색" 이 읽힌다. 5층(보라)에서 단검 보라가 겹치고 7층(진홍)에서 대검 용암이 겹치는 문제는 7절 임시 결정 4.

## 4. 단계 규칙: 기본 → 1차 → 2차 (밀도·크기·프레임)
| | 기본 | 1차 | 2차 |
|---|---|---|---|
| 캔버스 (칼 기준) | 48 (기존 32) | 64 (기존 48) | 96 (기존 48·64) |
| 겹 수 | 2 (본 + 바깥 잔상) | 3 (+ 안쪽 잔상) | 3 + 고유 요소 1 (보름달 고리 / 2단 링 / 분신 군집 / 가지 번개) |
| 프레임 | 5: 예비 → 본 → 광선 → 식음 → 꼬리 | 7: 예비 → **섬광** → 광선 → 식음 → 어두운 띠 → 점선 → 꼬리 | 7 + (루프형은 4) |
| 적중 광선 | 2 (길이 5) | 3 (길이 8) | 4 (길이 10) |
| 섬광 프레임 | 없음 | 1 (40ms) + 화면 오버레이 0.18 | 1 (40ms) + 오버레이 0.22 |
| 머리 글린트 (층 27) | 2px 1 | 2px 2 | 2px 2 + 네 귀 4 |
| 꼬리 프레임 | 1 (90ms) | 3 (100·120·140) | 3 (110·140·160) |
| 트레일 (시스템) | W1 α0.6→0 120ms, f2 부터 | W1 α0.7→0 180ms | W1 α0.7→0 220ms |
| 흔들림 (시스템) | 없음 | 2px 60ms | 3~4px 80~120ms |
- 타이밍은 "짧은 섬광 → 긴 꼬리": 첫 두 프레임 40ms, 마지막 프레임이 가장 길다. 공격 판정 시각(attack 2프레임 시작)은 그대로 — 예비 프레임(f0)은 판정 **직전** 40ms 에 재생되도록 `spawn: attack_frame2 - 40ms` 를 요청하거나, 불가하면 f0 를 빼고 재생(7절 임시 결정 5).
- 대검·단검·활의 기본 베기/화살도 같은 규칙(2겹·5프레임·48)으로 재생성한다. 화살 투사체(`bow_arrow` 8×8)는 크기 유지, 꼬리에 W1 2px 만 추가.

## 6. 시스템·UI 연출 요청 (결정 Q3)
### 6.1 잔상 트레일 (시스템)
- 대상: 베기 3종·거합·만월·쌍격·난무·대쉬 베기(발도술·허보·급소). 투사체(화살·섬광·추적)는 꼬리 시트가 있으므로 트레일 없음.
- 색 = 그 무기 `fx.weapons.<id>.ramp[1]` (W1). 알파 0.6(기본)/0.7(1·2차) → 0, 길이 120/180/220ms. 시작 = 시트 f2(광선 프레임) 시작. 트레일 폭 = 본 띠 두께의 0.6.
- 깊이: 이펙트 시트 바로 아래(캐릭터 위).

### 6.2 화면 섬광·색 오버레이 (시스템)
| 시각 | 색 | 알파 | 길이 |
|---|---|---|---|
| 거합 f1 | X1 `#fff4dc` | 0.18 | 40ms |
| 만월 f1 | X1 | 0.22 | 40ms |
| 지진·분쇄 f1 (낙뢰) | 대검 W3 `#f9b23c` | 0.16 | 40ms + 흔들림 4px 120ms |
| 중시 적중 f1 | 활 W3 `#cdefff` | 0.14 | 40ms + 흔들림 2px 60ms |

### 6.3 굵은 예고 (시스템)
- `telegraph_line` 두께 2→**4px**, 코어가 공격자→목표 방향으로 흐른다(`drawnFacing: right`, 타일링 그대로). `telegraph_circle` 은 **진행도 기반 6프레임**(`frame = min(5, floor(progress*6))`), 지름 44 기준 scale = R/22. `telegraph_aura` 신규(돌진·대기술 예고, 적 히트박스 중심 추적, 루프). `telegraph_cone` 은 선과 같은 4px 구조로 재생성 예정.
- 양산 시 기존 id 유지(`telegraph_line/circle/cone` + 신규 `telegraph_aura`), 캔버스는 32→64.

### 6.4 보스 페이즈 타이틀 카드 (UI)
- 구성(제안): 화면 중앙 상단, 잉크 패널(`panel_ink`) 320×48 — 좌우에서 닫히는 2px 선(층 22) 120ms → 보스 이름 글자 22 + 할로 18 + 그늘 G00(ui-kit 발광 규칙) → 페이즈 부제(G14) → 섬광 1프레임(X0 0.35) → 1.2s 유지 → 위로 사라짐. 카드 등장 시각 = 보스 hurt 플래시 종료 직후, 적·플레이어 정지 없음(인페르노식 카드는 전투를 멈추지 않는다).
- 아트 제공물: 없음(기존 UI 키트로 조립 가능). 보스별 문양 도장이 필요하면 추가 인터뷰.

## 7. 임시 결정 (도영 님 검수 대상)
1. **보조색 hex 4×4 + 코어 X1 `#fff4dc`(따뜻한 흰)**: 2절 표. 칼 은빛은 2차 비평에서 W1·W2 를 한 단 어둡게(L* 57→52, 80→74) 했다 — 1배에서 흰 덩어리가 되지 않게. 대검 W2 용암 `#e35c1c` 는 1층 호박 램프 21 `#d67a11` 과 가까워 1층에서 '층색' 으로 오해될 수 있다 → 대안: W2 를 더 붉게(`#d8441c`).
2. **크기 확대**: 기본 32→48, 1차 48→64, 2차 48/64→96 (칼 기준). 1배 목업에서 거합 64 가 주인공(24px) 의 2.7배 — 인페르노 규모로는 맞지만 화면이 좁은 방(12×8 타일)에서는 크다고 볼 수도 있다. 대안: 기본 40 / 1차 56 / 2차 80.
3. **색 예산 ≤11** (무채 2 + 코어 2 + 층 강조 3 + 보조 4). 기존 "무채 ≤4 + 강조 ≤8" 을 대체.
4. **층색과 보조색 충돌**: 5층 귀(보라 h272) ↔ 단검 W2 `#7a4fb2`(h~265), 7층 적(진홍 h352) ↔ 대검 W1 `#a8321c`(h~8). 그대로 두면 그 층에서만 글린트가 무기색에 묻힌다. 대안 A: 그대로(해당 층에서 무기가 '그 층과 공명' 하는 연출로 수용) / B: 보조색 hue 를 층과 20° 이상 벌림(단검 보라→자주 h300, 대검 용암→주황 h20) / C: 충돌 층에서만 글린트를 X0 로.
5. **예비 프레임(f0, 40ms)의 재생 시각**: 판정 40ms 전(공격 1프레임 '예비' 뒤쪽). 시스템이 `spawn` 오프셋을 지원하지 않으면 f0 를 빼고 4·6프레임으로 양산.
6. **대쉬 잔상(dash_trail)의 보조색 교체**: 발도술·허보·잔상 노드에서만 W1 로 — 시스템 틴트(`setTint`) 로 처리하면 시트 1장, 아니면 무기별 시트 2장 추가.
7. **잔월 띠에 번개 토막**(띠 사이를 뛰는 2px 지그재그)과 **만월 보름달 고리**(f3 에서 닫힘) 추가. 둘 다 결정문의 "초승달 잔상 겹침" 을 넘어서는 아트 제안.
8. **공통 적중 `hit_burst`(24, 무기 무관) 로 `hit_spark` 대체**, `crit_burst`·`dashcrit` 는 같은 구조에 광선 8갈래 + 고리로 재생성. 피는 그대로(층색).
9. **적·보스 예고에 보조색 금지, 코어는 허용**(닫히는 순간·오라 중심 X0). 보스 공격이 무기색과 겹치지 않게.
10. **4방향 = right 기준 회전/반전**(콘셉트). 양산 시 기존 방향별 SWEEP 각도 규약(바이블 4.3) 그대로 쓰되 결과 그림은 동일 — 회전은 픽셀 밀도를 유지한다.

## 9. 자기 비평 기록 (see→critique→fix 3회)
1. 1회차: 칼 본 띠가 코어 X0/X1(띠 두께의 30%) 에 먹혀 1배에서 흰 덩어리, 겹이 안 보임 → 코어를 몸체에서 분리해 1px 선으로. 암살 분신의 5px 해치가 보라 노이즈 → 단색 실루엣 + 우·하 림 + 흩어 배치. 잔월 3띠가 같은 두께 평행선(밴딩) → 바깥 띠 점선·가늘게. 색 예산 초과(칼 강조 5~6칸) → 22/24/27 세 칸으로. 목업 예고 선이 보스를 가로질러 의미 없음 → 사수→주인공 방향으로.
2. 2회차(8배 확대): 겹은 성립하지만 은빛 W2/W3(L* 80/93) 이 너무 밝아 여전히 흰 초승달 → 램프 W1·W2 한 단 어둡게 + 몸체 배분 [W0 W1 W2 W3 W2 W1] + 식는 프레임 코어 X1→W3. 수렴 오라가 정지 화면에서 폭발로 읽힘 → 토막이 중심에 가까울수록 길어지게. 대검 균열이 바퀴살 → 지그재그 4토막·진폭 2.2.
3. 3회차: 1배 목업에서 은빛 베기·호박 예고·흑백 캐릭터가 세 층으로 분리되어 읽힘, 섬광 오버레이(0.18) 는 바닥 디테일을 지우지 않음. 고립 0 · 반투명 0 · 예산 ALL OK. 남은 것: 오라는 움직여야 '수렴' 이 읽힌다(정지 1장은 여전히 방사형) — 대안으로 안쪽을 향한 쐐기(chevron) 토막.
