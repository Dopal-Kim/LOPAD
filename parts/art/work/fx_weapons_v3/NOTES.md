## 1. 문체 (무기별 — 같은 규격에 새 무기의 성격)

- **칼 B 재 칼날** — 가는 초승달: 바깥 1px 날선(판정 프레임만 백열 X0) + 호박 몸(A25→A19) + 안쪽 **회색 재 장막**(호를 따라 길쭉한 결로 부서짐) → 꼬리 쪽부터 재 조각으로 떨어지고 끝에서 접선으로 불티가 튐. 양끝 바늘.
- **대검 A 녹슨 양손검** — 넓은 녹·흙 띠(날선 쪽 35% 녹빛 A19/A21, 안쪽 흙 B2/B3 얼룩) + 바깥 호박 날선 + **이 빠진 홈 혼불 한 줄**(7곳에서 끊기고, 같은 자리 날선에 작은 V 홈) + 꼬리 흙먼지 구름 + 홈에서 떨어지는 불씨. 3타는 앞-아래 바닥 균열.
- **단검 B 재 송곳니** — 바늘 찌르기(재 방추 몸 + 호박 심 + **끝 백열**·작은 글린트) + 지나간 자리 공중에 남는 **가는 호박 금**(갈라지는 균열, 잔가지) → 금이 식으며 끊기고 재 조각이 떨어짐. 3타 = 옆 그림자 줄기 ±9°.
- **활 B 혼불 시위 + 재 화살** — 재 화살대(윗면 S3)·재 깃 V·**타는 촉**(호박 → 백열, 뒤로 핥는 불꽃 2) / 꼬리 = 재 연기 + 호박 실 + 불티 / 조준 = 시위와 같은 1px 혼불 실.
- 특수(진화)도 같은 언어로: 구 '번개' 는 **혼불 낙뢰**(호박 몸 + 백열 심), 구 보라 그림자 분신은 **재 실루엣**(주인공 v3 실루엣, 재 B0~B2 + 재빛 테), 바닥 충격은 **혼불이 스민 균열 + 흙먼지 띠**.

4. 발도 갈래의 몸 앞 '메아리 선' 이 막대처럼 보임 → 제거. 그림자 분신(암살·잔상·그림자 걸음)이 밝은 회색 석상처럼 보임 → 재 B0~B2 몸 + S0~S2 테, 웅덩이는 어두운 단색.
### 3회차 (특수 전체 띠)
5. 대검 바닥 충격(내리찍기·파쇄·중압·지진)이 '바퀴살 + 왕관' — 고르게 퍼진 균열과 같은 간격 먼지 → 균열 시작 반지름·각·길이 제각각 + 잔가지, 고리는 굵기가 흔들리고 몇 군데 끊김, 먼지는 크기·자리가 제각각인 낮은 띠.
6. 활: 저격 혼불 실이 점선이라 눈금자처럼 보임 → 이어진 1px 실(프레임 깜빡임만). 연기 꼬리가 소시지처럼 균일 → 크기 잡음 + 꼬리 끝에서 끊겨 흩어짐.

## 7. 남은 약점

1. **호 반경 = 판정 반경**이라 칼·대검 초승달이 칼끝보다 멀리 떠 있다(칼 132 도트 vs 칼끝 약 90, 대검 204 vs 약 150). 칼은 재 장막이 안쪽으로 이어 주지만 대검은 띠와 칼 사이가 빈다(구 시트도 같은 구조).
2. 대검 녹 띠는 비발광색이라 주변광이 어두우면 날선·홈 두 줄만 남는다(목업 주변광 0.425). 시스템이 fx 를 조명 위에(무조명) 그리면 해결.
3. 단검 바늘 몸(재)은 1배에서 거의 안 보이고 호박 심·금·백열 끝으로 읽힌다(의도: '백열 끝'). 3타 옆 줄기 ±9° 가 부채살처럼 곧다.
4. 화살은 구 청백 화살보다 어둡다(재 대). 촉 빛이 발광색이라 조명에서 읽히지만 밝은 바닥에서는 약할 수 있다.
5. 특수 중 `dashcrit` 2프레임째가 해 모양(고리 + 광선)으로 흔한 기호에 가깝다. `ironwall` 의 녹슨 벽은 대검 날 면과 같은 색이라 대검 오버레이와 겹치면 구분이 약하다.
6. 실루엣 이펙트(`longinvuln`·`afterimage`·`assassin`·`shadowstep_ghost`)는 주인공 v3 시트 사본 — 주인공 대쉬·대기 그림이 바뀌면 재빌드.
7. 방향 변환은 오른쪽 그림을 회전·반전한 것(계약 arcAngleNote) — 떨어지는 재·불티만 화면 아래로 떨어지게 따로 계산.
