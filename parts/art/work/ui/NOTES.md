### 발광 규칙 수치 (ui-kit.md 1.2절과 동일)
- 구조: 그늘 ring(맨해튼 거리 2, 오프셋 (±2,0)(0,±2)(±1,±1)) → 할로 ring(4방향 (±1,0)(0,±1)) → 본색. 8방향 금지.

### 임시 결정 (인터뷰 대상)
1. **램프 hex**: 위 표. 페이지 L*28 (지시 범위 25~30 가운데). S5 를 L*70 까지 올린 이유: 발광 글자 본색으로 쓰려면 페이지 대비 ≥ 4 가 필요(4.36). 대안: S5 를 L*60(#a58c77, 대비 3.2)으로 두고 본문을 G13 으로 — 세피아 글자가 사라지고 전부 흰 글자가 됨.
2. **흐린 글 = S5 α0.55** (지시의 "S4" 대신). S4(L*38) 는 L*28 페이지에서 대비 1.4 라 1배에서 안 읽힘. 대안: G09(회색, 대비 3.2, 할로 없음) — 차가운 회색이라 '바랜 잉크' 로 읽히지만 세피아 톤에서 튐.
3. **"저밀도 할로" = 알파 0.5** (체커 디더가 아니라). 디더는 1배에서 글자 둘레가 톱니처럼 보였을 것이라 시도하지 않음. 알파는 Phaser `setAlpha` 한 줄로 끝남.
4. **선택 항목 할로만 층 강조색 20** (제목·본문은 S4). 층마다 선택 항목 빛 색이 바뀜(커서 잉크 방울 21 과 같은 규칙).
5. **얼룩 데칼 시트 `stains.png` 신규** (32×32 ×4). 64 타일 안의 큰 얼룩은 반복이 보여서 데칼로 분리. UI 가 페이지당 3~5개, 고정 seed. 범위가 늘어난 셈이라 확인 필요 — 싫으면 데칼 없이 타일·패널만으로도 성립(목업보다 덜 더러움).
6. **종이 틀 선을 S4 '흐린 발광 선' 하나로** (v0.3 의 G01 잉크선 + S1 안쪽 선 제거). 어두운 페이지에서 어두운 잉크선은 안 보이고, 선 두 개는 격자처럼 보임.
7. **도장 = S4/S5/S2 바랜 발광 잉크** (G02 무채 도장은 L*28 위에서 사라짐). 유채(층 램프) 도장은 층마다 색이 바뀌어 '사망 도장이 초록' 이 되므로 피함.
8. **쏟은 잉크 얼룩(데칼·타이틀 일기장)도 발광색** — "잉크 = 빛나는 것" 규칙을 일관되게. 어두운 S0 얼룩으로 두는 대안도 가능(그을림·때와 구분이 안 됨).
9. `cursor.png` 종이용 촉을 S5 + 할로 S4 로 (G01 잉크촉은 안 보임). 8×8 유지, 피벗 (4,4) 유지, 촉이 한 줄 작아짐(5행).
10. 손때 띠는 단색 계단(S0/S1/S1/S2/S2) — 디더는 9-slice 늘림에서 줄무늬가 되어 포기.
11. 책 표지는 램프만 어두워지고 긁힘·바랜 자리 추가. 구조(캡·실·단면)는 v0.3 그대로.

### 교차 참조·후속 요청
- `parts/art/work/palette/build.py`(팔레트 생성기)는 여전히 `ui` 블록을 모른다. **재생성하면 `ui` 블록이 사라지고 UI 빌드가 멈춘다.** 생성기 `data` 에 `"ui": {...}`(v0.4 hex) 와 gpl 6줄 추가 필요(아트 파트, 다음 라운드).
- `art-bible.md` 2절 "UI 전용 세피아 램프" hex 와 4.4절 UI 키트 요약을 v0.4 로. `README.md` 파일 목록에 `stains` 추가.
- UI 파트 전달: `assets/sprites/ui/` 전체 재복사(+`stains`), 글자 발광 규칙(ui-kit.md 1.2절, Phaser 재현 두 방법), 조립 순서 ③′ 데칼, 종이 위 어두운 글자색 전면 폐기.
- 손글씨 폰트: 38라운드 정리 3항(도영 님 업로드 / 아트 제작 / Galmuri + 발광)은 아트가 정하지 않는다. 발광 규칙은 어떤 글꼴에도 같은 수치로 적용.
