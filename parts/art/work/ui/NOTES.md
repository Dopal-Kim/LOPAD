## 임시 결정 (인터뷰 대상)
1. **세피아 램프 hex**: S0 `#2b221b` / S1 `#413227` / S2 `#5d4a3b` / S3 `#78614f` / S4 `#907863` / S5 `#a58c77` (L* 14/22/33/43/52/60, Lab C* 7~16, 색상각 ≈65°). 페이지 S3 를 지시 범위(L* 35~45) 의 윗단에 둔 이유: G00/G01 글자 대비가 3.6/3.2 로 1배에서 읽히는 한계선. 더 어둡게(L* 35) 내리면 대비 2.6 이하 → 글자를 밝은색으로 뒤집어야 함.
2. **책 표지 틀을 별도 9-slice(`book_frame`)로** 두고 `panel_paper` 는 확장하지 않음. 이유: (a) 페이지가 틀 없이도 단독으로 쓰임(툴팁·쪽지·HUD 메모), (b) 두 페이지 펼침이 `paper | spine | paper` 조합으로 되어 틀을 한 번만 늘리면 됨, (c) 코너 32 + 띠 16 을 80 타일 안에 넣으면 페이지 코너 낡음(24)과 겹쳐 둘 다 망가짐.
3. 종이 위 글자 규칙 변경: 비선택 G03→**G02**, 흐린 글 G04→**G03** (S3 위에서 G04 는 대비 1.8).
4. 종이에서 유채 얼룩(19/18) 제거 → 세피아 S1/S0 점. 33라운드 "얼룩 스왑" 질문은 자동 해소. 남은 유채는 책갈피·봉인·술잔 자국·커서 방울·게이지·아이콘 포인트.
5. 잉크 틀(`panel_ink`·`minimap_frame`·게이지) 림을 가죽 1px(S1 위·왼쪽 / S0 아래·오른쪽)로 — '선택' 항목을 채택. 바탕은 G00 0.85.
6. 아이콘은 종이·책을 그린 둘(`icon_gold`·`icon_save`)만 세피아. 붕대·병·눈 등은 무채 유지(재질이 종이가 아님). `cursor_light` 는 S5/S1 세피아 촉.
7. 결과 화면을 두 페이지 펼침으로 목업(틀 632×432, 페이지 292×400 ×2). 일시정지는 한 페이지(틀 452×268). 레이아웃 좌표는 33라운드 그대로.
8. `book_frame` 실 제본은 연속선(점선이면 9-slice 늘림에서 점 간격이 늘어남). 금속 모서리 캡 다리 12px, 무채 G05/G07/G03.
9. `spine` 꿰맴 주기 16px (8 은 지퍼처럼 보임), 홈 6px.

## 교차 참조·후속 요청
- `parts/art/work/palette/build.py`(팔레트 생성기)는 이번 라운드 쓰기 범위 밖이라 안 고쳤다. **재생성하면 `ui` 블록이 사라진다.** UI 빌드는 그 경우 멈추도록 해 두었다. 생성기 `data` 딕셔너리에 `"ui": {...}` 와 gpl 6줄을 추가하는 후속 작업 필요(아트 파트, 다음 라운드).
- `art-bible.md` 2절(팔레트 규칙)에 "UI 전용 세피아 램프 6칸, 캐릭터·타일 금지" 한 줄과 4.4절 UI 키트 요약을 v0.3 으로 갱신 필요. `README.md` 파일 목록에 `book_frame`·`spine` 추가.
- UI 파트 전달: `assets/sprites/ui/` 재복사(전체 색 변경 + 신규 2개), 글자색 규칙 변경(G02/G03), 일기장 조립 순서(ui-kit.md 2.1).
