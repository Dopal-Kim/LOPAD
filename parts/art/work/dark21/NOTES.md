## 1. 타이틀 다크화 (`build.py`)
- 62 구도·좌표 그대로(title.json 의 hero·glow·voices·gate·logo 좌표 불변 — `BOX` 로 62 상자에 맞춰 자름). `title62/build.py` 는 다시 돌리지 말 것(밝은 판으로 덮임).

- 중경: 횃불 꺼진 출병 행렬(맨 앞 하나만 꺼져 가는 불), 젖은 진흙 길(웅덩이는 흐린 하늘·먼 불 반사), 길가·들판 시체 10, 마른 나무의 꺼진 등롱 3 + 까마귀, 창 끝 까마귀.
- 근경: 주인공 = 달 역광(차가운 회색 테)만, 도시 호박 반사 제거. 등 균열 62 의 0.62 배 크기로 검붉게, 어깨 혼불 → 꺼져 가는 불씨 몇 점. 허리천 피에 절음, 붕대 피 얼룩. 시체 더미 피 웅덩이·흘러내린 줄기, 창대 까마귀. 왼쪽 발치에 피 묻은 연회장 잔해(비스듬히 걸린 긴 상·찢긴 식탁보·상에 기댄 시체·깨진 술독·잔·뒤집힌 의자)와 꺼진 등롱 장대.
- 로고: 모양·알파 그대로, 호박 → 뼈빛(G05~G12) + 어두운 단 검붉은 B0~B4, 빛무리는 검붉은 연기(알파 0.7). `title_logo_reveal.png` 는 다시 만들어도 바이트 동일(확인).

## 2. 색 보정 (`grade.py`, `grade_proposal.json`, `lighting_proposal.json`)
- 실기 캡처: `npx vite build --outDir <scratch>` + 헤드리스 Chromium(`capture.cjs`, URL `?weapon=…&nobirth` / `&boss`) → `cap/`. 일반 전투 노드는 URL 만으로 못 들어가 황무지 탄생지·연회장(보스) 두 지역만 실측. 외곽·성문·양조는 기본값(연회장 기준) — 2차 실측 대상.
- 채도 측정 = HSV S 평균(V ≥ 0.08 픽셀). 크로마(max−min)는 어둡게만 해도 같이 줄어 '채도' 목표와 섞이므로 참고값으로만(grade_measure.json).
- 목업은 주변광 변경을 화면 곱으로, 적 림 빛(mob)을 몸 중심 광원으로 어림(`LIGHT_SCALE` 4.5 — 황무지 빛 웅덩이로 잰 어림값).

## 3. 타일 v4 (`tiles_audit.py`, `tiles_dark.py`)
- 판독 짝(바닥↔낙하·벽 윗면·앞면·덮개·데칼·테 등)의 칸 평균 명도 차 ≥ 0.045 또는 OKLab ΔE ≥ 0.06 을 '읽힘'으로 보고 보정 전후 비교.
- 바닥을 한 단 내리는 안(지시 '바닥은 더 어둡고 차갑게')은 시험해 보니 바닥이 데칼·덮개 테·낙하 채움(물·술)과 붙어 버려(외곽·양조에서 바닥↔낙하, 거의 모든 지역에서 바닥↔데칼·테가 새로 무너짐) **채택하지 않음** — 바닥 어둡게·차갑게는 주변광(#4e5260, 살짝 청)과 보정이 맡는다.
- 대신 **세로면만 한 단 어둡게**: 벽 앞면 376~382·앞면 끝 388~391·높은 단 앞면 472~475(PL → SL 한 칸 아래 = 차갑게). 윗면·윗면 테·높은 단 테는 그대로. 보정 뒤 무너지던 윗면↔앞면(연회장)·바닥↔앞면(성문)·바닥↔높은 단 앞면(외곽)이 살아남. JSON `v4.p21Dark` 에 기록. `p19/tiles4.py` 재실행 뒤에는 `tiles_dark.py` 를 다시 돌릴 것(원본은 항상 git HEAD 에서 읽음 — 두 번 돌려도 두 단 안 내려감).
- 남은 경계(칸 평균으로는 기준 아래, 실제로는 덮개 테 320~351 이 경계를 그림): 바닥↔돌 덮개(성문·양조·연회장·황무지), 바닥↔흙 덮개(외곽), 바닥↔벽 윗면(외곽·성문 — 보정 전부터 같은 명도, 윗면 테가 맡음), 양조 윗면↔앞면. 2차 실기 캡처에서 테가 안 보이면 테 칸만 한 단 올리는 안.
- 소품·위험물: 위험물 빛(still·fire_pool)·예고·무기 fx 는 조명 제안에서 그대로 두고, 계약 §7 대로 보정 영향 적은 층에 둘 것을 시스템에 권장.
