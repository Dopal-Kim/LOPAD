- **실내 느낌을 없앤 방법**: (1) void 를 투명 대신 원경으로 칠해 경계 밖에 '바깥' 이 보이게, (2) 경계를 벽이 아니라 둔덕·지붕·난간으로, (3) 다섯 지역의 바닥 재질·색이 달라 노드를 지날수록 장소가 바뀐다(흙 → 돌길 → 판석 → 널판 → 대리석/깔개).
- 눈 피로(v4 원칙 유지): 바닥 흔적은 방 종류당 넷 중 둘 이하, 2~3px, 낮은 대비. 1px 흩뿌림 0. 밝은 강조(19 이상) 비율은 2배 목업에서 0.01~0.17%.

## 3. 자기 비평 기록 (see → critique → fix)
1. outer 1회차: 회벽 띠 16px 는 장식 띠, 회색 기와 테는 돌 테로 읽혀 여전히 방 안 → 집 앞면에 갈색 처마를 얹고 윗면·void 를 갈색 지붕 경사로.
2. waste: 변형 넷 모두에 흔적 → 화면 가득 군화 자국 무늬 → 둘로 줄임. 윗면 돌 4개 = 점선 돌 테, 둥근 덩이 = 구슬 꿴 테 → 이음새 없는 토러스 높이장(`relief`)으로. 투구가 종 → 솥으로 읽혀 두 번 고침.
3. gate: 빠진 돌(흙 사각형) 변형이 25% 섞기에서 갈색 물방울 무늬, 회색 줄눈이 화장실 타일 → 흙 줄눈, 빠진 돌은 소품으로. 깃발이 작아 등불로 읽힘 → 성벽 높이 전체. 사방 회색 성벽 윗면이 '돌 방' → 북쪽만 성벽, 나머지는 흙 둔덕.
4. brewery: 16×8 판석 = 벽돌 바닥, 작은 술통 마구리 = 사슬 → 젖은 널판 + 옆모습 술통 두 줄 + 큰 뚜껑 하나. 갈색 반사 = 나뭇조각 → 회색 한 단. 술 웅덩이가 돌덩이 → 납작한 타원.
5. hall: 대리석 판 윗면이 '깔개 깐 방' 의 벽 → 십자 난간대(사이로 밤). 포도주 얼룩 변형 = 갈색 점 무늬 → 소품으로만. 뒤집힌 잔이 장화 → 나팔꼴 잔몸.

## 4. 임시 결정 · 남은 질문
1. **지역 바닥에 층 램프 어두운 칸(16~18)을 씀**(waste 흙, 깔개, 지붕, 술통). v4 의 남은 질문 3(흙을 갈색으로?)을 지역 타일에서만 시험했다. 층 타일이라 런타임 스왑과 무관. 색 수: 무채 9~13 · 강조 6~8 (v4 의 '무채 10 + 강조 4' 예산보다 넓음).
2. **void 불투명**(§7.3 문구대로). 시스템이 void 를 그리지 않고 배경색으로 둔다면 원경이 보이지 않으니, 시스템 쪽에서 void 칸에 `tiles["0"]` 인덱스 7 을 실제로 그리는지 확인이 필요하다.
3. 경계가 1칸 두께라 북쪽 '집 앞면' 은 16px 높이뿐이다. 경계를 2칸 이상(정면 + 그 위 윗면)으로 그리면 건물·성벽이 훨씬 잘 읽힌다 — 시스템 배치 합의 사항.
4. 지역 ↔ 노드 대응(어느 노드가 어느 region 을 쓰는지)은 시스템 몫. 아트 제안: 여정·튜토리얼 = waste, 1층 첫 갈림 = gate, 중간 전투·상점·휴식 = outer, 후반 = brewery, 보스 = hall.
