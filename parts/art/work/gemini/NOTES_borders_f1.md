## 3. 채택 이유 (키아트 유사도 우선)
- **황무지 북 b**: a 는 왼쪽 절반만 흙둑·말뚝·폐가이고 오른쪽 절반이 흙둑 없이 키아트식 원근 평야로 열려 '벽'으로 읽히지 않음 → "흙둑 앞면이 끝까지 끊기지 않게, 열린 땅은 둑 위로만" 수정 지시로 b 새로 생성(참고 이미지 같음). b = 끝까지 이어진 흙둑 단면 + 기울어진 말뚝 울타리 + 무너진 지붕 들보의 폐가 + 모닥불 + 수레, 둑 위로 키아트의 흐린 평야·지평선 성곽·연기. 아래 40%(꽂힌 무기·혼불이 있는 앞 땅)는 바닥 위 잡동사니로 오인될 수 있어 기준선(원본 y 690) 아래 80px 만 앞치마로 남기고 버림.
- **황무지 서·동**: 서 = 모래주머니·돌 담(오른쪽 끝 직선) + 폐가·말뚝·대포·혼불·모닥불, 동 = 돌 담 + 불타는 보급 수레·천막·칼 꽂힌 무덤·감시대·혼불. 위쪽 하늘(원본 y<280)은 반복에 안 맞아 잘라냄.
- **성문 북**: 3칸 높이 성벽 앞면 + 가운데 성문(반쯤 올린 창살·터널 호박빛) + 횃불 망루 2 + 양끝 망루 + 잔 문양 깃발 + 통행세 오두막·X 바리케이드·물통·술통 — 키아트 성문과 거의 같은 덩어리. 성 너머 도시 지붕이 2겹으로 흐려짐.
- **성문 서·동**: 서 = 흉벽 경비 담(횃불 줄) + 경비 초소·마구간·성벽 계단·우물, 동 = 바퀴 자국 진창길의 술통 수레 줄·통행세 부스·감시탑·바리케이드.
- **성문 남**: 해자 북쪽 둑 갓돌 + 검은 물(횃불 반사) + 진흙 남쪽 둑. 단순하지만 키아트의 해자와 같음.
- **양조 북**: 그을린 벽돌 증류소 + 화구 6(문 열림, 가장 밝음) + 지붕 위 증류기 5 + 굴뚝 연기 + 기중기에 매달린 술통 + 뜨거운 솥 — 키아트의 화구·증류기·기중기 그대로.
- **양조 서·동**: 서 = 술통 피라미드·기중기·쇠 저장통·보일러실(화구), 동 = **술 수로**(세로, 널다리·수문 바퀴) + 건너편 증류기·화구. 키아트의 '빛나는 술 수로'를 맡는 띠.
- **양조 남**: 판잣집 지붕·큰 통 윗면·관 — 외곽 남쪽과 같은 전경 문법.
- **연회장 북**: 정확히 가운데 단상 3단 + 빈 술통 왕좌 + 바로 뒤 화로 역광(가장 밝음) + 단상 계단으로 흐르는 술 + 넘어진 잔 + 좌우 기둥·잔 문양 휘장·촛대 + 양끝 난간 너머 도시(작은 호박 창). 키아트 hall b 의 대칭 구도와 같음. 보스는 그리지 않음(스프라이트가 왕좌 앞에서 시작, 52라운드 배치).
- **연회장 서·동**: 난간 안쪽 좁은 테라스(기둥·휘장·촛대·넘어진 벤치·술통) + 난간 + 바깥 낭떠러지 아래 도시.
- **연회장 남**: 난간을 위·뒤에서 본 전경. 난간 사이·위가 **흰 바탕**으로 나왔고 가운데가 번졌다 → 흰색은 '난간 너머로 보이는 바닥' 자리라 투명으로 빼면 오히려 맞음(`white_key`), 번진 구간을 피해 깨끗한 기둥 1주기(원본 x 78~1630, 주기 1478)만 반복. 재생성 안 함.

## 4. 골목 입구 조각 (Q13)
- 생성: 지역당 1회, 16:9 한 장에 패널 3개(1 = 북쪽 벽 입구, 2 = 서쪽 입구, 3 = 남쪽 출구). 검은 간격 자동 검출로 패널을 자름.
- **북 = 패널 1**(5지역 모두 우수): 외곽 = 두 반목조 집 사이 아치 골목 + 등불, 황무지 = 흙둑을 뚫은 길 + 부서진 말뚝 문 + 혼불, 성문 = 작은 옆문(창살·터널 빛·횃불 2), 양조 = 벽돌 아치 수레 입구(열린 쌍문·안쪽 술통·등불), 연회장 = 기둥 사이 아치 + 젖혀진 휘장 + 촛대.
- **남 = 패널 3**: 외곽 돌계단, 황무지 모래주머니 사이 참호 길, 성문 도개교(대각선), 양조 철 계단, 연회장 넓은 계단.
- **서 = 조립**(패널 2 미사용): 패널 2 는 5지역 모두 대각선(아이소메트릭) 원근이라 게임 카메라와 맞지 않음. 추가 호출 대신 **그 지역 Gemini 띠를 같은 축척으로 조립** — 위 = 북 띠의 집·둑·성벽 앞면(골목 북쪽 면, 아래를 향함), 가운데 = 골목 바닥(북 띠 기준선 아래 땅 줄을 흐리게 펴서 서쪽으로 어두워짐), 아래 = 남 띠 윗단(골목 남쪽의 지붕·둑·난간이 골목 가장자리를 덮음). **동 = 서 좌우 반전**.
- 축척: 패널은 생성 축척이 띠와 달라 술통·문 높이로 맞춤(외곽 0.63, 황무지 0.64, 성문 0.67, 양조 0.6, 연회장 0.45).
- 처리: 띠와 같은 LUT·발광 분리, 좌우·위 페이드(북), 좌우·위아래 페이드(남, 전경 곡선), 왼쪽·위아래 페이드(서).

## 7. 자기 비평 기록 (see → critique → fix)
1. **생성**: 황무지 north_a 오른쪽 절반 열림 → b 재생성(위 3절). 연회장 남 흰 바탕·번짐 → 재생성 대신 흰색 투명 + 깨끗한 1주기. 조각 패널 2(서) 대각 원근 → 조립 방식으로 전환(호출 3회 절약).
2. **조립 1회차**: 골목 바닥에 같은 땅 줄을 쌓아 줄무늬·상자가 반복돼 보임 → 땅 줄을 흐리게 펴 평균색과 섞음.
3. **목업 1회차**: ① 연회장은 카메라(위로 110)가 화로 불꽃을 잘라 키아트 핵심이 안 보임 → 연회장 목업 주인공을 보스 시작 자리(왕좌 앞, 북쪽 끝 가까이)로. ② 주인공 발광색 누락(목업 버그) 수정. ③ 연회장 서·동 조립의 남쪽 난간에 흰 틈 → 조립에도 white_key 적용.
4. **목업 2회차**: ① 구판 바닥 채도가 떠 키아트와 어긋남 → 바닥에 같은 톤 LUT. ② 황무지 화면 맨 위 검은 줄(카메라가 띠 위끝 너머) → 카메라 위 한계(`-baselineY`) 고정. ③ 서·동 조립 골목이 거의 검정이라 Q13 에서 미채택한 '잘라낸 어둠'처럼 보임 → 바닥 최소 명도 0.10 → 0.30, 북쪽 면 어둡힘 완화.
5. **3회차(조각 나란히)**: 연회장 서 조립의 북쪽 면에 단상 계단이 잘려 들어옴 → 기둥·촛대 구간으로 이동. 이음새 초과 띠(황무지 동 17.1, 양조 동 11.3·남 10.0, 연회장 남 16.0) → 감싸기 겹침·자르기 조정으로 7.2·3.7·4.6·1.8.
6. **키아트와 나란히(최종)**: 성문·양조·연회장은 덩어리·광원 배치가 키아트와 거의 같다. 외곽은 시범과 같음. 황무지는 둑·말뚝·폐가·지평선 성곽은 같지만 키아트의 '흩어진 혼불 여럿'이 북 띠에서 빠져(앞 땅을 버림) 어둡다.

## 8. 남은 약점
- 전체 명도: 지시대로 바닥 v2 의 약 0.85배 + 중립 주변광이라 키아트(중간 회색 하늘·벽)보다 화면이 훨씬 어둡다. 키아트 유사도만 보면 테두리 명도 곡선을 올리는 편이 점수가 높을 수 있음(질문 2).
- 황무지 북 띠 광원 1개(모닥불) — 혼불이 둑 위·앞에 거의 없음. 조각(북)의 혼불 1개가 보탬.
- 서·동 조각은 그림 생성이 아니라 띠 조립이라 '골목 속'이 단조롭다(어두운 바닥 + 양쪽 면). 키아트 수준의 골목 그림을 원하면 측면 전용 1회씩 필요(질문 3).
- 성문 남쪽 조각(도개교)은 대각선 원근 — 남 출구가 도개교로 쓰일 때 어색할 수 있음.
- 연회장 남 띠는 1주기 589 논리 px 반복 — 같은 기둥·항아리가 화면에 2번 보임(난간이라 자연스러운 편). 그 아래 '멀리 도시'는 그려지지 않고 어둠.
- 양조 동쪽 수로는 띠 전체가 빛남(0.55배로 낮춤) — 52라운드 Q8 '다리 근처만 밝게'와 완전히 같지는 않다.
- 성문·양조·연회장 북 띠 광원 10~14개 + 서·동 4~9개 — 시스템 광원 예산에 따라 `light_cap` 으로 더 줄일 수 있음.
- 조각 축척은 술통·문 높이 눈대중이다(±10%).
- 목업 바닥(4지역)은 구판 근사라 바닥과 테두리의 이음(질감)은 v2 바닥이 생긴 뒤 다시 봐야 한다.
