## 3. 채택 이유 (키아트 유사도 우선)
- **북**: 키아트의 반목조 집·돌출 상층과 받침 까치발·처진 기와·굴뚝 연기·덧창 호박빛·잔 모양 간판(글자 없음)·빨래줄·아치 골목·술통·자루·좌판 천막이 그대로 들어왔고, 뒤로 지붕이 2~3겹 흐려지며 깊이가 난다. b 는 발코니 집·술통 헛간·바깥 계단·닫힌 술 좌판·반지하 아치 문빛으로 겹치는 집이 없다.
- **서**: 연석 옆 3단 돌계단과 쇠 난간, 계단식으로 쌓인 집(앞면 + 지붕), 술통·상자 더미 — 카메라 각도가 바닥 쿼터뷰와 가장 잘 맞는다.
- **동**: 도르래 들보에 술통이 매달린 창고, 술통 피라미드, 내려가는 계단과 문빛, 버팀벽 높은 담, 손수레, 선술집 뒷문 — 외곽(빈민) 서쪽과 대비되는 '술 창고 뒷마당'.
- **남**: 전경 지붕을 위·뒤에서 본 모습(지붕창·평지붕 술통·굴뚝). 키아트에는 없는 부분이라 같은 문체만 맞추고 어둡게 눌렀다.

## 4. 보정 (`build.py`)
1. 원본 1px → 저장 0.8px (LANCZOS). **네 띠 같은 축척** → 그림 속 술통·문 크기가 띠마다 같다(문 ≈ 논리 120px, 술통 ≈ 45px, 주인공 72px).
2. 이음: 북 = a(0~4128) ⊕ b(176~3936, 양 끝 검은 실루엣 제거)를 겹침 40px 최소 오차 세로 경로로 잇고 좌우 감싸기 56px. 서·동 = 위아래 감싸기 72px. 남 = 좌우 64px.
3. 발광 마스크: 밝기 > 100 이고 따뜻함(R−B) > 55 인 픽셀(창·문빛·등불) → `*_emissive.png`(톤 맞춘 원색, 알파 = 세기).
4. 색조: `gkit.tone_match` 와 같은 사영(무채 G00~G15 ↔ 1층 램프 16~27)을 33³ 3D LUT 로 적용. 도트화·감색 없음.
5. 알베도 명도: 바닥 v2 알베도(평균 루마 64)와 같은 조명 공간에 두고 약 0.85배(벽 곡선), 하이라이트는 눌러 구운 빛 웅덩이를 약하게. 발광 자리는 0.3배로 어둡게 → 빛은 emissive 가 더한다. 남 = 전경 곡선(최대 76).
6. 알파: 북 = 기준선 아래 앞치마 페이드, 남 = 기준선 위 하늘을 투명(열마다 위에서 아래로 첫 물체까지) + 아래 끝 56px 어둠 페이드, 서·동 = 불투명.
7. 광원: 발광 마스크를 저장 8px 격자로 묶은 덩어리 → 중심·평균색(램프 쪽으로 밝힘), 반경 = 40 + 3.2√면적(50~150), 세기 = 0.4 + 0.015√면적(0.4~0.95), 26px 안은 합침. 면적 1200 이상 = `door_or_lantern`(깜빡임 0.08), 나머지 `window`(0.04).

## 6. 자기 비평 기록 (see → critique → fix)
1. **생성 단계**: south_a 번짐 → 4번 참고(west_a)를 넣고 "no smears, no fog" 로 b. b 는 또렷하지만 지붕선 높낮이 문제 → 3회차 목업 뒤 c(처마선 연속 지시) 생성, 위쪽만 채택.
2. **1회차 산출**: 남쪽 하늘 누름이 평지붕 납판(하늘과 비슷한 색)까지 먹어 얼룩 → 위 하늘과 이어진 영역만 채우는 방식으로 변경. 전경 곡선이 너무 검어 형태 소실 → 상한 56 → 76.
3. **1회차 목업**: ① 창 하나까지 반경 170·세기 1.0 (면적을 합친 공식 탓) → 반경·세기 공식 재설정, 창 ≈ 110 · 문 150. ② 조감도 왼쪽 위에 정체 모를 빛 얼룩 = 북쪽 띠에 가려진 서쪽 띠 광원 → 바닥 세로 범위 밖 측면 광원은 등록하지 않는 규칙(`lightsRule`). ③ 남서 카메라 계산 오류(왼쪽 한계 -56) → -200.
4. **2회차 목업**: 남쪽 b 의 직선 검은 판 → south_c 로 교체(문제 해결 확인). 기준선 위 겹침은 약 10px 로 줄어 남쪽 끝 캐릭터 가림이 거의 없다.
5. **3회차(키아트와 나란히)**: 테두리 문체·소품·호박빛은 키아트와 거의 같다. 다른 점 = 화면 전체가 남색으로 기움(v2 주변광 청색 편향) → 중립 주변광 비교안을 만들어 인터뷰로. 바닥 v2 판석은 키아트의 젖은 포석보다 규칙적이고 어둡다.
6. **남은 약점**
   - 바닥 소품(v2 32px 술통·상자·등불)이 주인공 1.5배·테두리 그림 속 술통(약 2배)보다 작아 보인다 → 소품 크기 재검토 필요(Q4).
   - 서·동 띠는 자체 광원이 띠 바깥쪽에 2개뿐이라 안쪽이 어둡다(형태는 읽힘).
   - 남쪽 지붕창 '갈라진 호박빛'(발광 3곳)이 문양처럼 보일 수 있다 — 빼도 무방.
   - 북쪽 a·b 그림의 바닥 포석 앞치마(32px)가 v2 도트 판석과 질감이 달라 가는 띠로 보인다(바닥 그늘 53 과 겹쳐 완화됨).

## 7. 시스템 구현 규칙 (제안 — `border.json` 에도 기록, 계약 §13 세부 확정 대상)
- **그리기 순서**: 바닥 → 바닥 데칼·바닥 그늘 → 서·동 띠 → 북 띠 → Y 정렬 층(소품·캐릭터·이펙트) → 남 띠(전경) → 조명(곱하기) → 발광(가산: 알베도 위에 `*_emissive` rgb×알파) → UI.
- **배치**: 북 띠 `baselineY` 줄 = 바닥 북쪽 끝(벽 앞면 아랫단 밑변), x 는 (바닥 왼쪽 − 256)부터 3107 주기로 반복. 남 띠 `baselineY` 줄 = 바닥 남쪽 끝. 서 띠 오른쪽 끝 = 바닥 서쪽 끝, 동 띠 왼쪽 끝 = 바닥 동쪽 끝, 세로 1615 주기 반복(북·남 띠 아래로 들어감).
- **Y 정렬·가림**: 북·서·동 띠는 Y 정렬에 참여하지 않는 배경(항상 캐릭터 뒤). 남 띠는 항상 앞. 남 띠의 불투명 픽셀이 플레이어 몸 사각형과 겹치면 그 띠를 `fadeAlpha` 0.45 로(겹침 높이가 작아 드물다).
- **충돌**: 격자 그대로. 테두리는 벽 칸 위에 덮는 그림이며 충돌을 바꾸지 않는다. 테두리가 있는 지역에서는 벽 타일(앞면 2칸·윗면·가장자리)을 그리지 않는다. 북 앞치마(포석)는 바닥 위 그림일 뿐 막힘 없음.
- **조명**: 테두리 알베도는 바닥과 같은 곱하기 조명을 받는다. `lights[]` 를 띠 주기마다 등록하되 서·동 띠의 광원 중 바닥 세로 범위 밖은 빼기. 발광 PNG 는 조명 뒤에 더해 어둠에 묻히지 않게.
- **카메라(제안)**: 위 한계 = 북 띠 위끝(바닥 북쪽 끝 −377), 아래 = 남 띠 아래끝(+111), 좌우 = 바닥 끝 ±200. 주인공이 북쪽 끝 200 이내면 카메라 중심을 최대 110 위로(`northLookUp`) — 그래야 집 2층·지붕이 화면에 들어온다(Q2).

## 8. 다른 지역 확장 계획
- 같은 틀: 지역마다 북(4:1 2장 이어 붙이기)·서·동(1:4)·남(8:1) = 5회 + 예비 1~2회. 문체 참고 = 그 지역 `keyart_<region>`, 카메라 참고 = `concept_v2_<region>` 채택안, 3회차부터 그 지역 북 a 를 함께 넣어 축척 통일. build.py 의 `BANDS` 표만 지역별로 늘린다.
- 지역별 띠 내용(개념도 NOTES_concepts 4절 기준): **황무지** 북 = 흙둑 + 말뚝 울타리 + 폐가 앞면, 남 = 낮은 모래주머니 담. **성문** 북 = 성벽 3칸 + 망루 + 반쯤 올린 창살(문빛), 남 = 해자 + 도개교(입구). **양조** 북 = 그을린 벽돌 증류소 + 화구 2 + 지붕 위 증류기, 서·동 = 술통 피라미드·기중기. **연회장** 북 = 단상 + 술통 왕좌 + 화로, 남 = 돌 난간 너머 낭떠러지(원경 도시).
- 1회 생성으로 남 띠가 처마선 연속을 잘 따르지 않으므로(5·6번) 처음부터 "continuous, no gaps" 지시를 넣는다.
