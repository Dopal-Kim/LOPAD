## 2. 각 안의 특징

### 칼 (katana)
- **A (raw_katana_A)**: 이 빠지고 녹 슨 휜 외날, 등줄기 실금에서 혼불이 새고 칼끝에서 작게 타오름. 붕대 감은 손잡이에 못 하나, 녹슨 원판 코등이, 금 간 옻칠 칼집을 붕대·끈으로 묶음. 이펙트 = 가는 호박 초승달 궤적 + 녹 부스러기·불티.
- **B (raw_katana_B2)**: 몸과 같은 검은 재 껍데기 칼날, **날 전체가 호박 균열 한 줄**로 빛남. 흉갑 조각 코등이, 붕대 손잡이, 몸처럼 금 간 재·흙 칼집(빛나는 이음매). 이펙트 = 굵은 호박 초승달이 곧바로 회색 재 장막과 불티로 부서짐.

### 대검 (greatsword)
- **A (raw_greatsword_A2)**: 시대 그대로의 츠바이헨더(긴 십자 코등이·리카소 갈고리·가죽 감은 리카소). 녹슬고 이 빠진 날, 박힌 화살 하나, 가장 깊은 홈에서 혼불이 숯불처럼. 가죽 끈으로 등에 사선으로 멤. 이펙트 = 흙먼지를 끄는 넓은 호 + 내리찍어 땅이 갈라지며 호박빛.
- **B (raw_greatsword_B)**: 창날·흉갑 조각·화살·못이 재·흙에 반쯤 박힌 채 굳은 넓은 판(끝이 각진 막날). 주인공 가슴과 같은 호박 균열, 균열에서 연기. 코등이 = 휜 창자루. 끈 없이 등 균열에서 나온 혼불 실로 등에 붙음. 이펙트 = 휘두를 때 재·흙 덩이가 떨어져 흩날리는 호 + 땅 균열.

### 단검 (dagger)
- **A (raw_dagger_A2)**: 론델 단검(원반 코등이·원반 폼멜, 갑옷 틈 찌르기용) — 녹 슨 송곳날, 금 간 원반, 못 박은 붕대 손잡이. 혼불이 날 뿌리에서 새어 끝에서 녹아 떨어짐. 역수. (1회차 raw_dagger_A 의 '짧은 찌르기 + 숫돌 불꽃 같은 짧은 호박 줄' 이펙트 컷이 더 좋음.)
- **B (raw_dagger_B)**: 자기 재 껍데기에서 부러낸 송곳니 모양 조각. 균열 사이 호박 속살, 백열 끝. 밑동에 붕대 + 녹슨 못. 이펙트 = 공중에 가는 호박 금이 남았다가 재로 떨어짐, 손 잔상. (정수로 그려짐 — 도트는 기존 역수 동작 유지.)

### 활 (bow)
- **A (raw_bow_A2)**: 주운 장궁 — 가운데 금 간 활대를 붕대·못 두 개로 부목. 해진 삼 시위. **화살은 자기 몸에 꽂힌 화살을 뽑아 쓴다**(휴대 모습 = 왼손에 활, 오른손이 어깨의 화살을 뽑음). 메기면 촉이 호박빛. 허벅지 화살통. 이펙트 = 가는 호박 직선 궤적 + 재 꼬리, 꽂힌 자리 불티 고리.
- **B (raw_bow_B)**: 재·흙 활대(창자루 심) + 호박 균열, 양 끝은 갑옷 조각. **시위가 혼불 한 줄**(그림 속 유일한 빛나는 선). 당기면 재 화살대 + 타는 촉이 생김. 이펙트 = 재·불티를 끄는 화살 + 시위가 튕길 때 짧은 번쩍임.

## 4. 추천안과 이유 (임시 — 도영 님 결정 대상)

**전체 B 계열(재·흙 + 혼불 균열)로 통일, 활만 A 의 '몸에서 화살 뽑기' 장전을 섞는 조합 (추천).**
1. 53라운드 피드백의 핵심이 "지금 주인공과 어울리지 않는다" 였다. B 는 무기가 주인공 몸과 **같은 재료·같은 균열·같은 혼불**이라 한눈에 한 몸이다. A 는 그림으로는 좋지만 연결 고리가 붕대·실금 정도.
2. 판독성: 어두운 바닥 + 숯빛 몸에서 B 는 4종 모두 '좋음 이상'(호박 선·밝은 재 판). A 는 단검·활이 약함.
3. 개성 있는 무기 표현(분위기 참고): B 는 실루엣이 4종 모두 고유하다(빛나는 날선 칼, 잔해 판 대검, 송곳니 조각 단검, 혼불 시위 활).
4. 진화(개성 변화) 여지: B 는 균열이 넓어지고 박힌 잔해가 바뀌는 식으로 단계 표현이 자연스럽다.
5. 활 A 의 '자기 몸에 꽂힌 화살을 뽑아 쏜다' 는 주인공 설정(꽂힌 화살)과 가장 잘 맞는 이야기라 장전 동작으로 살린다(B 의 재 화살은 시위에 메기는 순간 생기는 것으로).

무기별 단독 추천: 칼 **B**(A 도 판독 좋음 — 차선) · 대검 **B** · 단검 **B** · 활 **B + A 장전 연출**.

## 5. 자기 비평 (see → critique → fix)

1. **글자**: 1회차 8장 중 3장(칼 B·대검 A·활 A)에 라벨 글자. 꼬리의 "no text" 만으로는 부족했다 → 2회차에서 맨 앞에 "글자 없음" + 번호 배치 문장을 산문으로 → 4/4 글자 없음. **교훈: 배치를 (1)(2)(3) 으로 나열하면 칸 제목을 쓰는 경향.**
2. **칼 B 형태**: 1회차 단독 그림이 곧은 양날 + 십자 코등이(칼이 아님) → 2회차에 '휜 외날·둥근 코등이·십자 없음' 문단 → 반영.
3. **역수**: 단검 1회차 A·B 모두 정수로 쥠. 2회차 A 는 대체로 역수, B 는 한도 때문에 재생성하지 않음 → 도트는 기존 역수 동작(hero_v3 §8) 그대로.
4. **휴대 모습**: 대검 A 1회차는 등에 멘 칼이 몸 앞에 걸친 것처럼 보임 → 2회차 뒷모습 지시로 해결. 칼 A·B 휴대는 칼집을 몸 앞쪽에 비스듬히 — 기존 v3 칼집 방향(SAYA_DIR, 배 앞을 가로지름)과 비슷해 그대로 써도 됨.
5. **불꽃 과다**: 여러 장에서 무기에 열린 불꽃 → 도트에서는 판정 프레임에만(3절 공통).
6. **이펙트 컷**: Gemini 의 초승달 궤적은 두껍고 부드러운 그림 — 2배 밀도 도트 이펙트로는 '분위기·색 순서'만 가져온다(호박 → 재 회색으로 부서짐 / 대검은 흙먼지 + 땅 균열 / 단검은 짧은 숫돌 불꽃 줄 / 활은 직선 궤적 + 재 꼬리). 단검 A2·B 의 공격 컷은 인물이 잘린 흉상이라 약함 — 이펙트 참고는 단검 A1.
7. **주인공 일관성**: 12장 모두 hero3_b 정체성(얼굴 가면·왼눈 하나·어깨 불꽃·꽂힌 화살·흉갑·붕대) 유지. 일기장이 주머니처럼 그려진 장이 있음 — 도트는 바이블대로.
8. **판독 시험의 한계**: 그림을 줄인 것이라 실제 도트보다 흐리다. 명암 대비 비교용일 뿐이며, 도트 오버레이 단계에서 1배 조명 목업으로 다시 본다.
