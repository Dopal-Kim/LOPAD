## 3. 프롬프트 요약
- 공통(`style_keyart.txt`): 어둡고 처절한 키아트, 읽기 쉬운 덩어리·평평한 음영, 숯·재 회색 + **호박 잔불 한 색**(#8b4d22·#d67a11·#e8b858·#faeec0)만, 다른 색상 금지, 르네상스 초기 화약 시대(장창·장궁·화승총·진흙·보급 마차·반목조 집·참나무 술통), 판타지는 드문 기이함으로만, 건조한 해학이 깔린 거친 개척지 서부극 + 다크 판타지 분위기(특정 작품 복제·언급 없음), 글자·로고·UI·워터마크 금지.
- 지역별 장면은 `<id>/prompt*.txt` 전문. 2~7번은 `style_ref.txt`("첨부 이미지와 같은 문체·밀도·팔레트, 구도는 재사용 금지") + 1번 원본을 참고로 넣어 시리즈 통일.
- 지도: 가장자리까지 꽉 찬 일기장 양피지 지도, 사선 3/4 그림 기호, 오른쪽으로 갈수록 작고 어두워지는 원근, **가운데 30~70% 높이 띠는 빈 종이 + 길**, 강조는 잔 문양·불씨에만 호박색, 글자 금지.

## 4. 보정 단계 (`build.py` · `gkit.py`, Pillow 만)
1. `fit_crop` — 1376×768 → 960×540 (LANCZOS, 가로 몇 px 자름).
2. (지도만) `erase_dashes` — 넓은 밝은 길 띠(14px 상자 평균 ≥ 0.50) 안의 가는 어두운 점선을 중앙값으로 지움. 지도 자체 점선이 UI 노드 연결선과 겹쳐 두 겹 점선이 되던 문제(목업 1회차 비평).

## 6. 임시 결정 · 남은 질문
1. **팔레트 축**: 키아트 = 무채 16 + 1층 램프 12, 지도 = 세피아 S0~S4 + 1층 램프(잔 문양·불씨). 지도는 UI 레이어라 세피아를 썼고 키아트는 장면 그림이라 세피아를 쓰지 않음.
2. **'감색' 해석**: 방향 변경에 따라 투입본은 '팔레트 색조 맞춤(연속 톤)' 이고 28색 고정이 아니다. 엄격한 팔레트 고정이 필요하면 `alt_quant.png` 방식(도트 배율 1로도 가능)으로 바꿀 수 있다 — 검수 대상.
3. **지도 비율·노드 자리**: 길이 왼쪽 위 → 가운데 아래 → 오른쪽 위로 휘어 있어 노드 열이 길을 따라 위아래로 움직인다(목업 참고). UI 가 노드 좌표를 지도에 맞출지, 지도를 노드 배치(열 간격)에 맞춰 다시 만들지 UI 와 합의 필요. 연회장(보스 노드 자리)은 오른쪽 위 (855,220) 근처.
4. **2층 '패'** 키아트·지도는 후속(같은 `style_keyart.txt` 틀에서 색만 2층 램프로).
5. 지배자 해석: 이번 그림은 도영 님 원문대로 **술에 잔뜩 취한 지배자**. 스토리 바이블 표의 1층 보스는 "양조장주 '취하지 않는 자' — 모두를 취하게 하고 혼자 깨어 있다" 라서 충돌 가능 — 스토리 확인 필요.
6. 원경 배경은 맵 시점 재설계 결정 후 다시 개시(계약 §8 원경 항목은 보류 상태로 남음 — 프로듀서가 계약 문구 정리 필요).
