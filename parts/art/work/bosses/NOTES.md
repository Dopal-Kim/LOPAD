## 디자인
### stage1 양조장주 '취하지 않는 자' (32×48)
- 실루엣: 민머리 큰 머리(12폭) → 술통처럼 부푼 거구 몸통(최대 26폭) → 굵은 다리·장화. 롤업한 린넨 셔츠(G12) 위 가죽 앞치마(G06)·허리띠, 왼쪽 허리 국자, 오른쪽 허리띠에 술병.
- 눈: 가는 눈 = 검은 눈꺼풀 1px + 호박 눈빛 23 (1px). 공격 예고 프레임에서만 25 로 밝아진다. 굵은 눈썹 능선(G07)과 콧수염(G05)으로 '맨정신의 날카로움'.
- 소지품: **통나무 망치** — 평소에는 지팡이처럼 땅에 짚고 서 있다(자루 G06/G03, 통나무 머리 7×5 G07, 절단면 G08). 공격에서 머리 위로 들어 올렸다가 **배 앞에 가로로 안고 돌진**(공성추). 일반 적 결사병의 '어깨에 멘 망치'와 구분되는 실루엣.
- 강조색 4: 눈 23, 예고 눈빛 25, 앞치마 술 얼룩 19/21, 술병 21. 무채 11 (G00,01,03,05,06,07,08,09,10,12,14) — 예산 12+6 안.
- 방향별: down = 망치 화면 오른쪽(그의 왼손) / up = 망치 화면 왼쪽, 등에 X 자 앞치마 끈 / left = 망치 전부 보임(앞 바닥), 술병 앞 허리 / right = 망치 자루가 등 뒤로 올라가고 통나무는 뒤 바닥, 술병 앞 허리. 공격 ram 자세는 4방향 모두 통나무가 몸 앞으로 나와 보인다(후면은 양 끝만).
- 사망: 충격(눈 감김) → 휘청 → 주저앉음(몸통 4px 압축) → 앞으로 꺾임(7px) → 술통처럼 옆으로 누움(장화·망치 떨어짐, 병 깨져 술 21) → 안착(술 웅덩이 넓어짐, 눈빛 꺼짐).

### emperor 황제 '평(平)' (48×64)
- 실루엣: 뒤로 넘긴 은발(G13/G11), 긴 얼굴, 높은 흰 깃(G14), 어깨 18폭에서 밑단 24폭으로 살짝 퍼지는 긴 외투(G12, 그늘 G10, 빛 G14), 검은 장갑·장화(G01). 어깨에서 허리로 내려오는 어두운 띠(G06)와 가슴의 훈장.
- 1층 램프로 그렸다: 외투는 무채 G12 라 어느 층에서도 그대로이고, 강조는 **눈 23 · 훈장 21** 2슬롯뿐. 8층 램프(은빛 흰, s0.12)로 스왑하면 눈·훈장이 거의 무채 흰빛이 된다.
- 소지품: 오른손(화면 왼쪽) 서류 뭉치(G14, 글줄 G10), 왼손(화면 오른쪽) 지휘봉(G01 자루, 양 끝 G13). 위압보다 '질서'의 정적인 자세 — idle 은 1px 숨과 서류 한 장 넘김, 머리 1px 기울임뿐.
- 무채 11 (G00,01,03,06,07,09,10,11,12,13,14) + 강조 2.
- 공격: 1 예고 = 가벼운 목례 + 지휘봉을 가슴 앞 가로로 / 2·3 돌진 = 지휘봉을 앞으로 겨누고 외투 뒷자락이 날림(flare 2→3) / 4 = 지휘봉 옆으로 휘두름(부채꼴 탄 발사 자세 겸용).
- 사망: 충격 → 물러섬 → 한쪽 무릎(외투가 바닥에 퍼짐) → 머리 숙임 → 옆으로 누움(서류 흩어짐·지휘봉 떨어짐) → 안착(서류 한 장 더, 눈빛 꺼짐).

## 시스템 전달 요점 (보스 패턴 ↔ 프레임 매핑)
- attack JSON 에 `phaseFrames: { telegraph: [0], dash: [1, 2], recover_or_fan: [3] }` 를 넣었다 (0부터 세는 열 번호).
  - **frame 0 = 예고**: `phase.dash.telegraphMs` 동안 유지 (양조장주는 통나무를 머리 위로, 눈 25; 황제는 목례 + 지휘봉 가슴 앞). JSON 의 350/300ms 는 참고값이고 실제 길이는 시스템의 telegraphMs 를 따르면 된다.
  - **frame 1·2 = 돌진**: `durationMs` 동안 1↔2 를 150ms 씩 반복 (다리 교차·통나무/지휘봉 앞으로). 벽 충돌 `wallStunMs` 중에는 frame 3 유지 또는 hurt 2번째 프레임 사용.
  - **frame 3 = 휘두름/복귀**: 부채꼴 탄(`fan`, `afterDash: true`)의 발사 시점에 이 프레임을 쓰면 '휘두름 → 탄 퍼짐' 으로 읽힌다. 탄 자체는 시스템/이펙트.
- 피벗은 발바닥 중앙 고정: stage1 (16,47), emperor (24,63). 돌진 중 몸 전진은 프레임 안에서 ±2px 만 넣었고 실제 이동은 시스템.
- `data/bosses.json` 의 size 는 [40,40]/[48,48] 인데 스프라이트는 32×48 / 48×64 다. 바디는 발밑 정렬이면 된다 (적 연동과 같은 방식).
- 2~7층 보스는 29라운드 결정 F 대로 `stage1_*` 시트를 그대로 쓰고 층 램프 스왑 (눈·얼룩·병 색이 층색으로 바뀜). 황제도 1층 램프로 그려져 있으므로 8층 램프 스왑 대상.
- 그림자(발밑 타원)는 시스템이 그린다. 폭은 보스 몸통 폭(stage1 ≈ 26px, emperor ≈ 20px) 기준 권장.

## 임시 결정 (도영 님 복귀 후 검토)
1. 1층 보스 파일 이름을 `data/bosses.json` 의 키 `stage1` 로 했다 (`stage1_idle.png` 등). 2~7층 램프 스왑 대체도 같은 시트.
2. 양조장주 소지품은 국자 대신 **통나무 망치**를 주역으로 (국자는 허리에 소품으로만). 돌진 패턴과 맞물리는 '공성추' 연출 때문.
3. 양조장주 눈을 양쪽 다 호박색(2px)으로 — 주인공(한쪽만)과 대비되는 '전부 기억하는 눈'.
4. 황제 외투 색은 무채 G12 (은빛 흰). 8층 램프의 저채도 흰과 겹치지 않도록 강조는 눈·훈장만.
5. attack 4번째 프레임을 '휘두름'으로 만들어 부채꼴 탄 발사 자세를 겸하게 했다 (별도 fan 동작 시트 없음).
6. 보스 피격 플래시 G14 는 적과 같은 규칙(예산 밖 1색, 양조장주는 셔츠 하이라이트와 공유).
7. 타이밍 ms 표 전체.
8. 사망 연출(술통처럼 눕는 양조장주 / 무릎 꿇고 옆으로 눕는 황제).

## see→critique→fix 기록
1. 1회차: up 뷰 팔 중복 그리기, 술병이 팔과 겹침, 좌향 뷰 몸통 가장자리·통나무 절단면의 빛 방향 반전(절차적 그리기에 LIGHT_SWAP 을 잘못 적용 — 빛은 좌상단 고정이므로 지도 미러링에만 swap), 사망 3·4프레임 머리 공중 부양(crouch 이중 가산), 황제 지휘봉 G03 이 바닥 G04 에 묻힘, 더미 프레임이 사람으로 안 읽힘(장화 추가).

3. 3회차: 확인. 고립 픽셀 stage1 0 / emperor 11 (sweep 프레임 1px 사선 지휘봉, 8방향 연결 — 바이블 3.1 허용), 반투명 0, 색 11+4 / 11+2.
