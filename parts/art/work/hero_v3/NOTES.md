## 0. 1.5배 방식 (최근접 확대 아님)

- 골격·자세 코드는 그대로 '설계 좌표'(64×96 판 치수, 피벗 (32,92))로 두고, `v3kit.Rig3(S=1.5, src=(32,92), dst=(48,138))` 가 모든 도형(다각형·타원·캡슐)·반지름·셰이딩 흐림을 1.5배로 변환해 **96×144 에서 다시 래스터·셰이딩**한다. 셀아웃·가장자리 빛·겹침 그림자·내부 선은 새 해상도에서 1px 로 다시 계산 → 선이 상대적으로 가늘고 부드러워짐.
- 1.5배 해상도에서 새로 그린 세부(도트 좌표): 얼굴(눈두덩 다각형·분노한 눈 2줄·광대 빛/패임·콧등·입), 정수리 균열 그라데이션 + 잔가지, 관자놀이 실금, 갈비 능선(빛 + 그늘 2줄)·쇄골, 가슴 균열 아래 잔가지·바깥 잔광, 흉갑·견갑·정강이받이 리벳·긁힘·가장자리 빛, 붕대 감긴 결(정강이·두 손), 완갑 끈, 허리천 주름·찢김, 일기장 테·종이 단면·걸쇠(3px)·그을린 모서리, 허리끈 매듭, 혼불 7×10 6모양(떨어져 나가는 불씨 조각), 재 파편 3px 비늘, 바닥 일기장 18×10.

## 2. 무기 든 느낌 (53라운드 피드백 대응)

- 대기·걷기·달리기: **왼손이 칼집 입구 바로 뒤를 쥐고 엄지로 코등이를 누른다**(`katana3.saya_hold` — 1차 골격으로 입구를 찾아 왼손 IK 목표). 손 픽셀 위 칼집·코등이는 오버레이에서 지워 손이 칼집을 감싼다. 걷기·달리기에서 왼팔은 흔들지 않고 칼집을 눌러 잡는다(오른팔만 흔듦).
- 칼집 폭 3→5줄, 반사 띠·쇠 장식·밝은 끈으로 어두운 바닥·허리천 위 대비 강화(1배 목업에서 칼집이 선으로 읽힘).
- 뽑아 든 휴대(`katana_carry_drawn_*`): 대기·걷기 = 오른손에 앞·아래·바깥으로 낮게 든 칼, 달리기 = 뒤로 끌며 수평에 가깝게, 대쉬 = 뒤로 곧게. 몸 시트는 칼집 휴대와 같은 것을 쓴다(왼손은 빈 칼집 입구).

## 3. 보폭 (stride) 근거

- 시스템 보고: 실제 걷기 이동 = 논리 **192 px/s**. 몸 키 72 논리 px(≈1.8 m 로 보면 40 px/m) → 192 px/s ≈ 4.8 m/s = **사람의 달리기 속도**. 걷기 동작으로는 발이 맞을 수 없다.
- 걷기: 다리(허벅지+정강이 31.6 설계)와 엉덩이 높이(27)로 무릎이 거의 펴지는 한계가 앞뒤 ±16 설계 → 자연스러운 큰 걸음 ±12(9→12), 주기 800→640ms(빠른 전투 걸음 3.1보/s). 한 주기 72 도트 = 36 px / 0.64 s = **56 px/s**. 192 px/s 에서 배속 3.4 → 상한 2 에 걸려 발이 192 vs 112 로 약 40% 미끄러진다(64×96 판 22.5 px/s 대비 77% → 40%). 걸음을 더 키우면 다리가 펴져 뻣뻣하고, 주기를 더 줄이면 상한 2 배속에서 0.32 s/주기로 다리가 헛돈다 → 자연스러움 우선으로 여기서 멈춤.
- 달리기: 체공이 있는 뛰기로 다시 짰다. 디딤발이 한 프레임에 25 도트(16.7 설계) 뒤로 밀리고 접지 2·체공 2 프레임(실제 4.8 m/s 달리기의 접지 ≈ 0.11 s·체공 ≈ 0.13 s 와 비슷). 한 주기 200 도트 = 100 px / 0.52 s = **192.3 px/s → 배속 1.0, 미끄러짐 없음**. 걸음 길이 = 키의 0.7배, 3.8보/s.
- 그래서 **이동 속도 192 에서는 run 을 재생하는 것을 추천**(질문으로 올림). walk 는 느린 이동(≈ 112 px/s 이하, 배속 2 이내)용.

## 4. 구조 (코드)

- `v3kit.py` 셰이딩 렌더러 + 설계 → 도트 변환(`T`, `px`/`cdot`(부위 안에만)/`pline`/`hole`), 균열 빛 번짐을 거리 사전으로 바꿔 1.5배에서도 빠르게.
- `hero.py` 몸 Rig(정면·뒷면·측면 따로) + 대기·걷기 + 1.5배 세부 도구(`fline`·`fpoly`·`wraps`·`rivet`·`crack`·`groove`) + `scar_rect`.
- `motion.py` 달리기·대쉬·피격·사망 + 몸 밖 덧칠(재 조각, 재 무덤, 바닥 일기장) — 도트 좌표.
- `katana3.py` 칼 3D(로컬 f·r·z → 4방향 투영 → 도트) · 휴대(칼집/뽑아 든) · 연격 `COMBO` · 뽑기·넣기·패링 `MOVES`(`along` = 손잡이 축 거리, `slide` = 왼손 칼집 당김, `idle` = 다음 시트와 같은 마지막 그림).
- `anim.py` 목록·렌더 / `export.py` 시트·JSON(+ 타이밍 assert) / `preview.py` 미리보기 / `build.py` 실행(선택 렌더).
- 정리: 64×96 1단계 비교(`preview_compare_v1_v2.png`, `ref_v1/`)는 지웠다(git 기록에 있음). `ref_64/` = 이번 1.5배 전 64×96 판 사본(목업 크기 비교용).

## 5. 자기 비평 (see → critique → fix)

### 몸 전체(1.5배 재렌더)
1. 정수리 결손 2개 사이가 솟아 '뿔·고양이 귀'처럼 읽힘 → 결손을 얕게(반지름 2.3→1.7) 하나로, 새로 넣은 작은 결손 제거.
2. 측면 오른쪽 보기에서 칼이 거의 안 보이고, 정면에서 손잡이가 카메라를 향해 6 도트로 짧아 손에 가려짐 → 칼집 방향을 바깥으로(r -0.36→-0.55) 돌려 손잡이가 배 앞을 가로지르게, 왼손은 입구 '뒤'를 쥐게 → 정면·뒷면·왼쪽에서 코등이·손잡이가 손 앞으로 드러남.
3. 색 31/30 — 허리천 찢김에 WD0 새로 씀 → 셀아웃색으로 바꿔 30/30.

### 대기·걷기
1. (대기) 왼손이 칼에 닿지 않아 '그냥 서 있음' → 왼손 칼집 쥠, 칼집 5줄 + 반사 띠 + 사게오. 1배 목업에서 칼집이 허리 오른쪽(화면)으로 읽힘.
2. (걷기) 보폭 ±12 로 측면 걸음이 뚜렷, 정면 앞뒤 깊이 그대로. 왼팔 고정·오른팔 흔듦이 '칼을 잡고 걷는' 모양으로 읽힘. 오른쪽 보기는 칼이 먼 허리라 손잡이 일부만.

### 달리기
1. 구 4접지 달리기(45 도트)를 192 px/s 에 맞추려 접지 2·체공 2 로 재설계, 디딤 발 25 도트/프레임. 팔 흔들기 정규화(±13 설계 넘지 않게) — 전과 같이 정면이 제자리 뛰기처럼 보이지 않게 무릎 들림 유지.
2. 숙임 3.8→4.2, 머리 앞으로 4.5→5.0 — 측면에서 질주가 읽힘. 뽑아 든 칼(달리기)이 처음엔 다리를 대각선으로 가로질러 어지러움 → 칼 방향 (155°, -30°) → (165°, -18°) 로 뒤로 수평에 가깝게.

### 대쉬 · 피격 · 사망
1. 재 조각이 1.5배에서 듬성 → 수 ×1.3, 3px 비늘 조각 추가, 거리·중력 ×1.5. 대쉬는 자세 그대로(1.5배)로 낮은 돌진이 유지됨.
2. 사망 재 무덤·가라앉음 깊이 ×1.5, 바닥 일기장 12×7 → 18×10(종이 두 줄·걸쇠 4px·그을린 모서리) — 사망 끝이 1배에서도 '책'으로 읽힘.

### 칼 연격 1~3
1. 1.5배 칼(55 도트 날, 3줄 + 반사)로 판정 프레임 날이 정면·측면에서 선명. 1타 0프레임 칼집이 바뀐 방향(배 앞 손잡이)이라 오른손이 손잡이를 쥐는 모습이 정면에서 보임.
2. 2·3타 각도는 52라운드 승인값 유지. 판정 시점 assert 통과.

### 칼 뽑기
1. 4프레임(다 뽑음 직후) 칼이 앞·아래로 짧게 줄어 3→4 프레임이 '튐' → 칼끝이 앞·왼쪽으로 휘어 나오는 각도(-45°, -8°)로 바꿔 수평 뽑기 → 앞 → 낮은 겨눔이 이어짐.
2. 2·3프레임 손이 닿지 않는 문제(손잡이 축 40 설계는 팔 길이 26 초과) → 왼손이 칼집을 뒤로 13 당기는 사야비키(`slide`)를 넣어 오른팔이 펴진 채 닿음 — 뽑는 힘도 보임. 왼쪽 보기에서 가장 잘 읽힘.

### 칼 넣기
1. 피 털기(1) 불티 8개, 칼끝을 입구에 댄 2프레임 → 3·4·5 밀어 넣기 → 6 코등이 반짝(백열 코어 1 + 밝은 회색 4). 마지막 프레임 = 칼집 휴대 대기 0 과 같은 그림.

### 칼 특수(패링)
1. 처음 가드(날을 가로로 가슴 앞)는 측면에서 날이 카메라를 향해 사라짐 → 날을 솟은 대각선(-56°, 40°)으로, 왼손바닥이 날 등을 받침 → 네 방향 모두 막는 자세가 읽힘. 4프레임(유지) 날 호박 글로우.
