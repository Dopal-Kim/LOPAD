## 3. 구조 (코드)

- `hero.py` 몸 Rig(정면·뒷면·측면 따로) + 대기·걷기. 2단계 확장 키(`squash`·`hdx`·`handAt`(IK)·`elbow`·`armBack`·`farArmFront`·`footdx`·`glow`·`eyeOff`·`flameOff`·`flameRows`)는 기본값이면 1단계와 **픽셀 동일**(커밋본 `out/player_idle·walk.png` 와 비교해 차이 0 확인).
- `motion.py` 달리기·대쉬·피격·사망 + 몸 밖 덧칠(재 조각 `chips`, 재 무덤 `sink`).
- `katana3.py` 칼을 몸 기준 3D(앞 f · 해부 오른쪽 r · 위 z)로 한 번 정의 → 4방향 투영(`KY` 0.35). 칼 픽셀마다 깊이(gy)를 갖고, 몸 중심보다 카메라에서 먼 픽셀은 몸 실루엣과 겹치면 지운다. 쥔 손잡이는 주먹 픽셀 아래로 숨긴다.
- `anim.py` 동작 목록·렌더 / `export.py` 시트·JSON / `preview.py` 미리보기 / `build.py` 실행.

## 4. 자기 비평 (see → critique → fix)

### 달리기
1. 측면 뒷다리가 바닥을 따라 길게 끌려 '미끄러지는 다리'로 보임 / 정면 팔 흔들림이 걷기와 구분 안 됨 / 숙임이 약함 → 흔드는 다리 들림 7→13~16(뒤꿈치 차올림), 정면 손 흔들림 ±5→±8 + 안쪽 2.6, 숙임 2.7→3.2.
2. 차올림·팔 펌프는 읽히나 머리가 여전히 엉덩이 위 → `lean_body` 3.8 · `hdx` 4.5. 디딤 4프레임 발 위치를 몸 속도(5.63 도트/프레임)에 맞춰 미끄러짐 제거.

### 대쉬
1. 활공(2·3) 측면이 무릎 꿇은 런지처럼 보임(엉덩이 너무 낮고 앞무릎이 땅에 닿음, 뒷다리 끌림) → crouch 10→7, 두 발 모두 들어 공중 돌진으로.
2. 박차기(1) 뒷다리가 굽어 꿇은 듯 → 뒤로 곧게 뻗음(-19, 0). 정면은 상체 눌림(squash 0.26) + 팔이 뒤·바깥으로 끌려 '낮게 파고듦'이 읽힘.

### 칼 휴대
1. 칼집이 길고(46) 가팔라 뒷면·측면에서 지팡이처럼 땅에 닿음 / 손잡이 감은 끈 G02 가 어두운 몸에 묻힘 → 칼 50(날 37·손잡이 12)·칼집 38, 아래 기울기 축소, 감은 끈 G03 + 상어가죽 PL3.
2. 뒷면 칼집이 여전히 거의 수직 → 바닥 깊이 눌림 KY 0.5→0.35(몸 Rig 의 거의 수평 시점과 맞춤), 기울기 -0.30.

### 칼 연격
1. (1타) 뒷면 판정 프레임에서 칼이 정면(멀리)을 향해 몸에 완전히 가려 핵심 프레임에 칼이 없음 / 정면 판정 칼이 카메라를 똑바로 향해 짧음 / 왼손 '균형' 자세가 어깨까지 올라가 힘자랑처럼 보임 → 세 연격 모두 판정 프레임 칼을 호 중앙에서 30° 비껴(여전히 호 안) 정면·뒷면에서 옆으로 드러나게, 균형 손을 허리 높이로.
2. 1·2·3타 4방향 재검: 정면 판정 날이 대각선으로 선명, 뒷면은 어깨 너머로 날 끝이 보임, 3타는 머리 위 예비 동작 + 깊은 숙임으로 마무리 무게가 다름. 2타 fade 프레임 어두운 날로 다음 타 연결.

### 피격
1. 재 조각이 실루엣 안에서 시작해 거의 다 버려짐 · 색이 어두워 안 보임 / 정면 움찔이 대기와 구분 약함 → 조각을 가슴에서 바깥으로 걸어 나가 실루엣 가장자리에서 날리고(G04~G07 + 호박 불씨 2~3), 정면 머리 -4·팔 벌림 ±7.5.
2. 조각 수·크기 상향(24/16/7, 2px 조각 50%). 균열 백열(glow 2) + 어깨 혼불 눌림(행 4→3) + 회복으로 3프레임이 읽힘.

### 사망
1. 재 무덤이 어둡고 납작해 웅덩이처럼 보임 / 마지막 일기장이 9×5 로 작고 7·8 프레임에 무덤에 묻힘 / 무덤 → 빈 화면 전환이 갑작스러움 → 무덤 높이 10·밝은 재(G05~G07 윗면), 일기장 12×7 을 8 프레임부터 드러냄, 8 프레임은 낮아진 무덤 + 불씨.
2. 정면·뒷면은 숙여 앉은 머리가 낮아 7 프레임에 이미 묻혀 눈빛이 꺼지는 순간(8)이 안 보임 → 정면·뒷면 가라앉음 깊이 ×0.62.
3. 1배 목업: '사망 끝' 일기장이 바닥 위 작은 호박 조각으로 읽힘.

## 5. 남은 약점

1. 오른쪽 보기 1타 0~1 프레임(발도 시작)은 칼이 먼 허리라 몸 뒤에 가려 손만 움직인다. 왼쪽 보기 1타 4~5·2타 측면 일부도 칼이 몸 뒤로 사라진다(물리적으로 맞지만 판독은 베기 이펙트에 기댐).
2. 뒷면 판정 프레임의 칼은 어깨 너머 날 끝만 보인다.
3. 1배 어두운 바닥에서 검은 옻칠 칼집은 거의 묻힌다(손잡이·코등이만 읽힘).
4. 측면 무릎 꿇기(사망 2~3)는 IK 로 쪼그린 자세에 가깝다.
5. 몸 색 30/30 — 예산이 꽉 차서 다음 동작(뽑기·넣기 등)에 새 색을 쓸 수 없다.
6. 20ms 프레임(2·3타)은 60fps 에서 1~2 화면 프레임이라 일부 생략될 수 있다(판정 시각은 ms 로 고정).
7. 정면 얼굴은 Q12 지시대로 게임 안에서 보고 재조정.
