## 2. 바닥 v4 설계 (임시)
- **1층 잔 = 큰 판석**(16×16 한 장, 반·T·L 분할 4배치), **2층 패 = 보도블록 16×8 반장 엇쌓기**. 두 층 모두 면 G02 · 줄눈 G01(무채 한 단 차 — 일부러 낮은 대비), 깊은 금·구멍 그늘만 K. 1px 흩뿌림 노이즈 0.
- 판단 근거(2배 목업): 줄눈 G01 은 주인공·적의 K 셀아웃보다 한 단 밝아 윤곽선과 섞이지 않고, 캐릭터 G03~G12 부위는 G02 면 위에서 뜬다. 벽 윗면 G04·벽 정면 G03 벽돌(1층)/판자(2층)로 바닥과 두 단 갈린다.
- **균등 25% 섞기 대응(핵심)**: 시스템이 4변형을 좌표 해시로 균등하게 섞으므로 한 변형의 무늬는 화면 타일의 1/4(한 화면 약 120개)에 나온다. 그래서
  - 손상은 방 종류당 **변형 하나에 하나만**, 금은 줄눈→줄눈으로 이어 '갈라진 판석' 으로 읽히게(떠 있는 도장 무늬 금지), 이 빠짐은 줄눈 교차점 3px.
  - **잔불(강조색)은 바닥 변형에 넣지 않는다**(1회차에 시련 바닥 한 변형에 2px 넣었더니 화면에 100개 넘게 찍혔다). 예외: 보스 바닥 `_0` 의 벌어진 금 사이 S 1px.
  - '금 사이 잔불'·'배수구' 처럼 드물어야 하는 것은 **소품(maxPerRoom)** 으로: 1층 `ash_pit`(방당 1) = 별 모양으로 깨진 판석 틈의 잔불(이름 유지, 그림만 교체), 1층 `puddle`(방당 2) = 꺼진 판석에 고인 물 + 쇠 배수구 뚜껑.
  - 같은 이유로 보스 바닥의 잔·패 문양 각인은 뺐다(25% 반복 = 벽지). 문양은 벽 변형 `wall_v1`(G04 낮은 대비 스텐실)에만.
- **1층 roomFloors.start = 황폐한 평화지역**: 포장 없는 흙 G02 평면 + 변형마다 다른 자리에 2px 흔적 2개(흙덩이 G01·자갈·그을린 자리·깨진 판석 조각). 큰 탄 자국·잔불은 `ash_pit`·구조물(모닥불·묘) 몫. 같은 자리에 덩어리를 두면 격자 점무늬가 됐다(2회차 비평).
- 2층 start(2층엔 여정 노드 없음) = 보도블록 + 작은 흙 한 덩이·자갈.
- 강조 비율(2배 목업 한 화면, 소품·구조물 포함): 1층 전투 0.09% · 여정 0.12% · 보스 0.10% · 2층 전투 0.40%(룰렛·칩). v3(흙바닥) 대비 바닥 자체의 강조는 사실상 0.
- 색 예산 그대로: 무채 10(K,1~7,9,C) + 강조 4(19·21·23·25), 반투명 0.
- 벽·문·출구·상점·소품도 같은 결로 정돈: 벽 덩어리 얼룩·흩뿌림 제거, `wall_v2` K 구멍은 벽을 따라 점선처럼 보여 얕은 홈(G02)으로, 문 안 흙 점 제거, 출구 = 지하로 내려가는 계단(1층 뒷골목 지하 술집 입구), 소품의 과한 강조점·잡점 제거. 소품 이름·solid·maxPerRoom·weight 는 40라운드 값 그대로.

## 3. 노드 지도 아이콘 (임시)
- 192×96 = 32×32 × 6열 × 3행. 열 `journey, battle, shop, rest, event, boss`, 행 0 기본 / 1 지나옴(식음) / 2 잠김(흐림). JSON: `order`, `states`, `frameIndex`, `pivot (16,16)`, `anchor: ui`, `accentSlots [20,21,22]`.
- 모양: 마름모 테(바깥 그늘 S2 · 발광 테 S5 · 안쪽 할로 S4) + 가죽 바탕 S1, 상징 S5 선 + 4방향 할로 S4 + 면 S2(UI 키트 1.2절 발광 규칙과 같은 구조). 강조는 **아이콘당 한 점(2×2 이하, 슬롯 20~22)**: 여정 길 시작의 불씨 · 칼끝 · 자루의 동전 · 불꽃 심 · 물음표 점 · 왕관 보석. 1층 램프로 그렸고 UI 가 현재 층 램프로 바꿔 쓴다.
- 상징: 여정 = 굽은 점선 길 + 이정표 / 전투 = 엇갈린 칼 / 상점 = 묶은 자루 / 휴식 = 모닥불 / 이벤트 = 물음표 / 보스 = 왕관.
- 지나옴 = 테·상징 S4, 발광·강조 없음. 잠김 = 바탕 S2 + 끊긴 테 S4 + 상징 S3(눌린 자국).
- 비평: 1회차 — 대각선 칼끝이 테에 닿아 X 로만 읽힘(마름모 안 대각 폭은 ±5뿐 → 가파르게 세우고 코등이를 가로 막대로), 좁은 자루가 물약 병으로 읽힘, 잠김(S2 테만)이 페이지 얼룩에 묻혀 1배에서 안 보임. 2회차 — 귀 둘 + 가운데 동전 자루가 얼굴로 읽힘 → 모인 주름·좁은 목·동전 아래로. 3회차 통과. 상징은 모두 |dx|+|dy| ≤ 11 안(빌드에서 assert).

## 4. 남은 질문 (인터뷰 후보)
1. **바닥 변형 가중치**: 지금 규약(4변형 균등)으로는 '드문' 무늬를 바닥에 넣을 수 없다(어느 변형이든 25%). 도영 님 원문의 "금·빠진 블록·배수구·흙더미는 드물게" 를 바닥에서 직접 하려면 시스템이 가중치를 받아야 한다. 안: (추천) JSON 에 `roomFloorsWeights` 같은 선택 필드 추가(없으면 균등) / 목록에 같은 인덱스 중복 허용 / 지금처럼 소품으로 대체. 계약 §2·check_json 변경이 필요하므로 시스템·프로듀서 합의 사항.
2. 2층에는 '금 사이 잔불' 역할의 소품이 없다(소품 8종 이름 유지). 2층도 소품 하나(예: `chip_scatter`)를 '녹빛 새는 금' 으로 바꿀지.
3. 1층 start 흙을 갈색(강조 램프 어두운 16·17칸)으로 할지 — 예산이 강조 4 → 5~6 으로 늘어나 보류, 현재는 무채 흙.
4. 목업은 발밑 그림자 없이 그렸다(시스템이 그림자를 그리는지 아트는 모름). 그림자가 없을 때도 K 셀아웃 + 밝은 부위로 떠 보임을 확인.
