### 1.1 이음 규칙(무작위 이웃)
- 흙 같은 '면' 재질: 공유 주기 잡음(고주파·낮은 대비) + 가장자리 창으로 줄인 변형 잡음 → 어떤 변형이 붙어도 경계가 같다. 금·돌·풀·얼룩은 안쪽(가장자리 3px 밖)만.
- 판석 재질: 외곽 v2 `flag_tile` 그대로(왼쪽 열·위 행 = 줄눈). roomFloors 도 같은 바탕·같은 가장자리라 섞어도 사각형이 튀지 않음.
- 테두리와의 이음: 각 지역 북 띠 기준선 근처 땅 색(황무지 50,41,39 · 성문 46,37,34 · 양조 바닥 줄 67,63,63 · 연회장 44,44,46)을 테두리 명도(바닥의 약 0.85배)로 되돌린 값에 바닥 알베도 평균(약 60~70)을 맞춤 — 황무지·성문은 따뜻한 회갈, 양조·연회장은 중립 회색.

## 3. 자기 비평 (see → critique → fix)
1. **1회차**: 공유 잡음이 저주파라 황무지 흙에 같은 얼룩이 32px 마다 되풀이(격자 뚜렷), 성문 진흙도 같은 모양 반복, 흙 금이 새 발자국 모양 → 공유 잡음을 고주파·낮은 대비로, 큰 변화는 데칼·roomFloors 로 넘김. 금은 방향을 오래 유지하는 긴 선.
2. **2회차**: 황무지 roomFloors(어두운 램프)가 사각형으로 튐 → 모든 방 바닥을 같은 바탕·같은 가장자리로. 성문 8px 포석 + 진흙이 소금·후추처럼 시끄럽다 → 16×8 은 벽돌 벽처럼 보여 폐기 → 외곽 판석 규칙 + 따뜻한 회갈 + 안쪽 진흙 얼룩 하나(타일 2만).
3. **3회차(목업)**: 흙 색이 주황으로 떠 테두리의 회갈 땅과 어긋남 → 램프를 회갈 위주로(갈색 섞임). 양조 술 얼룩이 너무 잦음 → 바닥 0~3 에서 빼고 데칼·방 바닥으로. 성문 진흙 얼룩이 짙은 점으로 반복 → 밝은 진흙 색 + 가중치 1/7. 양조 수로가 화면 밖 → 목업 배치 조정(수로는 북쪽 벽에서 8칸).
4. **최종(키아트·개념도와 나란히)**: 성문·양조·연회장은 테두리 발치 땅과 바닥이 같은 계열로 이어진다. 황무지는 흙둑 아래 앞치마와 바닥 흙 질감이 비슷하지만 바닥 쪽이 약간 붉다. 외곽은 기존 v2 바닥(청회)이 테두리(따뜻한 갈색)보다 차갑다 — 이번 범위 밖(질문 5).

## 4. 남은 약점
- 바닥은 32px(1배 밀도)라 v3 소품·주인공(2배 밀도)보다 거칠다(§11 '타일 32px 유지' 결정대로).
- 황무지 마른 풀·자갈이 타일 단위라 멀리서 점 격자처럼 보일 때가 있다(가중치로 완화). 데칼을 더 뿌리면 줄어든다.
- 벽(내부 장애물) 타일은 최소 세트 — 테두리 문체(Gemini)보다 단순해 전투장 안 장애물 벽과 테두리가 붙는 곳은 문체 차이가 보일 수 있다.
- 문·출구·상점 8~12 는 외곽 그림 재사용(지역 문체 아님).
- 연회장 잔 문장 상감은 데칼 1장(4×4칸) — 위치(단상 앞 가운데)는 시스템 배치.
