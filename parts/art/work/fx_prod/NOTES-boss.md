## see → critique → fix 기록 (3회)
1. **1회차**(3배 + 2층 스왑 + 목업): 균열 12줄이 고르게 퍼지고 고리에 닿아 **수레바퀴/태양**으로 읽힘. 먼지 뭉치가 같은 간격이라 톱니바퀴 리벳처럼 보임 → 주 균열 8(각도 불규칙, 길이 18~28 로 고리보다 짧게) + 짧은 금 4, 지그재그 1.6→2.3, 가지 4. 균열은 0.35 → 0.75 → 1.0 으로 자라 고리가 균열을 남기고 떠나가게. 먼지는 간격·크기·반경을 흔들어 몰렸다 비게.
2. **2회차**: 바퀴살 해소 — 파면이 퍼지고 땅이 갈라진 모양으로 읽힘. 남은 것: 먼지가 r45 까지 나가 캔버스 가장자리에서 잘림 + 판정 반경(40)보다 바깥까지 그려져 범위를 크게 오해하게 함 → 먼지를 파면 **바로 뒤**(r30/37/39/40.5)에 두고 고리를 위에 덮음, 가장자리 assert 추가.
3. **3회차**(5배 확대 + 1배 목업): 고리가 r40 안내선과 1px 안쪽으로 겹침, f4 에서 고리가 점선으로 얇아지며 먼지 고리가 드러남, f5 는 균열 점선만 남아 바닥으로 사라짐. 1층(호박)·2층(녹)에서 18 테두리가 어두운 바닥 위 윤곽을 잡고 X0/X1 섬광은 층과 무관하게 흰색. 1배 목업에서 보스 발밑 원 + 52px 거리 주인공 = '피했다' 가 읽힘. **SHIP.**

## 임시 결정 (도영 님 검수 대상)
1. **캔버스 96×96 · 피벗 (48,48) 중심**: 반경 40 + 고리 두께 + 먼지(≤47) 가 들어가는 최소 정사각. 배율 1 로 판정 반경과 맞음. 다른 보스의 반경 R 이 다르면 `scale = R/40`(정수 배율이 아니면 픽셀이 깨지므로 1 유지 권장).
2. **고리 = 정원**(원근 압축 없음): 판정 원·`telegraph_circle` 과 같은 모양으로 "예고 원 = 맞는 범위 = 충격파" 가 한 모양으로 읽히게. crush 의 세로 0.6 타원과도 구분. 대안: 0.75 정도 눌러 바닥감 강화(판정과 어긋남).
3. **고리 도달 시각**: f3 시작(150ms)에 r39, f4(230ms) 점선 r40.5. 판정은 시스템 시각 그대로(그림은 판정 직후 퍼지는 연출).
4. **6프레임 480ms** (40/50/60/80/110/140). 짧게 원하면 f5 제거(340ms).
5. **섬광 = 코어 X1 `#fff4dc` 0.2 · 40ms · f0**(고정색, 층 스왑 불필요). 층 강조로 하려면 현재 층 ramp[11](27) — 시스템이 층 색을 고르는 코드가 필요해 기본값은 X1. **흔들림 4px · 120ms**(지진·분쇄와 같은 세기, 보스 공격이라 1차 crush 2px 보다 크게).
6. **anchor = `hitbox_center`**: 계약 §3.1 열거값 안에서 고름(새 값 `slam_point` 를 만들지 않음). 의미는 "내리찍기 판정 원 중심 = 슬램 지점" — `pivotNote` 에 적음. 보스 발과 판정 중심이 다르면 판정 중심에 둔다.
7. **JSON 메모 필드 `source: "boss"`, `hitRadiusPx: 40`** 추가(시스템은 모르는 필드 무시). `weapon`·`secondary` 는 넣지 않음(무기 이펙트가 아님).
8. **먼지 무채 G06/G09**: "층 램프 + 코어 + 무채" 지시 범위 안. 무채 예산 2 를 그대로 씀.
