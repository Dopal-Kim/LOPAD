## 0. 방식

- 적 v3 와 같은 3D 골격(`enemies_v3/erig·human` import 만) → 4방향 쿼터뷰 투영 → `hero_v3/v3kit.Rig3` 셰이딩. 생성 이미지 픽셀은 쓰지 않음(개념 `gemini/concept_char/raw_boss_c.jpg` 눈으로 참고만).
- **Q14 확대 = 단순 확대가 아님**: `b1body.SCALE` 1.0 → 1.3 으로 같은 골격을 다시 래스터·셰이딩(도트 1:1 밀도, 최근접 확대 없음). 늘어난 해상도에 맞춰 픽셀 단위 덧칠을 새로 그림(`K = SCALE`):
  - 얼굴: 2줄 덥수룩한 처진 눈썹 + 눈두덩 그늘 · 무거운 윗눈꺼풀 · 충혈된 흰자(A19)·호박 눈빛 2도트 · 아랫눈꺼풀 · 눈 밑 처짐 · 웃는 입(이빨 하나 빠짐·젖은 아랫입술)·포효 입(이빨·혀) · 볼 홍조 0.5 격자(빈틈 없음) + 실핏줄 · 술코 땀 반짝임·실핏줄·모공·콧구멍 그늘 · 귀 세부.
  - 수염 결 가닥 22 + 털점 46 · 수염 끝 3가닥을 굵고 짧게(가는 막대처럼 보이던 것 수정).
  - 모피 깃 털점 150 + 털 뭉치 결 34 · 망토 모피 단 털 뭉치(줄무늬 띠로 보이지 않게 끊음).
  - 더블릿: 터진 앞섶 0.5 간격(빈틈 없음) · X 끈 + 놋 끈구멍 · 풀려 늘어진 위 끈 · 기운 천 조각(바늘땀 테) · 옆구리 솔기.
  - 허리띠: 두꺼운 사각 놋 버클 + 핀 · 띠 구멍 3 · 늘어진 띠 끝. 앞치마 주머니(바늘땀) + 꽂힌 마개.
  - 장화: 접은 목 바늘땀 · 장화 끈(놋 고리). 왕관: 테 새김 점 띠 · 꼭지 밑 호박 알 · 앞 보석 2×2.
  - 화면 효과의 픽셀 거리(술 튀김·방울 줄·횃불 불꽃)는 ×1.3, 먼지만 ×1.12(192 폭 안에 들게).
- **Q13 술통 잔**(`draw_cup`, 유리 굽잔·백랍 잔 분기 삭제): 배부른 통(널 12장 이음 + 빛 쪽 나뭇결) · 쇠테 3줄(2도트) · 손잡이(쇠띠 2) · 놋 꼭지 · 윗면 = 호박 술 + 거품 테(빈 통은 어두운 속). 오른손이 손잡이를 쥐고 통은 손 바깥쪽.
  - 마시기: `b1acts.cask_pose` 가 입 위치에서 거꾸로 손 위치를 구해 **통 마구리가 입에 닿게** 기울임(입 오른쪽에서 들이켬). 1차 대안 C 시안에서 통이 입 아래에 떠 있던 문제 해결.
  - 깨짐(`drink_break` 0~2): `cask_burst` — 통이 터져 널 9장(3도트 폭 휜 판, 일부 쇠테 조각)이 회전하며 사방으로, 쇠테 2개가 기울어 벌어지며 떨어짐, 나뭇조각·술 방울. 바닥 잔해(`shards`)도 유리 조각 → 널 조각·쇠테 고리·놋 꼭지.
  - 사망 3: 놓친 술통이 바닥에서 부서짐(같은 잔해).
- Q16 그대로: 누운 그림 전 방향 공통(`asDir down`) · `throw`/`throw_torch` 분리 · 잔은 다음 대기에서 다시 참(drink 끝은 빈 통 → idle 은 찬 통) · **죽음 1.59초**(마지막 유지 400 → 390ms). Q15 촛대는 변경 없음.

### 좌표 기준 (시트 한 프레임 안의 도트, 왼쪽 위 0,0)

- `cupAnchors` = 사각형 `{x, y, w, h, visible, visiblePx}` — **x, y = 사각형 왼쪽 위**(시스템 현재 해석과 같음). 잔이 없는 프레임은 `null`.
- `handAnchors`·`handR`·`handL`·`footAnchors`·`impactAnchors`·`bellyAnchors` = **점 `[x, y]`**. throw = 술통 마구리(윗면) 가운데, throw_torch = 횃불 끝(없는 프레임 `null`), kick = 차는 왼발 발끝, slam = 왼 주먹, attack·stagger_dash = 배 중심.
- 논리 px = (도트 − pivot) × 0.5.
- fx `boss1_cup_shatter` 는 pivot = 술통 중심 → `cupAnchors` 의 (x + w/2, y + h/2) 에 놓는다.

## 3. 자기 비평 (see → critique → fix)

1. 1회차(SCALE 1.3 만): 몸은 같은 밀도로 잘 커졌으나 얼굴 덧칠(눈·입)이 1차 픽셀 크기 그대로라 얼굴이 작아 보임, 앞섶·볼 홍조 점에 빈틈, 망토 모피 단이 줄무늬 → 얼굴 픽셀 패턴 새로 그림, 격자 0.5 간격, 모피 단 털 뭉치로 끊음.
2. 2회차(술통 잔): 대기 정면·측면은 좋음. 들이켜기에서 통이 손 옆에 떠서 입과 멂(1차 대안 C 와 같은 문제) → 입에서 거꾸로 손 위치를 구하는 `cask_pose`.
3. 3회차(깨짐): 쇠테 3개가 머리 위 후광·용수철처럼 보이고 널이 가늘어 수염과 섞임, 바닥 잔해가 발에 가려짐 → 쇠테 2개를 기울여 끊고, 널을 3도트 폭 밝은 면으로, 흩어짐 거리 키우고, 바닥 잔해를 발 옆(24,12)으로·크게.
4. 4회차(가장자리): 모든 시트가 바닥 행에 닿음(카메라 쪽 발이 피벗 아래 11 도트, 1차 128×192 에도 1~2 도트 잘림이 있었음) · 내리찍기·사망 먼지가 좌우 100 도트 → 피벗 y 232 → 220, 먼지 배율 1.12 → 가장자리 픽셀 0.
5. 색: throw_torch 41 → 술통 쇠테 반짝임 G13 → G12, 놀란 눈·술면 반짝임 A24 → A23 으로 40.
