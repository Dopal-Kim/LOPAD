## 결정(프로듀서 위임 범위 안의 세부)
- **피 색**: 7층 '적' 램프 어두운 5단 고정 hex `#1a0f13 #381b25 #572030 #751f33 #941930`(BL0~4). BL4 는 덩어리마다 하이라이트 1도트만. 바닥 웅덩이는 가운데가 가장 어둡다(BL0) — 밝은 테두리 고리 금지.
- **주인공 피** = 타르(G0~G3, 하이라이트 G4/G5 1도트) + 호박 불씨 + 재(G5~G8). 상흔도 호박 램프(몸 30색 안, 새 색 없음).
- **분출 행 = amount**: `blood_spray_*` 행 0~2 = ENEMY_GORE.amount 1·2·3. 오른쪽 = 진행 방향(시스템 회전), flipY 허용.
- **상흔 단계 누적**: `hero_wound3_*` 는 1·2·3 단을 다 그린 그림 → 한 번에 한 단계 시트만 겹친다. 깊이 = 몸 바로 위·무기 오버레이 아래.
- **상흔 오버레이 범위(20 몸 시트)**: idle·idle_free·walk·walk_free·run·run_free·dash·hurt · katana_rise/fall/thrust · greatsword_sweep_cw/cleave/sweep_ccw(8방향) · dagger_combo1~3 · bow_aim/draw_hold/release. 나머지(특수기·갈래·처형·turn_skid·death·birth)는 오버레이 없음(계약 §8 '없는 시트는 오버레이 없음').
- **상흔 그리는 법**: `hero20/rig20.py` 에 `WOUND` 전역(기본 0 — 본 렌더 그대로)과 `wounds()` 층을 넣고, hero20 파이프라인(자세·IK·오프셋 그대로)을 쓰기 없이 0·1·2·3 네 번 렌더 → **WOUND 0 이 assets 본 시트와 픽셀까지 같은지 확인(20시트 전부 0 차이)** → 차이 픽셀만 남긴 투명 시트. 부위 위에만 칠하므로 팔·무기에 가린 곳은 자동으로 가려진다.
- **박힌 화살 앵커**: rig20 `arrow_anchors()` — 화살은 몸 뒤·바깥으로 박힘(등·어깨 위·허벅지 뒤·오른위팔 바깥). 앞/뒤는 보기 방향 규칙(정면: 등·허벅지 = below / 뒷면: 전부 above / 측면: 가까운 쪽 above). 화면 각은 3D 방향을 투영해 `stuck_arrow` 5각(−90·−120·−150·180·150°) + flipX 중 가장 가까운 것.
- **사망 변형**: 같은 3D 리그(erig)를 훅(부위 거르기·골격 기록)해 원래 사망 자세로 다시 렌더. behead = 머리 쪽 부위 제거(머리·모자·머리카락·투구·두건·턱수염·머리띠 꼬리), bisect = 0 프레임 윗몸을 허리선에서 떼어 앞으로 꺾여 떨어지고 다리는 원래 사망 자세, pinned = 사망 2 프레임 자세를 선 채로 늘어지게 바꾼 새 자세 + 가슴 화살대, burn = 원 자세 + 그을림·불길, collapse = 원 자세 + 상처·피 젖음. 프레임 수·ms 는 원 death 와 같다(10). drown 은 만들지 않음(기존 낙하 연출). `_rim`·`_elite` 변형 없음.
- **처형**: 새 자세를 리그로 짜지 않고 P20 몸 공격 시트(몸+무기 동기 완료)에서 프레임을 골라 0.45초로 재구성(`sourceSheet`·`sourceFrames` 기록). 칼 = katana_iai(수평 일섬 → 피 털기), 대검 = greatsword_cleave(8방향), 단검 = dagger_backstab, 활 = dagger_combo3 몸 + 새로 그린 '역수로 쥔 화살' 오버레이(원 단검이 보이던 자리 기준으로 가림 굽기). 타격 프레임부터 날에 피.

## 자기 비평 기록(see → critique → fix)
1. 분출 1차: 사거리가 짧아 둥근 터짐 · 띠(ligament)가 피벗을 빼먹고 왼위 구석에 그려짐 → 속도 ×1.7·감속 ×0.8, 띠 좌표 수정.
2. 바닥 데칼·웅덩이 1차: 밝은 BL2 테 + 검은 속 = '구멍 뚫린 고리' → 2차: 동심 띠 디더도 고리로 읽힘 → 3차: 몸 BL1 단색 + 빛 쪽 가장자리만 BL2 + 깊은 곳 BL0(낮은 주파수 경계) + 끊긴 젖은 빛 호. 튐 가시(왕관) 추가.
3. 부숨 분출: 같은 속도의 고리 방울이 완벽한 동그라미 자국으로 남음 → 속도·크기 들쭉날쭉. 타르 방울이 어둠에 묻힘 → 크게·빛 쪽 G3.
4. 상흔 3단 팔: 곧은 네온 줄 → 지그재그 마디 + 끊긴 틈 + 심만 백열.
5. 화살 앵커: 그림자 셈으로 좌우 어깨가 비대칭(한쪽 below) · 정면에서 허벅지 화살이 배 위로 솟음 → 보기 방향 규칙으로. 박힌 자리 3×3 검은 점 = 총알 구멍 → 2도트 + 불씨 1.
6. 사망 behead: 분출 방울이 쓰러짐 변형(xf)을 거친 '바닥' 때문에 공중에 멈춤 → 바닥 = 발 피벗 줄, 속도·중력 조정(맥박 3번).
7. bisect 1차: 윗몸을 북쪽으로 미는 방식은 다리와 겹쳐 안 갈라져 보임 + 끌린 피가 사다리 줄무늬 → 윗몸은 0 프레임 그림을 허리에서 떼어 앞으로 꺾여 떨어지게(틀 밖 잘림 방지), 피는 원 웅덩이로.
8. collapse·pinned: 밝은 셔츠가 선홍 판으로 번짐 → 젖음 한 단 어둡게, 반경 상한. pinned 정면 화살이 셔츠에 묻힘 → 옆·위로 비스듬히, 밝은 나무색.
9. gore_parts: 깃발·망치·방패까지 윗몸에 붙어 날아감 → 소품 부위 제외, 외딴 불티 점 지움.
10. 처형 날 피: 해시 점박이 = 녹 → 한쪽 날을 따라 이어진 띠 + 끊긴 마디.

## 남은 약점
- 박힌 화살은 원근 단축 없이 늘 같은 길이(정면에서 카메라 쪽으로 박힌 화살도 옆으로 뻗어 보임).
- 처형 4종은 기존 공격 프레임 재구성이라 '처형 전용' 고유 안무(적을 붙잡는 손 등)는 없다. 칼 처형은 iai 원 시트의 검광(청백 띠)이 그대로 섞인다.
- 사망 변형 pinned 의 늘어진 자세는 리그 자세 키만 바꾼 것이라 적마다 비슷하다. burn 의 그을림은 2×2 블록 노이즈.
- 상흔 오버레이는 무기 오버레이 아래에 둔다 — 무기 오버레이가 몸을 덮는 칸(대검 등)에서는 상흔도 가려진다(의도).
