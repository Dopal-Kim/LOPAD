## 4. 지키는 것 (UI 파트)
- 정수 배율만, `pixelArt: true`, 모든 좌표 정수. 9-slice 는 Phaser `NineSlice`, 질감은 `paper_tile` tileSprite, 제본선은 `spine` tileSprite(세로).
- 색을 새로 만들지 않는다. 글자색은 위 표에서. **종이 위 글자는 G00/G01(본문)·G02(비선택)·G03(흐림)까지만.** 세피아 S0~S5 는 UI 그림 전용이며 글자색으로는 쓰지 않는다(임시).
- 세피아 램프를 캐릭터·타일·이펙트 틴트에 쓰지 않는다.
- 아이콘·커서·도장·일기장을 회전·비정수 확대하지 않는다.
- 키트 수정 요청은 아트 파트로.

## 5. 36라운드 재작업 기록 (see→critique→fix)
1. 1회차: 세피아 램프 도입(S3 페이지 L*43), 책 틀·제본선 신규, 잉크 틀 G00 + 가죽 림 → 종이 스티플이 글 밑에서 소금처럼 튀고 64px 반복이 600px 펼침에서 보임. 책 틀~페이지 사이 동심 테 11줄로 과함. 제본선 8px 꿰맴이 지퍼처럼. 결과 왼쪽 페이지 글이 제본선을 넘침.
2. 2회차: 스티플 상한 0.30/0.60 → 0.16/0.42, 섬유 22→14, 단면 4줄→3줄, 꿰맴 주기 16, 결과 글 줄바꿈. 1배 가독성: S3 위 G00 제목·G01 본문 읽힘, G02 한 단 뒤, G03 흐림. 잉크 G00 위 G13 선명. 게이지 빈 구간 G01 이 바탕과 구분.
3. 3회차: 밝은 점 상한 0.12·문턱 0.68 (펼침에서 밝은 군집 반복 완화). 고립 0, 반투명은 `panel_ink` 가운데만. 색 수: 패널·틀 세피아 5 + 무채 ≤4, 아이콘 세피아 ≤4.
