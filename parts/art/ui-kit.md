## 4. 지키는 것 (UI 파트)
- 정수 배율만, `pixelArt: true`, 모든 좌표 정수. 9-slice 는 Phaser `NineSlice` 로 늘리고 가운데 질감은 `paper_tile` tileSprite 로 (타일 64).
- 색을 새로 만들지 않는다. 글자색·선색도 위 표의 무채 또는 현재 층 램프에서 고른다. 종이 위 글자는 G00/G01 (G03 이하로 밝은 글자는 바랜 종이에서 묻힌다).
- 아이콘·커서·도장을 회전·비정수 확대하지 않는다. 깜빡임은 프레임 교체로.
- 키트 수정 요청은 아트 파트로 (빌드 스크립트 한 곳에서 재생성).

## 5. 33라운드 재작업 기록 (see→critique→fix)
1. 1회차: 종이 G13→G09 로 내리고 얼룩을 타원 blob 으로 찍음 → 32px 타일에서 같은 얼룩이 격자로 반복돼 글 밑에서 벽지처럼 보임. 누런 점이 흩어져 '주황 색종이'. 보스 이름·공지 23 이 칙칙한 톤에서 튐. 결과 도장 2배는 픽셀 밀도 혼합.
2. 2회차: 타일 64 + 주기 값 노이즈(16px+8px) 문턱 → 덩어리가 여전히 64px 마다 보임 → 노이즈 값 비례 확률 스티플로 바꿔 얼룩덜룩만 남김. 누런 점은 얼룩 중심에만, G08 로 감싼 2~3px 군집. 가장자리 그을림 띠 G08 추가. 강조 글자 23→22, 도장 1배.
3. 3회차: 타일당 누런 점 4→2(하나는 18) — 1배에서 격자로 줄지어 보이던 것 해소. 1배 가독성 확인: 종이 G09 위 G00 제목·G01 본문 읽힘, G04 흐린 글 읽히되 한 단 뒤. 고립 0, 반투명은 `panel_ink` 가운데만.
