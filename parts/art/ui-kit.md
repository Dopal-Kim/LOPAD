# LOPAD UI 키트 v0.1 (2026-10-02, 32라운드 Q3 전폭 재설계)

근거: `decisions/2026-10-02-round-32-redesign-direction.md` Q1(960×540 정수 배율)·Q3(무채 + 층 강조색, 종이·잉크·일기장, HUD 가장자리). 아래 "임시"는 아트 파트 제안이며 검수 대상. 프로듀서가 이 문서를 `contracts/ui-art-kit.md` 로 승격한다.

- 원본: `assets/sprites/ui/*.png` + 같은 이름 `.json` (아트 소유). UI 파트는 `assets/ui/` 로 **그대로 복사**해 쓴다 (수정 금지, 갱신 시 재복사).
- 빌드: `python3 parts/art/work/ui/build.py` (단일 소스, PNG 를 손으로 고치지 않는다).
- 미리보기: `parts/art/work/ui/preview_kit.png`(전체 2배 + 9-slice 늘림 검증) · `preview_mock.png`(960×540 HUD·메뉴 목업) · `preview_icons.png`(아이콘 8배, 종이·잉크 두 배경).
- 모든 그림은 1배(960×540 내부 해상도) 기준. 창 배율은 정수만 (1280×720 창 = 1배, 1920×1080 = 2배). 비정수 배율·보간 금지.

## 1. 색 규칙
| 역할 | 색 |
|---|---|
| 종이 | G13 `#d8d9db` 본색, G14 빛 가장자리, G12 그늘·섬유, G11 단면 |
| 잉크 | G01 `#141516` 본색, G00 가장 진한 고임, G03 번짐, G09 옅은 선·연필 |
| 어두운 틀 (HUD) | G01 바탕(반투명 0.85), G02 림(빛, 위·왼쪽), G00 림(그늘, 아래·오른쪽), G03 꺾쇠 |
| 글자 (권장, UI 파트) | 종이 위 본문 G03 / 제목 G01 / 흐림 G09. 잉크 위 본문 G13 / 흐림 G11 / 강조 **층 램프 23 light1** |
| 유채 | **현재 층 강조 램프만** (인덱스 16~27). 키트는 1층 호박으로 그렸고, 시스템/UI 가 층 램프로 스왑하거나 `setTint` 한다. 고정 포인트색 없음 |

강조색 사용처(임시): 게이지 채움(체력·보스), 선택 커서 잉크 방울, 아이콘의 1~3px 포인트(피·술·문장·눈빛·책갈피), 공지 글자(출구·본영 문 열림), 보스 이름. 그 외는 전부 무채.

## 3. 레이아웃 제안 (임시, 목업 `preview_mock.png` 기준, 960×540, 여백 8)
- 좌상단 `panel_ink` 236×62: 1행 `icon_hp` + `gauge_frame` 196 + 숫자, 2행 `icon_gold` 숫자 · `icon_potion` 숫자 `Q`.
- 상단 중앙: 층 제목 · 시련 n/4 — 패널 없이 글자 + 1px G00 그림자.
- 우상단 `minimap_frame` 118×98 + 아래 `icon_sound`/`icon_mute` + `M`.
- 좌하단 `panel_ink` 300×52: 무기 아이콘(기존 `weapons/<id>_icon`) + 이름·진화·우클릭 / `icon_sense` + `gauge_frame`(gray) 160 + 개성 n/100.
- 하단 중앙 보스전: `icon_boss` + 이름(램프 24) + `gauge_boss` 360.
- 우하단 공지(`exitOpen`/`bossUnlocked`): `panel_ink` 150×30 + `icon_exit`/`icon_boss` + 글자(램프 23).
- 중앙 메뉴·일시정지·결과: `panel_paper` + `paper_tile` 깔기, 제목 G01, `rule`, 본문 G03, 항목 앞 `cursor`, 결과 화면은 우하단에 `stamp_*`.
- 글꼴은 이번 범위 밖 (목업은 Unifont 16px 로 그렸음 — 픽셀 글꼴 느낌의 참고일 뿐).

## 4. 지키는 것 (UI 파트)
- 정수 배율만, `pixelArt: true`, 모든 좌표 정수. 9-slice 는 Phaser `NineSlice` 로 늘리고 가운데 질감은 `paper_tile` tileSprite 로.
- 색을 새로 만들지 않는다. 글자색·선색도 위 표의 무채 또는 현재 층 램프에서 고른다.
- 아이콘·커서를 회전·비정수 확대하지 않는다. 깜빡임은 프레임 교체로.
- 키트 수정 요청은 아트 파트로 (빌드 스크립트 한 곳에서 재생성).
